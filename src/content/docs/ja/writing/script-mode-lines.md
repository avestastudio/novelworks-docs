---
title: "スクリプトモード：すべての行"
description: スクリプトモードで書けるすべての種類の行を、例つきで紹介します。
---

スクリプトモードでは、**1行が「起こること」1つ**です。例では英語の単語を使っています。NovelWorks は、ほかのエディターの言語の単語も同時に理解します（`si`、`décor`、`fin` など）。キーワードや名前を読み取るとき、大文字・小文字、アクセント記号、余分なスペースは区別されません。

選択肢、条件、ジャンプについては、[スクリプトモード：条件と選択肢](/novelworks-docs/ja/writing/script-mode-conditions/)を見てください。

## セリフ

```
Mia : Hello!
```

`Name : text` の行（名前 : テキスト）は、そのキャラクターが話すセリフです。コロンの前後のスペースはなくてもかまいません。その名前のキャラクターがいない場合は、行全体がナレーションとして読まれて警告が出ます。クイック修正でキャラクターを作ることもできます。

### 表情をつける

```
Mia (happy) : Hello!
```

Mia は「happy」の表情で話します。すでにステージにいる場合は、その場所のまま表情だけが変わります。ステージにいない場合は、中央に登場します。

### 複数行のテキスト

```
Mia : I looked for you everywhere.
  I had given up hope.
```

スペース2つでインデントした行は、上の行の続きになり、**同じ枠の中**の新しい行として表示されます。

## ナレーション

```
It had been raining since morning.
```

ほかの種類の行ではない行は、すべてナレーションです。

## 書いたとおりに残す行

```
> background : this is just text
```

`>` で始まる行は、コマンドのように見えても、**書いたとおりの**ナレーションになります。ナレーションがそのままでは誤って読まれてしまう場合は、NovelWorks が自動で `>` を書き足します。

## メモ

```
// to re-read
Mia : Hello!
```

`//` で始まる行は、次のカットにつく自分用のメモです。ゲームには表示されません。[メモ](/novelworks-docs/ja/writing/notes/)を見てください。

## ステージの行

これらの行は、それ自体はカットになりません。次の行から、ステージの状態を変えます。

```
background : Station
show : Mia happy left
hide : Mia
hide : everyone
```

- **`background : Name`** は、背景を Name という名前の画像に変えます。`background : none`、またはコロンのあとに何も書かないと、背景がなくなります。
- **`show : Mia happy left`** は、キャラクターを登場させたり、表情や位置を変えたりします。名前のあとに、表情と位置を足せます。位置は `left`、`center`、`right`、または自由な配置のままにする `placed by hand` です。位置を書かない場合、すでにステージにいるキャラクターはその位置のまま、新しいキャラクターは中央に出ます。キャラクター名にはスペースを含められます。
- **`hide : Mia`** は、キャラクターを退場させます。`hide : everyone`、またはコロンのあとに何も書かないと、ステージが空になります。

ステージの行のあとには、もう1行必要です。ない場合は警告が出ます。

## アイテム

```
give : Key
give : Key x3
remove : Key
give : Key, no notice
```

プレイヤーにアイテムを渡す、または取り上げるカットです。`x3` は個数です（×の記号でも書けます）。`take :` は `remove :` と同じ意味です。`, no notice` を付けると、プレイヤーに普段表示される短い通知が出ません。アイテムはゲームの機能の1つです。[インベントリ](/novelworks-docs/ja/features/inventory/)を見てください。

## マップを開く

```
map
```

`map` という単語だけの行は、マップを開きます（「マップを表示」カット）。[マップ](/novelworks-docs/ja/features/map/)を見てください。

## エンディング

```
end : Good ending
  You understood everything.
```

エンディングです。コロンのあとに名前を書きます。その下のインデントした行は、省略できる短いテキストです。`ending :` でも書けます。「End」という名前のキャラクターがいる場合は、キーワードよりキャラクターが優先されます。コマンドを角かっこで囲んだ場合は別です。

## 探索のカット

```
exploration : 3 zones
```

スクリプトモードでは、探索のカットはエリア数つきの1行で表示されます。ここではエリアを作ったり編集したりできません。探索はインスペクターで編集します。ほかのテキストを編集しても、カットのエリアと小道具はそのまま残ります。新しく書いた `exploration` の行は、空の状態で始まります。[探索](/novelworks-docs/ja/features/exploration/)を見てください。

## 見出し（ゲーム全体のテキスト）

```
# Park
```

ゲーム全体のテキストでは、`#` で始まる行が、その名前のシーンの始まりになります。

## 角かっこ

コマンドの行は、角かっこで囲めます。`[background : Station]` は `background : Station` と同じです。角かっこは、いつも「これはコマンドです」という意味です。必要なのは、キャラクターの名前がコマンドと同じ場合だけです。たとえば Background というキャラクターがいるなら、コマンドは `[background : Station]`、キャラクターは `Background : Hi!` と書きます。

## 早見表

| 書くもの | 意味 |
|---|---|
| `Mia : Hello!` | Mia が話します。 |
| `Mia (happy) : Hello!` | Mia が表情つきで話します。 |
| `It rained.` | ナレーションです。 |
| `  more text` | 同じ枠の中で行が続きます。 |
| `> text` | 書いたとおりに残す行です。 |
| `// note` | 次のカットにつく自分用のメモです。 |
| `background : Station` | ここから先、背景が変わります。 |
| `show : Mia happy left` | キャラクターが登場する、または変わります。 |
| `hide : Mia` | キャラクターが退場します。 |
| `give : Key x3` / `remove : Key` | アイテムを渡す、または取り上げます。 |
| `map` | マップを開きます。 |
| `end : Good ending` | エンディングです。 |
| `-> Park` | シーンへのジャンプです。 |
| `? …`, `- …`, `if …` | 選択肢と条件です。次のページを見てください。 |
| `# Park` | シーンです（ゲーム全体のテキストのみ）。 |
