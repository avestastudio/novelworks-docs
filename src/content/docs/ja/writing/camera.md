カメラは、シーンのどの部分をプレイヤーに見せるかを決めます。画面全体でも、クローズアップでもかまいません。カットを選び、[カットパネル](/novelworks-docs/ja/writing/moment-panel/)の「{ui.inspectorTabs.effects}」タブを開いて、「{ui.camera.open}」をクリックします。

![カメラのウインドウ。枠の付いたシーン、上部の用意された動き、横の設定、下部のショットがあります。](/novelworks-docs/screenshots/camera-window.png)

エディターのゲーム画面には、常にシーン全体が表示されます。「{ui.inspectorTabs.effects}」タブの小さなプレビューに、プレイヤーに見える画面が表示されます。

## ショット

カットには1つ以上のショットがあり、ウインドウの下部に並んでいます。各ショットはシーンの上の枠で、カメラはショットからショットへ移動します。

- シーンの上の枠を**ドラッグ**して、プレイヤーに見せる範囲を選びます。
- 「{ui.camera.addShot}」（プラス記号）で、6つまでショットを追加できます。
- 「{ui.camera.removeShot}」は、選んでいるショットを削除します。
- 「{ui.camera.play}」は、ウインドウの中でショットを再生します。「{ui.camera.stop}」で終わります。

## 用意された動き

上部のボタンは、ショットを自動で作ります。今あるショットは置き換えられますが、カット全体の設定は保たれます。寄っていく動きは、舞台の最初のキャラクターに向かいます。誰もいないときは、画面の中央に向かいます。

| 動き | 内容 |
|---|---|
| {ui.camera.preset.fixed} | 画面全体のまま、動きません。 |
| {ui.camera.preset.slowZoom} | 画面全体から、ゆっくり近づきます。 |
| {ui.camera.preset.travelling} | 一定の速さでシーンを横切ります。 |
| {ui.camera.preset.reveal} | 近くから始まり、画面全体まで引きます。 |
| {ui.camera.preset.focus} | 背景がぼけていく間に、少し近づきます。 |
| {ui.camera.preset.tension} | 画面全体から、傾いたクローズアップへ移ります。少しぼかしが入ります。 |

## キャラクターに合わせる

「{ui.camera.frameOn}」には、舞台上のキャラクターが表示されます。クリックすると、そのキャラクターの顔に枠が合います。枠はその場所に残ります。あとでキャラクターが動いても、枠は追いかけません。

## ショットの設定

| 設定 | 内容 |
|---|---|
| {ui.camera.zoom} | 100%（画面全体）から400%まで。 |
| {ui.camera.arrive} | カメラがこのショットに届く動き方です。「{ui.camera.smooth}」、「{ui.camera.steady}」、「{ui.camera.quick}」、「{ui.camera.cut}」から選びます。最初のショットでは、この設定は「{ui.camera.arriveFirst}」になります。 |
| {ui.camera.seconds} | カメラがそこへ届くまでの時間です。0.2〜8秒。 |
| {ui.camera.hold} | すぐに届くショットでは、代わりにこの設定が表示されます。次のショットまでそこにとどまる時間です。 |
| {ui.camera.blur} | 背景をぼかします。キャラクターはぼけません。 |
| {ui.camera.tilt} | ショットを傾けます。左右それぞれ12度まで。 |

シーンの最初のカットでは、最初のショットに移動元がありません。「{ui.camera.start}」と表示されます。

## カット全体の設定

「{ui.camera.wholeMoment}」の下に次の項目があります。

- {ui.camera.bars}
- {ui.camera.vignette}
- {ui.camera.grain}
- {ui.camera.fadeIn}
- {ui.camera.handheld}
- {ui.camera.depth}。最初は100%で、0まで下げられます。

「{ui.camera.foreground}」は、枝や窓ガラスなどの画像をキャラクターの手前に置きます。画面全体を覆うので、透明な部分のある画像を使ってください。奥行きがあると、キャラクターより大きく動きます。クリックは前景を通り抜けます。

「{ui.camera.reset}」は、このカットのカメラを取り除きます。すべてのショットとカット全体の設定が消えます。前景は残ります。

## どこまで続くか

カメラと前景は、背景と同じように、カットで変えるまでカットからカットへ続きます。「{ui.stage.scopeLabel}」はウインドウの下部にあります。[ステージ](/novelworks-docs/ja/concepts/stage/)を見てください。

## ゲームでは

- テキストが表示されている間に、ショットが順に再生されます。
- 最初のクリックで動きが終わり、セリフ全体が表示されます。次のクリックで先へ進みます。
- 次のカットは最後のショットを保ち、ショットをもう一度再生することはありません。
- 同じシーンの2つのカットの間では、カメラは新しい場所へなめらかに移動します。新しいシーンは、最初のショットから直接始まります。
- ロードしたセーブは、最後のショットから始まります。
- ダイアログボックスとメニューは動きません。

プレイヤーがシステムで動きの軽減を求めている場合、ゲームは揺れもフェードもなしで、最後のショットへ直接移ります。

## 制限

- 探索のカットでは、エリアが対象の上からずれないように、「{ui.camera.tilt}」と「{ui.camera.depth}」は無視されます。
- ズームすると画像が拡大されるので、小さな背景はぼやけます。
- スクリプトモードではカメラを書けません。テキストを編集しても、カメラは保たれます。
- 体験版では、カットごとにショットは2つまでです。[無料体験版](/novelworks-docs/ja/getting-started/demo-edition/)を見てください。
