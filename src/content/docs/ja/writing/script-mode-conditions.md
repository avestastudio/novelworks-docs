このページは[スクリプトモード：すべての行](/novelworks-docs/ja/writing/script-mode-lines/)の続きです。例では英語の単語を使っています。NovelWorks は、ほかのエディターの言語の単語も同時に理解します。

## ジャンプ

```
-> Park
```

Park というシーンへのジャンプです。プレイヤーにはこのカットは見えません。名前を付けずに `->` だけ書くと、行き先のシーンがまだないジャンプになります。

## 選択肢

```
? What now?
- Talk to her -> Park
- Leave
```

- `?` で始まる行は質問です。省略できます。前に質問がない `-` の行は、質問のない選択肢の始まりになります。
- `-` で始まる各行が1つの項目です。テキストのあとの `-> Park` は、その項目が向かうシーンです（**最後の** `->` よりあとの部分）。`->` がない項目では、物語がそのまま続きます。
- 質問だけで項目がない選択肢も、そのまま読み取られます。ゲームで動くには、選択肢に項目が2つ以上必要です。

### 項目が変えるもの

項目の下にインデントした行は、その項目が変えるものです。

```
- Give her the flower -> Park
  + Affection 1
  = MetMia true
  give : Key
  remove : Coin
```

| 行 | 意味 |
|---|---|
| `+ Affection 1` | Affection というスコアに1を足します。 |
| `= MetMia true` | MetMia の値を決めます。値は数字、または `true` / `false` です（`yes` / `no` も使えます）。 |
| `give : Key` (`give : Key x3`) | プレイヤーにアイテムを渡します。 |
| `remove : Key` | アイテムを取り上げます。 |

そのほかのインデントした行は、警告が出て無視されます。

### ときどきだけ表示される項目

```
- Open the door -> Hall
  if item Key, locked
```

項目の下にインデントした `if` の行は、その項目が選べる条件を表します。`, locked` を付けると、選べないときに項目がグレー表示になります。付けない場合、項目は隠れます。[物語の分岐のしかた](/novelworks-docs/ja/concepts/how-stories-branch/)を見てください。プレイヤーには、いつも先へ進む道が残ります。

## テスト

条件は、変数またはアイテムを調べます。

| テスト | 意味 |
|---|---|
| `Affection >= 3` | スコア Affection が3以上です。 |
| `MetMia = true` | できごと MetMia が「はい」です。 |
| `item Key` | プレイヤーが Key を持っています。 |
| `item Coin x3` | プレイヤーが Coin を3個以上持っています。 |
| `without Key` | プレイヤーが Key を持っていません。 |

スコアには、`=`（または `==`）、`!=`（または `≠`）、`>`、`>=`（または `≥`）、`<`、`<=`（または `≤`）が使えます。できごとには `=` と `!=` が使えます。小数点がカンマの数字も受け付けます。

## 条件：「もし…」カット

```
if Affection >= 3 -> Park, else -> Nothing
```

条件が成り立つときの行き先と、`, else ->` のあとに、成り立たないときの行き先を書きます。どちらも省略できます。プレイヤーにはこのカットは見えません。

### 複数のケース

ケースごとに1行ずつ書きます。最初に成り立ったケースが選ばれます。

```
if Affection >= 5 -> Park
else if Affection >= 2 -> Station
else -> Nothing
```

- `else if …` はケースを追加します。`else -> …` は、どのケースも成り立たないときの行き先です。
- これらの行は、間に空行を入れずに続けて書く必要があり、最後の `else` のあとには何も続けられません。条件の続きではない `else` の行は、ふつうのテキストになります。
- 最後の `else` のあとにシーンを書かない場合、物語は次のカットに続きます。

![「もし…」は、ケース1、ケース2の順に調べ、そのあとで「それ以外」へ進みます。](/novelworks-docs/diagrams/if-order.svg)

### 1つのケースに複数のテスト

```
if Affection >= 3 and item Key -> Park
if MetMia = true or item Letter -> Library
```

すべてのテストが成り立つ必要があるときは `and`、どれか1つでよいときは `or` を使います。**1行の中で `and` と `or` を混ぜないでください。** NovelWorks は警告を出し、最初に書いた種類だけを使います。

## まだ存在しない名前

存在しないシーン、変数、アイテムには下線が引かれます。クイック修正、または「{ui.scriptMode.createMissing_other}」で作成できます。[スクリプトモード：基本](/novelworks-docs/ja/writing/script-mode/)を見てください。
