---
title: "スクリプトモードの基本"
description: シーン全体を脚本のようにテキストで書き、入力しながら更新される様子を見ます。
---

**スクリプトモード** では、ゲーム画面とタイムラインの代わりに、シーンがテキストで表示されます。起きることを 1 行に 1 つずつ、脚本のように書くと、入力に合わせてシーンが更新されます。どちらの表示も同じストーリーを編集しているので、いつでも切り替えられます。

```
Mia : Hello!
Mia (surprised) : You came back.
background : Station
? What now?
- Talk to her -> Park
- Leave
```

## スクリプトモードに切り替える

ゲーム画面の上にある「{ui.topBar.storyView}」のスイッチには、2 つのボタンがあります。「{ui.topBar.visual}」(ゲーム画面とタイムライン)と「{ui.topBar.script}」(テキストで見たシーン)です。同じスイッチがスクリプト表示にもあるので、戻れます。

![スクリプトモード: 左にテキストのシーン、右にカーソルの位置のカット。](/novelworks-docs/screenshots/script-mode.png)

## テキストに表示されるもの

スクリプトのツールバーには、「{ui.scriptMode.scope}」のスイッチがあります。

- **シーンの名前**: 選んだシーンだけです。
- 「{ui.scriptMode.wholeGame}」: ゲームのすべてのシーンが 1 つのテキストにまとまり、各シーンは `# Name` の見出しの下に置かれます。見出しからシーンの名前を変えたり、新しい見出しでシーンを追加したり、シーン間で行を移したりできます。見出しを削除したシーンは残り、ほかのシーンのあとに移されます。マップ専用の非表示のシーンは含まれません。

1 シーンだけの表示にある `# heading` は、無視され、印が付きます。

## プレビュー

右側には、**カーソルの位置のカット** が、ゲームでの見た目のまま表示されます(「カット 3 / 12」)。カーソルを動かすと、そのカットが選ばれます。ほかの場所でカットを選ぶと、カーソルがその行に移ります。上の行の続きの行は、同じカットに属します。プレビューの列は、端をドラッグして大きさを変えられます。端をダブルクリックすると元に戻ります。

プレビューの上の「{ui.branches.whereTitle}」の行には、選んだカットがどこへつながるかが、ビジュアル表示と同じように表示されます([ストーリーの分岐のしくみ](/novelworks-docs/ja/concepts/how-stories-branch/)を見てください)。ボタンで隠せます。

## 編集

- テキストは、**入力をやめて 0.5 秒後** に、プロジェクトに反映されます。範囲を切り替えたとき、プレイしたとき、スクリプトモードを離れたときにも反映されます。
- ひと続きの入力は **取り消しの 1 ステップ** です。約 1 秒の間をあけると、新しいステップになります。
- テキストを変えていないカットは、**そのまま残ります**。メモ、ストーリーマップ上の位置、読んだ行、プレイヤーのセーブも残ります。テキストでは表せないもの(自由な配置、大きさ、反転、キャラクターの順番、探索のエリアと小道具)も残り、画面が変わっていないカットは、画面もそのまま残ります。
- 別の場所(インスペクター、タイムライン、取り消し)でプロジェクトを変えると、カーソルを動かさずにテキストが更新されます。ちょうどそのとき入力している場合は、入力中のテキストが優先されます。
- まだ存在しない名前があっても、何かが止まることはありません。カットはそのまま作られ、その行に下線が引かれます。

## 入力中のヘルプ

- 行の先頭で `/` を入力すると、一覧からコマンドを選べます。キャラクター、画像、シーン、変数、アイテムの名前は、入力に合わせて候補が表示されます。`background :`、`show :`、`hide :`、`give`、`remove`、`->`、`+`、`=`、`if` のあとには、それに合う種類の名前が一覧に出ます。
- **Tab** でインデントし、**Shift+Tab** でインデントを戻します。
- キャラクターの名前は、そのキャラクターの名前の色で表示されます。
- **?** ボタン(「{ui.scriptMode.help}」)を押すと、書き方を説明する「{tx.script.help.title}」パネルが開きます。

## まだ存在しない名前

不明な名前には下線が引かれ、クイックフィックスでワンクリックで作成できます。

- ツールバーの「{ui.scriptMode.createMissing_other}」ボタンは、テキストに書かれた、まだないキャラクター、表情、シーン、変数、アイテムをすべて作成します(**Cmd+.** / **Ctrl+.**)。
- 行ごとのクイックフィックスでは、その 1 つだけを作成できます。

作成された表情には、まだ画像がありません。行で変数を比べたり、真か偽に設定したりしている場合、変数は「できごと」として作成され、そうでなければ「スコア」として作成されます。行に `x3` のような数量があれば、アイテムはまとめて持てるものになります。

## カーソルからプレイする

「{ui.scriptMode.playFromCursor}」は、カーソルのある行からゲームをプレイします(**Cmd+Enter** / **Ctrl+Enter**)。

## スクリプトモードの警告

NovelWorks が確認してほしい行には、黄色の下線が引かれます。ポインターを合わせると、理由が読めます。確認が必要な行の数は、プレビューの下に表示されます。

| メッセージ | いつ表示されるか |
|---|---|
| 「…」というキャラクターはいません | 名前がキャラクターではない `Name : text` の行です。今のところ、ナレーションとして読まれます。対処: キャラクターを作成するか、「これはナレーターです」を選びます。 |
| 「…」という表情はありません | キャラクターが持っていない表情です。対処: 作成します。 |
| 「…」という画像はありません | どの画像にも一致しない `background :` です。読み込むか、名前を確認してください。 |
| 「…」というシーンはありません | どのシーンの名前でもない `->` の行き先、選択肢、条件です。対処: 作成します。 |
| 「…」という変数 / アイテムはありません | 対処: 作成します。 |
| 選択肢の下のこの行は効果ではありません | 選択肢の下にあるインデントされた行で、`+`、`=`、`give`、`remove` ではないものです。無視されます。 |
| この条件を読み取れませんでした | 理解できない比較を含む `if` の行です。 |
| 1つの条件では「{tx.conditionCases.and}」か「または」のどちらか一方だけを使ってください | 同じ条件に両方があるとき: 最初の種類だけが使われます。 |
| この行はステージを変更しますが、後に続く行がありません | あとに行がない `background`、`show`、`hide` です。 |
| このメモに対応する行がありません | 最後にあって、そのあとに何もない `//` のメモです。 |
| 「…」はここでは画面に表示されていません | ステージにいないキャラクターへの `hide :` です。 |
| 「…」は予約語です | コマンドと同じ名前のキャラクターです。キャラクターの名前を変えるか、コマンドを角括弧で囲んで書いてください。 |
| # 見出しはゲーム全体のドキュメントでのみ使えます | 1 シーンだけの表示にある見出しです。無視されます。 |
