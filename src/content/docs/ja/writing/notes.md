## カットのメモ

**メモ**は自分だけのためのものです。アイデア、やること、リマインダーなどを書けます。各カットに1つずつ付けられます。

- カットを選び、インスペクターの「{ui.momentInspector.note}」に入力します（「{tx.momentInspector.ideasToDosReminders}」）。インスペクターには、メモは自分にしか見えず、ゲームには表示されないと書かれています。
- または、カットを右クリックして「{ui.contextMenus.addNote}」（または「{ui.contextMenus.editNote}」）を選びます。その枠に移動します。

メモのあるカットには、カードに付箋のアイコンが表示されます。ポインターを合わせるとメモを読めます。ストーリーマップには、各シーンでメモのあるカットの数が表示されます。メモは[検索と置換](/novelworks-docs/ja/writing/search/)でも見つかります。

### スクリプトモードのメモ

[スクリプトモード](/novelworks-docs/ja/writing/script-mode-lines/)では、メモは `//` で始まる行で、付けたいカットの前に置きます。

```
// check the timing of this joke
Mia : Hello!
```

あとに続く行がないメモは、警告が出ます。

## シーンのメモ

シーンにはメモはありませんが、「{ui.sceneInspector.summary}」があります。自分だけのための1〜2文で、ストーリーマップとタイムラインの上に表示され、ゲームには表示されません。[シーン](/novelworks-docs/ja/writing/scenes/)を見てください。
