title: 無料体験版
description: NovelWorks 体験版でできること、できないこと、製品版との関係を説明します。
---

**NovelWorks Demo** は無料のエディションです。エディターのすべての機能とプレイモードが使えるので、ゲームを作って最初から最後まで試せます。

## 制限：書き出したゲームは最大5シーン

体験版でも、**シーンが5つ以下**で、下の制限に収まっていれば、ゲームを書き出せます。数えられるのは、「{ui.leftPanel.scenes}」タブに並んでいるシーンです。（マップのワークスペース専用の隠しシーンは数えません。）

プロジェクトがそれを超えていると、ファイルメニューの「{ui.native.menu.exportForWeb}」が「{ui.demoExportDialog.exportYourGame}」というウインドウを開きます。どこが制限を超えているかが表示されます。シーンの数と、ほかに体験版の範囲を超えているものです。2つのボタンがあります。

- 「{ui.demoExportDialog.getTheFullVersion}」を押すと、製品版を入手できる NovelWorks のページが開きます。Steam の体験版では、このボタンは「{ui.demoLimit.wishlist}」になります。
- 「{ui.demoExportDialog.notNow}」を押すと、ウインドウが閉じます。

編集とプレイの間は、シーン、カット、画像の数に上限がありません。もっと長いゲームを書き出すには、シーンを削除するか、製品版を入手してください。

## 体験版で追加できるもの

体験版ではすべての機能を開けますが、次の数を超えて追加することはできません。

| 項目 | 体験版の上限 |
|---|---|
| キャラクター | 3 |
| キャラクターごとの衣装 | 2 |
| エフェクト | 全25種のうち10種：登場2種、退場2種、リアクション2種、画面エフェクト2種、トランジション2種 |
| パーティクル | 全5種のうち2種：雨と雪 |
| カットごとのカメラショット | 2 |
| サウンドファイル | 5 |
| 変数 | 5 |
| アイテム | 3 |

上限に達すると、ウインドウでお知らせします。「{ui.demoLimit.continue}」と製品版へのボタンがあります。何も失われません。錠前の付いたエフェクトは、エフェクトのウインドウで試すことはできますが、カットには追加できません。

すでにこの上限を超えているプロジェクト（製品版で作ったものなど）も普通に開けて、作業を続けられます。上限に収まるまで、体験版からは書き出せません。

## 体験版で書き出したゲームの表示

体験版から書き出したゲームには、次の目印が付きます。

- 起動時のスプラッシュ画面に、いつものキャッチコピーの代わりに「**Made with NovelWorks Demo**」と表示されます。
- ゲームのプレイ中、画面の隅に小さな **NovelWorks Demo** のロゴが表示されたままになります。

プロジェクトのファイル自体は変わりません。製品版から書き出したゲームには、どちらの目印も付きません。

## 体験版と製品版を一緒に使う

- 2つのエディションは**同じプロジェクト形式**を使います。体験版で作ったプロジェクトは、そのまま製品版で開けます。逆も同じです。
- 体験版は製品版と並べてインストールできるので、両方を残せます。体験版は専用の設定と専用の最近使ったプロジェクトの一覧を持ち、製品版のライセンスには一切触れません。ウインドウと「NovelWorks について」ウインドウのタイトルは **NovelWorks Demo** です。
- 制限と目印をなくすには、製品版を入手して、[インストールと認証](/novelworks-docs/ja/getting-started/install-and-activate/)をご覧ください。
