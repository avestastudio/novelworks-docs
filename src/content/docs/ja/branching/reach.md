---
title: "選択肢がたどり着ける範囲(最大 +5)"
description: スコアのテストの下に表示される文の意味と、その計算方法、わからないことについて説明します。
---

[もし…](/novelworks-docs/ja/branching/conditions/)、選択肢の条件、探索のエリアで **{ui.variables.number}** をテストすると、NovelWorks はテストの下に1行を追加します。自分で数えなくても、選択肢で合計いくつまで増やせるかがわかります。同じ文は、変数のインスペクターにも表示されます。

## 表示される文

| 表示 | 意味 |
|---|---|
| 「選択肢の合計で、Affection に最大 +5 まで加えられます。」 | スコアは初期値から始まり、選択肢では増やすことしかできず、最大でも5です。 |
| 「選択肢の合計で、Affection を 0 から 5 の間にできます。」 | 減らす選択肢もあるため、最小値と最大値があります。 |
| 「Affection を変えるものはまだありません。0 のままです。」 | このスコアを変える選択肢はありません。 |
| 「{tx.reachHint.possible}」 | 比べるために入力した数値の場合:可能な範囲に入っています。 |
| 「⚠ これは決して成り立ちません。Affection は 0 から 5 の間にとどまります。」 | テストはスコアが決して届かない値を必要としているため、そのケースは選ばれることがありません。 |

できごと(はい・いいえ)には範囲がないので、何も表示されません。

## 計算のしかた

NovelWorks は、1つの道筋ではなく**プロジェクト全体**を調べます。

- スコアは初期値から始まります。
- 「選択肢」のカットごとに、プレイヤーは1つの項目を選びます。NovelWorks は、**最良**の項目(最も多く加えられるもの)を最大値に足し、**最悪**の項目(最も多く減らすもの)を最小値に足します。
- スコアを変える探索のエリアが **{ui.explorationInspectors.onceOnly}** に設定されている場合は、1回だけ数えます。**{ui.explorationInspectors.everyTime}**(初期設定)のエリアは何度でも使えるので、その側は上限なしになります。「何も表示されないとき」を参照してください。
- **「{tx.branchInspectors.setTo}」** による変更は、わざと範囲を広くします。最小値は、初期値と設定できる値のうち小さいほう、最大値は大きいほうになります。その後に出てくる加算は、これまでどおり数えられます。

## 何も表示されないとき

話の一部が繰り返せる場合(自分自身に戻るシーン、プレイヤーが何度でも訪れられるマップの場所、または **「{ui.explorationInspectors.everyTime}」で動くすべての探索エリア(これが初期設定です)**)、合計はその側に限りなく増えることがあります。そのため、初期設定のエリアで変わるスコアには、文がまったく表示されません。NovelWorks に数えさせたいときは、エリアを「{ui.explorationInspectors.onceOnly}」に設定してください。そのとき NovelWorks はその側については何も言いません。間違ったことを言うより、何も言わないほうがよいからです。スコアを変えるものが何もないときの「…を変えるものはまだありません」という行だけは、そのまま表示されます。

## わからないこと

この文は慎重ですが、物語の流れを追っているわけではありません。

- シーンの**順番**や、プレイヤーがどの道筋を通るかは無視します。
- 条件で隠されている項目も数えます。使えるようになるかどうかがわからないからです。
- ですから「最大 +5 まで加えられます」は「5 を超えることはありません」という意味で、「どのプレイヤーも 5 に届く」という意味ではありません。

「決して成り立たない」と表示された条件は、信頼できます。「これは起こりえます」と表示された条件は、可能性が排除されていないというだけの意味です。
