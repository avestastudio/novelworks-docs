title: Web書き出し

---

**{ui.native.menu.file} → {ui.native.menu.exportForWeb}**（**Cmd+E** / **Ctrl+E**）を選びます。NovelWorks は、コンピューターでもスマートフォンでも、どのWebブラウザでも遊べるゲームを作ります。共有やアップロードにそのまま使える、**フォルダーと .zip** です。このコマンドは、プロジェクトを開いているときだけ使え、プレイ中は使えません。

**体験版**では、書き出せるのは5シーン以下のゲームに限られます。[無料体験版](/novelworks-docs/ja/getting-started/demo-edition/)を見てください。製品版では、[認証](/novelworks-docs/ja/getting-started/install-and-activate/)が済むまで、書き出すたびに認証を求められます。

## 手順

1. **警告を確認します。**NovelWorks が確認すべき点を見つけると、一覧で表示します。「先に確認が必要な点が N 件あります。ゲームはプレイできますが、プレイヤーが気づく可能性があります。」各行に場所が書かれています（「公園、カット3 — …」）。このときボタンは**{ui.exportDialog.exportAnyway}**になります。[問題](/novelworks-docs/ja/testing/problems/)を見てください。
2. **保存先を選びます。****{ui.exportDialog.saveTo}**にフォルダーが表示されます。NovelWorks は、このプロジェクトで最後に使ったフォルダーを覚えていて、なければプロジェクトを含むフォルダーを提案します。別のフォルダーを選ぶには**{ui.exportDialog.change}**を押します。
3. **{ui.exportDialog.export}**をクリックします。終わるまで、ボタンには「{tx.exportDialog.exporting}」と表示されます。
4. 「{tx.exportDialog.yourWebGameIsReady}」と表示されると、.zip の名前（共有やアップロード用。隣にあるフォルダーには、同じゲームが展開された状態で入っています）と、3つのボタンが表示されます。
   - **{ui.exportDialog.showInFinder}**: ファイルをファイルマネージャーで表示します（どのコンピューターでも、名前は「Finder」のままです）。
   - **{ui.exportDialog.testInBrowser}**: 書き出したゲームを、ローカルのアドレスで、既定のブラウザで再生します。
   - **{ui.exportDialog.done}**。

![書き出しが終わったときに表示されるウインドウ。](/novelworks-docs/screenshots/export-done.png)

プロジェクトの素材フォルダーに見つからない画像があった場合、ウインドウにその一覧が表示されます（「N 枚の画像がプロジェクトの素材フォルダーに見つからず、含められませんでした」）。書き出し自体は成功します。

ウインドウには、**推奨ゲームサイズ**（プロジェクトの解像度）と、デスクトップとモバイルのブラウザでゲームを確認するようにという案内も表示されます。

## 書き出されるもの

NovelWorks は、選んだフォルダーの中に次のものを作ります。

- ゲームの名前から付けた、末尾が `-web` のフォルダー（例: `The-Rainy-Day-web`）と、同じ名前の `.zip`。アクセント記号は取り除かれ、そのほかの文字は `-` に置き換えられます。ラテン文字も数字もないタイトル（たとえば中国語、ロシア語、日本語のタイトル）は `Game-web` になります。
- 中身は、`index.html`、`project.js`（ゲームのデータ）、`game.js`（プレイヤー）、**ゲームで使う画像だけ**を入れた `assets` フォルダー、そしてフォントとそのライセンスファイルを入れた `fonts` フォルダーです。

画像は、サイズ変更や変換をせず、そのままコピーされます。キャラクターの表情とアバターは、そのキャラクターが登場または発言するとき、すべて含まれます。

同じ名前の書き出しフォルダーがすでにあり、それが以前の書き出し結果なら、置き換えられます。ほかのものだった場合、NovelWorks は書き出しを拒否して別のフォルダーを選ぶよう求めるので、あなたのファイルが上書きされることはありません。

### 取り除かれるもの

あなた専用の執筆用データは、書き出す前に空になります。カットの**メモ**、シーンの**概要**と**執筆の状況**、ストーリーマップ上のシーンの位置、そして探索のゾーンの名前です。ストーリー、キャラクター、変数はもちろん残りますが、`project.js` の中に**そのまま読める形で**入ります。ファイルを開けば、誰でもすべてのテキストと分岐を読めます。

## 開き方

- **コンピューターで**: `index.html` をダブルクリックします。Webサーバーなしで動きます。
- **Webで**: **すべてのファイル**をアップロードし、`index.html` をルートに置きます。`project.js` がないと、ページに「{tx.player.missingProject}」と表示されます。

## プレイヤーが得るもの

- 最初に短い **NovelWorks のスプラッシュ**が表示されます。ロゴと「{tx.splash.tagline}」で、約3秒、スキップできます。（エディターでは「Made with NovelWorks」画面と呼ばれます。）
- ページのタイトルはゲームのタイトルで、ページの言語はゲームの言語です。ページのアイコンは、メインカラーの地にタイトルの最初の文字を置いたものです。
- ウィンドウに合わせて、縦横比を保ったまま拡大縮小され、周りに黒い帯が出るゲーム。コンピューターでもスマートフォンでも同じです。ブラウザが許す場合は**{rt.player.fullscreen}**ボタン、タッチ画面では**{ui.gameUIInspector.menu}**ボタンもあります。[キーとタッチ画面](/novelworks-docs/ja/player/keys-and-touch/)を見てください。
- セーブはそれぞれのブラウザに保存され、ゲームを更新しても残ります。[セーブとロード](/novelworks-docs/ja/player/save-and-load/)を見てください。
- JavaScript が必要です。ない場合、ページに「{tx.export.javascriptRequired}」と表示されます。

## 書き出しに失敗したら

| メッセージ | 対処 |
|---|---|
| NovelWorks はこのフォルダーに保存する権限がありません。 | 書類やデスクトップなど、別のフォルダーを選んでください。 |
| ディスクの空き容量がありません。 | 容量を空けるか、別のディスク上のフォルダーを選んでください。 |
| このフォルダーはすでに存在しません。 | 別のフォルダーを選んでください。 |
| 「…」という名前のフォルダーがすでにあり、以前の書き出し結果ではありません。 | 別のフォルダーを選んでください。 |
| ゲームを書き出すには NovelWorks を認証してください。 | **{ui.native.role.help} → NovelWorks を認証…**を開いてください。 |
| 体験版で書き出せるのは5シーンまでのゲームです。このプロジェクトは N シーンあります。 | 体験版のみです。シーンを削除するか、製品版を入手してください。 |
| ゲームを書き出せませんでした: … | 続けて理由が表示されます。[トラブルシューティング](/novelworks-docs/ja/reference/troubleshooting/)を見てください。 |

## 公開する

ゲームをオンラインで公開するには、[itch.io で公開する](/novelworks-docs/ja/publish/itch-io/)を見るか、HTMLゲームを配信できる任意のWebホスティングを使ってください。
