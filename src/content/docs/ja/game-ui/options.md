---
title: プレイヤーオプション
description: プレイヤーが文字サイズ、速度、フォント、コントラストを選ぶ画面と、制作者が決められることです。
---

「{ui.gameUI.options}」画面では、プレイヤーがゲームを自分に合わせて調整します。制作者が決められるのは**見た目**です。オプションの項目はどのゲームでも同じで、非表示にすることはできません。

## 変更できること

「{ui.gameUIInspector.screen}」の下:

- 「{ui.gameUIInspector.backgroundColor}」:初期設定はタイトル画面の色で、少し透けています。
- 「{ui.gameUIInspector.textColor}」:初期設定は「{tx.gameUIInspector.sameAsTheTextColor}」です。
- 「{ui.gameUIInspector.buttonStyle}」:ボタンのスタイルです。

## プレイヤーが選べること

| オプション | 選択肢 |
|---|---|
| 文字サイズ | 標準、大、特大 |
| テキスト速度 | 遅い、標準、速い、とても速い、即時 |
| オート速度 | 遅い、標準、速い |
| ディスレクシア対応フォント | オン、オフ |
| ハイコントラスト | オン、オフ |

サンプルのセリフで、文字の見え方を確認できます。**{rt.optionsScreen.defaults}**ですべてが元に戻ります。変更はすぐに反映されます。変更はゲームUIより**優先**され、そのプレイヤーにだけ適用され、ブラウザの中にゲームごとに保存されます。

プレイヤーがテキスト速度を選んでおらず、システムで視覚効果の軽減が求められている場合、テキストは即時に表示されます。

各オプションの詳細と、プレイヤーがこの画面を開く方法は、[オプションとアクセシビリティ](/novelworks-docs/ja/player/options-and-accessibility/)を参照してください。

## プレイヤーが見つける場所

タイトル画面とポーズメニューの「{rt.game.options}」ボタン、そして(表示している場合は)クイックメニューのオプションボタンです。Esc で閉じます。
