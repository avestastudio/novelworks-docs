「{ui.gameUI.pauseMenu}」は「右クリックまたは Esc で開きます」。タッチスクリーンでは、ゲームを動かす環境が開く方法を用意します。

## 変更できること

- 「{ui.gameUIInspector.buttonStyle}」:初期設定は「{tx.gameUIInspector.sameAsFontsColors}」です。
- 「{ui.gameUIInspector.panelColor}」:初期設定は「{tx.gameUIInspector.sameAsTheDialogueBox}」です。
- 「{ui.gameUIInspector.textColor}」:初期設定は「{tx.gameUIInspector.sameAsTheTextColor}」です。

## ボタン

ここでは編集できません。ゲームの言語に従います。

- 「{rt.game.resume}」。
- 「{rt.game.save}」、「{rt.game.load}」、「{rt.game.quickSave}」(F5)、「{rt.game.quickLoad}」(F9):セーブできるときだけ表示されます。「{rt.game.quickLoad}」は、クイックセーブができるまで押せません。
- インベントリのボタン([インベントリ画面](/novelworks-docs/ja/game-ui/inventory-ui/)で変更していなければ「{rt.theme.inventory}」と表示されます):インベントリ機能がオンのときに表示されます。
- 「{rt.game.history}」(H)。
- 「{rt.game.options}」。
- マップのボタン([マップボタン画面](/novelworks-docs/ja/game-ui/map-button/)で変更していなければ「{rt.theme.map}」と表示されます):そのときにマップを開けるとき(常に、またはストーリーで最初にマップが表示されたあと)に表示されます。
- 「{rt.game.backToTitle}」。

パネルのタイトルは「{tx.game.paused}」です。
