---
title: 選択肢
description: プレイヤーが選ぶボタンの見た目です。
---

「{ui.gameUI.choices}」画面では、[選択肢](/novelworks-docs/ja/branching/choices/)のボタンの見た目を設定します。プレビューには、3つのサンプル選択肢つきの質問が表示されます。

## ボタン

- 「{ui.gameUIInspector.buttonStyle}」:初期設定は「{tx.gameUIInspector.sameAsFontsColors}」です。
- 「{ui.gameUIInspector.buttonColor}」:初期設定は「{tx.gameUIInspector.sameAsTheDialogueBox}」です(ボックスの色と不透明度)。
- 「{ui.gameUIInspector.textColor}」:初期設定は「{tx.gameUIInspector.sameAsTheTextColor}」です。

選択肢の文は、ストーリーから取られます。プレイヤーは選択肢をクリックするか、その番号のキーを押します。

ロックされた選択肢([選択肢](/novelworks-docs/ja/branching/choices/)を参照)は、グレーで表示され、選べません。
