title: マップボタン

「{ui.gameUI.mapButton}」画面では、[マップ](/novelworks-docs/ja/features/map/)を開くボタンの見た目を設定します。マップ機能が必要です。機能がオフのときは、このページにその旨が表示され、機能を開くボタンが出ます。

## 変更できること

- 「{ui.gameUIInspector.label}」:ボタンとポーズメニューの項目の文字です。初期設定は「{tx.theme.map}」です。
- 「{ui.gameUIInspector.cornerOfTheScreen}」:左上(初期設定)、右上、左下、右下から選びます。
- 「{ui.gameUIInspector.buttonStyle}」:初期設定は「{tx.gameUIInspector.sameAsFontsColors}」です。

ボタンにはダイアログボックスの色が使われ、色を別に設定することはできません。

## プレイヤーが使えるもの

プレイヤーは、ポーズメニューや **M** キーからもマップを開けます。マップ上には、同じ見た目の「{rt.game.back}」ボタンがあり、元の場所に戻れます。

ボタンが表示されるタイミングは、マップの設定です(常に、またはストーリーで最初にマップが表示されたあと)。[マップ](/novelworks-docs/ja/features/map/)を参照してください。
