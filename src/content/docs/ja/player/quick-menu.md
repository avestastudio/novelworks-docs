---
title: クイックメニュー
description: ストーリーの上に表示される読み進めの操作を、プレイヤーの側から説明します。
---

クイックメニューは、ストーリーの上に表示される小さく控えめなバーです。位置、見た目、ボタンは、デザインページの[クイックメニュー](/novelworks-docs/ja/game-ui/quick-menu/)で決めます。プレイヤーは、次のボタンかキーを使えます。

| ボタン | キー |
|---|---|
| 履歴 | H |
| オート | A |
| スキップ | S |
| セーブ、ロード | |
| クイックセーブ、クイックロード | F5、F9 |
| 設定 | |
| メニュー | Esc |

- ボタンは、ポインターを重ねるまで薄く表示されます。オートとスキップは、オンの間は押された状態に見えます。
- ボタンをクリックしても、ストーリーは進みません。オートとスキップ以外のボタンを押すと、読み進めのモードはオフになります。
- バーは、タイトル画面とエンド画面、そして画面やメニューが開いている間は隠れます。**{rt.game.quickLoad}**は、クイックセーブができるまでグレーで表示されます（ポーズメニューでは、代わりに非表示になります）。ブラウザがセーブできないときは、セーブ画面とロード画面でそのことが表示されます。
- ボタンを隠しても、そのキーは使えます。スクリーンリーダーは、このグループを「{tx.quickMenu.label}」と読み上げます。
