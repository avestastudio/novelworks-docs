title: キーとタッチ画面
description: プレイヤーがゲームで使えるすべてのキー、マウス操作、タッチ操作です。
---

**Ctrl**、**Cmd**、**Alt** を押している間、ショートカットは無視されます（**Ctrl** だけを押し続けてスキップする場合を除きます）。

## キーボード

| キー | 動作 |
|---|---|
| **Space**、**Enter** | テキストを最後まで表示し、そのあと先へ進みます。フォーカスされたボタンでは、そのボタンを押します。フォーカスされたゾーンでは、そのゾーンを使います。 |
| **1**～**6** | 画面上のN番目の項目を選びます。テキストが表示されている間の最初の入力は、テキストを最後まで表示します。 |
| **Esc** | ポーズメニューを開閉します。インベントリ、履歴、オプション、セーブ/ロードを閉じます。 |
| **H** | 履歴を開閉します。 |
| **A** | オートをオン/オフします。 |
| **S** | スキップをオン/オフします。 |
| **Ctrl**（押し続ける） | 押している間、スキップします。 |
| **F5** | クイックセーブ（プレイ中）。 |
| **F9** | クイックロード（タイトル画面からでも使えます）。 |
| **I** | インベントリを開閉します（インベントリ機能を使っている場合）。 |
| **M** | マップを開きます（マップボタンが表示されている場合）。 |
| **Tab** | ボタンと探索のゾーンの間を移動します。セーブ、履歴、オプション、コンテンツに関する警告が開いている間は、その中にとどまります。 |
| 矢印キー、**Home**、**End**、**Page Up**、**Page Down** | 履歴ではスクロールします。セーブとロードでは、矢印キー、**Home**、**End** でスロット間を移動します。オプションでは、矢印キーで値を変えます。ストーリーは進みません。 |
| スロット上の `Delete` / `Backspace` | セーブを削除するか確認します。 |

ゲームには全画面表示のキーはありません。ブラウザ自身のキー（**F11**）か、ページのフルスクリーンボタンを使います。

## マウス

- ストーリー上での**左クリック**: テキストを最後まで表示する、先へ進む、選択肢を選ぶ、ゾーンを使う、のいずれかです。
- **右クリック**: ポーズメニューを開閉します（ゲーム上にブラウザのメニューは表示されません）。セーブ、ロード、履歴、オプション、質問のいずれかが開いている間は、何も起こりません。
- **ホイールを上へ**: 履歴を開きます。下へ回しても何も起こりません。
- 探索のゾーンに**ポインターを重ねる**: ハイライトとラベルが表示されます。

## タッチ画面

- **タップ**すると、クリックと同じように先へ進みます。
- **ラベルのある**探索のゾーンでは、最初のタップでラベルが表示され、2回目のタップで実行されます。ラベルがなければ、1回のタップで実行されます。
- ゲームには、スワイプ、長押し、ダブルタップはありません。右クリックに当たるタッチ操作はないため、ページがタッチ端末用に{ui.gameUIInspector.menu}ボタンを追加します。
- ドラッグすると履歴がスクロールします。

## 書き出したWebページが追加するもの

右上にある小さなボタンのグループです（触れるかポインターを重ねるまで薄く表示されます）。

- {ui.gameUIInspector.menu}（タッチ端末のみ）: ポーズメニューを開きます。右クリックも Esc もないためです。
- {rt.player.fullscreen} / {rt.player.exitFullscreen}（ブラウザが対応している場合。iPhone では表示されません）。

Webのゲームには、終了ボタンはありません。ゲームは、縦横比を保ったままウィンドウに合わせて拡大縮小され、周りに黒い帯が出ます。JavaScript が必要で、セーブを保存するにはローカルストレージを許可するブラウザが必要です。[Web書き出し](/novelworks-docs/ja/publish/web-export/)を見てください。
