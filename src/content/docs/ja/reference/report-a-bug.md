**{ui.native.role.help} → {ui.native.menu.reportABug}** を選びます。ウェブブラウザで NovelWorks のお問い合わせフォームが開きます。同じリンクは、バージョン情報のウインドウと、プロジェクト一覧画面の左側にもあります。

## 書いてほしい内容

- お使いの **NovelWorks のバージョン**：バージョン情報のウインドウと、プロジェクト一覧画面の左下に表示されています。
- 何をしていたか（手順を順番に）と、どうなると思っていたか。
- 代わりに何が起きたか。メッセージが出たときは、その文面そのまま。
- **警告**が関係しているときは、その文面（[問題一覧](/novelworks-docs/ja/testing/problems/)を参照）。
- お使いのコンピュータ：Mac か Windows か。

プロジェクトが関係しているときは、ほかの操作をする前に、そのフォルダのコピーをとっておいてください。[保存、バックアップ、取り消し](/novelworks-docs/ja/getting-started/saving-and-undo/)を参照してください。
