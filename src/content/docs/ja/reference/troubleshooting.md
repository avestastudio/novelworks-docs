## プロジェクトを開くとき

| メッセージ | 意味と対処法 |
|---|---|
| 「…」は Novelworks プロジェクトではありません。project.json ファイルがありません。 | 選んだフォルダに `project.json` がありません。プロジェクトのフォルダそのものを選んでください。 |
| project.json が破損しています。有効な JSON ではありません。 | ファイルが書き換えられたか、途中で切れています。バックアップを開いてください。`backups` の中のファイルを `project.json` に上書きコピーします（壊れたほうは別の場所に残しておきます）。 |
| このプロジェクトは、より新しいバージョンの Novelworks（形式 N）で保存されました。開くには Novelworks をアップデートしてください。 | 最新の NovelWorks をインストールしてください。何も変更されていません。 |
| アップグレード前にこのプロジェクトの安全なコピーを保存できなかったため、開きませんでした。プロジェクトは変更されていません。 | フォルダに書き込めません。フォルダのアクセス権と空き容量を確認してから、もう一度開いてください。 |
| 「{tx.projectHub.folderNotFound}」（プロジェクト一覧画面） | プロジェクトのフォルダが移動または削除されました。{ui.projectHub.locate} をクリックして、新しい場所を選んでください。 |

## 認証

| メッセージ | 対処法 |
|---|---|
| 先にダウンロードキーを貼り付けてください。 | 入力欄にキーを貼り付けます。 |
| NovelWorks が認証サーバーに接続できませんでした。インターネット接続を確認して、もう一度お試しください。 | インターネット接続を確認して、もう一度試してください。認証と、認証の無効化には、接続が必要です。 |
| NovelWorks のダウンロードキーではありません。ダウンロードページまたは購入メールからもう一度コピーしてください。 | ダウンロードページか購入メールから、もう一度コピーしてください。 |
| このキーはすでに3台のコンピュータで認証されています。別のコンピュータで NovelWorks の認証を無効化するか、お問い合わせください。 | 別のコンピュータで NovelWorks の認証を無効化するか、ウインドウの {ui.activateDialog.contactUs} を使ってください。 |
| 現在、認証できません。数分後にもう一度お試しください。 | サーバー側の一時的な問題です。 |
| 現在、認証を無効化できません。数分後にもう一度お試しください。 | 同じです。認証を無効化するときのものです。 |

## 書き出し

[ウェブ書き出し](/novelworks-docs/ja/publish/web-export/)の表を参照してください。いちばん多いのは次の場合です。別のフォルダ（書類やデスクトップ）を選ぶ、ディスクの空き容量を増やす、または NovelWorks を認証する。

## ゲームでの保存

ブラウザが保存を止めたときにプレイヤーに表示されるメッセージは、[セーブとロード](/novelworks-docs/ja/player/save-and-load/)にあります。

## ストーリーの様子がおかしいとき

- {ui.scenesTab.unreachable} と表示されたシーン、カードの三角形、または「{tx.branchInspectors.thisMomentNeedsYourAttention}」という枠：[問題一覧](/novelworks-docs/ja/testing/problems/)を参照してください。
- キャラクターが画面にいない：キャラクターは、何かが変えるまで舞台に残り、カットが指示すると去ります。[舞台](/novelworks-docs/ja/concepts/stage/)を参照してください。
- 選択肢が表示されない：条件が付いているのかもしれません。[選択肢](/novelworks-docs/ja/branching/choices/)を参照してください。
- ストーリーが「もし…」を飛ばす：条件が、削除されたものを調べています。[「もし…」の条件](/novelworks-docs/ja/branching/conditions/)を参照してください。

## まだ解決しないときは

[不具合を報告する](/novelworks-docs/ja/reference/report-a-bug/)。
