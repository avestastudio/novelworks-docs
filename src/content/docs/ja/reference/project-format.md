## プロジェクトとは

プロジェクトは**フォルダ**です。ほかのフォルダと同じように、コピーしたり、移動したり、バックアップしたりできます。

- `project.json`：ゲーム全体を 1 つにまとめたファイル（JSON 形式のテキストで、インデントは半角スペース 2 つ）。
- `assets`：読み込んだ画像。
- `backups`：`project.json` の以前のバージョン。削除した画像は `backups/deleted-assets` に入ります。

保存するたびに、NovelWorks はファイルを安全に書き込みます（一時ファイルに書いてから名前を変えます）。そのため、保存中にクラッシュしてもファイルは壊れません。

## 形式のバージョン

`project.json` には**形式のバージョン**があります。この NovelWorks が書き込む形式は**17**です。形式が変わるたびに、NovelWorks には自動アップグレードが加わったので、古いプロジェクトもすべて開けます。変更の例：

| 形式 | 追加されたもの |
|---|---|
| 2 | ダイアログボックスのオプション（9スライスの角、文字の色、全員共通の名前の色）と、スペルチェックの言語。 |
| 3, 4 | 書き手のメモ、ストーリーマップ上の位置、シーンの概要、執筆の状態。 |
| 5 | 探索カット（エリアと小道具）。 |
| 6 | アイテムと、追加できる機能。 |
| 7 | キャラクターの自由配置。 |
| 8 | マップ機能。 |
| 9 | プレイヤーのセーブ用のゲーム識別子と、セーブ画面・ロード画面の見た目。 |
| 10, 12, 13 | 履歴画面、クイックメニュー、オプション画面の見た目。 |
| 11 | 専用の空間にあるマップ。 |
| 14 | イントロの画像と、コンテンツに関する警告。 |
| 15 | キャラクターはステージに残る：カットには、変えたものだけが保存されます。 |
| 16 | 複数のケースを持つ「もし…」。 |
| 17 | 条件が成り立つときだけ表示される選択肢。 |

## 古いプロジェクトを開く

- NovelWorks がアップグレードするのは**メモリの中だけ**です。プロジェクトをエディターに渡す前に、元の `project.json` の**完全なコピー**を `backups` に保存します。名前は `project-2026-11-07_17-15-04-migration.json` のようになります。そして、コピーが元と同じであることを確かめます。
- コピーが作れないときは、プロジェクトは**開かれず**、何も変更されません。
- バーが、コピーの場所（{ui.store.showCopy} で表示）と、アップグレードを残すには保存が必要なことを知らせます。プロジェクトは未保存の扱いになります。
- 保存せずにもう一度開くと、同じコピーが再利用されます。「{tx.restoreBackupDialog.beforeUpgrade}」のコピーは、削除されることはありません。
- **{ui.native.menu.file} → バックアップから復元…** で、元の状態に戻せます。

プレイヤーのセーブデータは、そのまま読み込めます。セーブデータは、シーンとカットを、その識別情報で指しているからです。

## 新しいプロジェクトを開く

**新しい**バージョンの NovelWorks で保存されたプロジェクトは開けません。NovelWorks がそのことを知らせて、アップデートをお願いします。何も変更されません。

フォルダに `project.json` がない場合や、ファイルが壊れている場合（有効な JSON ではない場合）は、NovelWorks がそのことを知らせて、開きません。

## バックアップ

[保存、バックアップ、取り消し](/novelworks-docs/ja/getting-started/saving-and-undo/)を参照してください。手動で保存するたびにバックアップが 1 つ作られます。自動保存では 15 分に 1 つまでです。保存されるのは、新しい方から 20 個と、過去 7 日間の各日の最新の 1 つです。

## ファイルを手で編集する

`project.json` はテキストエディターで開けますが、NovelWorks でそのプロジェクトを開いている間は編集しないでください。また、先にコピーをとっておいてください。NovelWorks は、読めないファイルを推測で開くことはせず、拒否します。

## 体験版とフル版

どちらのエディションも、まったく同じ形式を使います。[無料体験版](/novelworks-docs/ja/getting-started/demo-edition/)を参照してください。
