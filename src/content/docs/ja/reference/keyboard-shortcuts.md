エディターでは、**{ui.native.role.help} → {ui.native.menu.keyboardShortcuts}**（Mac は **Cmd+/**、Windows は **Ctrl+/**）で同じ一覧が開きます。「入力中も使える」と書かれたショートカットは、テキストボックスにフォーカスがあるときも働きます。それ以外は働きません。

補足:

- **カット、コピー、貼り付け**は、ビジュアル表示で、カット、シーン（シーンタブ内）、またはゲーム画面上のキャラクターに対して使えます。[コピー、貼り付け、複製](/novelworks-docs/ja/writing/copy-paste-duplicate/)を見てください。
- 「プレイ」、**複製**、**新しいカット**、**前/次のカット**（**Cmd+[** / **Cmd+]**）、パネルのショートカットは、入力中も使えます。Delete、矢印キー、**Home**、**End** は使えません。
- パネルのショートカットはストーリーモードに切り替わりますが、ゲームUI（**Cmd+5**）とストーリーマップ（**Cmd+6**）は、それぞれのモードに切り替わります。
- プレイ中と、ウインドウ、メニュー、ポップアップが開いている間は、すべてのショートカットが無視されます。
- マップのワークスペースでは、`Delete` と **Cmd+D** は選択中の場所に対して働きます。
- スクリプト表示では、カットのコピーと貼り付けは使えません。テキストエディター自身の機能が優先されます。そこでは、**Cmd+Enter** / **Ctrl+Enter** が「{tx.scriptMode.playFromCursor}」、**Cmd+.** / **Ctrl+.** が足りないものをすべて作成します。

## ゲームで

これらは、書き出したゲームとプレイモードで使えます。

| 操作 | キー |
|---|---|
| 先へ進む（まずテキストを最後まで表示） | クリック、**Space**、**Enter** |
| 項目を選ぶ | **1**～**6**（画面上のN番目の項目） |
| ポーズメニュー | **Esc** または右クリック |
| クイックセーブ / クイックロード | **F5** / **F9** |
| 履歴 | **H** またはマウスホイールを上へ |
| オート | **A** |
| スキップ | **S**、または **Ctrl** を押し続ける |
| インベントリ | **I**（インベントリ機能） |
| マップ | **M**（マップボタンが表示されている場合） |
| ボタンとエリアの間を移動 | **Tab** |

タッチ画面を含む詳しい説明は、[キーとタッチ画面](/novelworks-docs/ja/player/keys-and-touch/)を見てください。
