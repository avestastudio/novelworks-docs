---
title: 用語集
description: NovelWorks とこのドキュメントで使われる言葉。
---

| 言葉 | 意味 |
|---|---|
| {ui.inspector.scene} | ストーリーの 1 章。順番に再生されるカットの並びです。 |
| カット | シーンの 1 ステップ。セリフ、選択肢、ジャンプ、エンディングなど。 |
| {ui.timeline.timeline} | エディタの下にある、カットのカードが並んだ列。 |
| 舞台 | ゲーム画面にあるもの。背景とキャラクターです。次のカットにも引き継がれます。 |
| 開始シーン | 新しいゲームが始まるシーン。星印が付いています。 |
| キャラクター | ストーリーに登場する人物。名前の色と表情を持ちます。 |
| 表情 | 気分（うれしい、悲しいなど）ごとのキャラクターの 1 枚の画像。星印が付いているものが初期設定です。 |
| {ui.gameUIInspector.avatar} | ダイアログボックスのキャラクター名の横に表示される、小さな肖像画。 |
| {ui.gameUIInspector.image} | プロジェクトの中の画像。背景、キャラクターの立ち絵、CG、小道具、UI の画像、アバターなど。 |
| CG | 特別な場面のための、画面いっぱいのイラスト。 |
| 小道具 | 物の画像。探索に置いたり、アイテムの画像として使ったりします。 |
| 変数 | ゲームが覚えているもの。*スコア*は数値、*できごと*は「はい」か「いいえ」です。 |
| {ui.moments.item} | プレイヤーが持ち歩くもの（インベントリ機能）。*単品*（持っているか、いないか）または*スタック可能*（複数）。 |
| {ui.moments.choice} | プレイヤーが 2〜6 個の選択肢から 1 つを選ぶカット。 |
| {ui.moments.condition} | プレイヤーには見えないカット。ゲームが覚えていることを調べて、シーンへ進みます。上から順に調べる*ケース*と、*それ以外*があります。 |
| {ui.moments.jump} | 見えないカット。すぐに別のシーンへ進みます。 |
| {ui.moments.ending} | エンディングの名前を表示して、タイトル画面に戻るカット。 |
| {ui.moments.exploration} | テキストボックスがなく、プレイヤーが画像の*ゾーン*をクリックするカット。 |
| ゾーン | 探索の中のクリックできる範囲。マップでは、ゾーンは*場所*になります。 |
| 機能 | 機能のライブラリでオンにする、ゲームの追加パーツ。インベントリとマップがあります。 |
| {ui.topBar.storyMap} | すべてのシーンと、その間のつながりを表示するビュー。 |
| {ui.topBar.gameUI} | ゲームの見た目を変えるモード。 |
| スクリプトモード | シーンを、脚本のようなテキストで表示するビュー。 |
| 通知 | ゲームの中の短いメッセージ。たとえば「入手しました:Key」など。 |
| {ui.quickMenu.title} | ストーリーの上に表示される、読み進めるための小さなバー。 |
| プレイモード | エディタの中でゲームをプレイすること。 |
| バックアップ | `project.json` の以前のコピー。`backups` フォルダに保存されます。 |
| ゲームの言語 | ゲーム自体のボタンやメニューの言語。ストーリーは、あなたが書いたままです。 |
| {ui.languageDialog.label} | エディタ自体の言語。 |
