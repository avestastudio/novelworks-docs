## ゲームはあなたのもの

NovelWorks のバージョン情報のウインドウには、こう書かれています。「{tx.aboutDialog.makeVisualNovelsWithoutCodeYourGames}」ゲームに含まれるフォントには、それぞれのオープンライセンスが適用されます（下を参照）。

## エディション

| | 体験版 | フル版 |
|---|---|---|
| エディター全体、プレイモード、スクリプトモード、ゲームUI | 使える（下の制限あり） | 使える |
| ウェブ向けの書き出し | 最大 5 シーンまで、かつ下の制限の範囲内。書き出したゲームにマークが入ります | 大きさの制限なし、マークなし |
| ダウンロードキーが必要 | いいえ | はい。書き出しに必要（itch.io のフル版）。Steam 版には不要です。 |

[無料体験版](/novelworks-docs/ja/getting-started/demo-edition/)と[インストールと認証](/novelworks-docs/ja/getting-started/install-and-activate/)を参照してください。どちらのエディションも、同じプロジェクト形式を読み書きします。

## 体験版の制限

| 体験版で | 上限 |
|---|---|
| キャラクター | 3 |
| キャラクターごとの衣装 | 2 |
| カットごとのカメラショット | 2 |
| サウンドファイル | 5 |
| 変数 | 5 |
| アイテム | 3 |
| エフェクト | 登場、退場、リアクション、画面、トランジションの各カテゴリで2つ |
| パーティクル | 雨と雪 |

これらの制限は、それ以上追加できなくするだけです。何も失われず、プロジェクトは製品版と同じようにそのまま続けられます。制限を超えているプロジェクトも体験版で開けますが、体験版からは書き出せません。

## 認証

フル版では、購入時に届くダウンロードキーが必要です。キーがなくても、プロジェクトを開いて、編集して、プレイできます。ロックされるのは書き出しだけです。認証のウインドウによると、1 つのキーは最大 3 台のコンピュータで使え、認証を無効化すると別のコンピュータに移せます。NovelWorks は起動のたびにお使いのコンピュータ上でライセンスを確認するので、インターネットがなくても書き出せます。

ライセンスの状態は、バージョン情報のウインドウで見られます（「{tx.aboutDialog.activated}{tx.aboutDialog.manage}」または「{tx.aboutDialog.notActivated}{tx.aboutDialog.activateNovelWorks}」）。

## 書き出したゲームに含まれるもの

- あなたのゲーム、画像、動画、サウンド、テキスト。
- ゲームUIのフォントと、ディスレクシアの人にも読みやすいフォント。ライセンスファイルも付いています。ゲームのフォント（Inter、Lora、Nunito、Courier Prime）とディスレクシアの人にも読みやすいフォントは、それぞれのオープンライセンスで公開されている無料のフォントです（主な 4 つのフォントは SIL Open Font License）。
- ゲームの開始時に表示される、短い「Made with NovelWorks」画面。
- 体験版で書き出したゲームには、「Made with NovelWorks Demo」の画面と、プレイ中に画面の隅に表示される小さな「NovelWorks Demo」のロゴ。

## Windows と macOS のインストーラー

Mac 版のアプリケーションには、まだ Apple Developer ID による署名がありません。[インストールと認証](/novelworks-docs/ja/getting-started/install-and-activate/)を参照してください。
