---
title: "問題: すべての警告"
description: ストーリーのおかしな点をエディターが知らせる場所と、警告の完全な一覧、そして対処のしかたです。
---

エディターは、ストーリーに未完成の部分や、決して動かない部分があると警告します。プレイヤーに見られる前に直せます。**警告があってもできることは変わりません**。プレイも書き出しもできます。ゲーム自体は、これらの問題でクラッシュしません。リンクが切れている場合は、単に「次のカットに続ける」動きになります。

## 警告が表示される場所

- タイムラインの**カットのカード**に、警告の三角が出ます。ポインターを重ねると、そのカットのすべての問題が読めます。
- カットの**インスペクター**に、「{tx.branchInspectors.thisMomentNeedsYourAttention}」というボックスで一覧が出ます。
- **シーンタブ**では、どこからも到達できないシーンに、赤い{ui.scenesTab.unreachable}のタグが付きます。
- **[ストーリーマップ](/novelworks-docs/ja/branching/story-map/)**では、シーンのカードに件数つきの警告バッジが付き、{ui.storyMap.unreachable}のタグも付きます。{ui.storyMap.problems}フィルターは、警告のあるシーンや到達できないシーンを強調します。「{tx.storyMap.gameEndsHere}」のタグは情報であり、警告ではありません。
- **マップのワークスペース**には、「マップを確認」のボックスが出ます。
- **書き出すとき**に、ゲーム全体の「先に確認が必要な点」の一覧が出ます。[Web書き出し](/novelworks-docs/ja/publish/web-export/)を見てください。
- **[スクリプトモード](/novelworks-docs/ja/writing/script-mode/)**では、行に黄色の下線が別に付きます。

トップバーに問題の数は表示されず、すべてを一覧にするパネルもありません。ゲーム全体の問題を一度に一覧にするのは、書き出しのウインドウだけです。

## どのカットでも

| 警告 | 意味と対処 |
|---|---|
| プレイヤーにはこのカットは表示されません。このシーンの前に、エンディング、ジャンプ、「{tx.moments.showMap}」カット、または「続ける」エリアのない探索があります。 | シーンを離れるカットのあとに置かれたカットです。移動するか、削除してください。 |

## 選択肢

| 警告 | 対処 |
|---|---|
| この選択肢には項目がありません。 | 項目を追加してください。 |
| 選択肢 N にはテキストがありません。 | 項目のテキストを入力してください。 |
| 選択肢 N は、削除されたシーンへ移動します。別のシーンを選ぶか「続ける」を選んでください。 | 別のシーンを選ぶか、「続ける」を選んでください。 |
| 選択肢 N は変数を変更しますが、変数が選ばれていません。/ …削除されました。 | 変数を選んでください。 |
| 選択肢 N はアイテムを使いますが、アイテムが選ばれていません。/ …削除されました。/ …ただしインベントリ機能がオフです。 | アイテムを選ぶか、機能設定でインベントリをオンにしてください。 |
| 選択肢 N は変数またはアイテムを調べますが、何も選ばれていません。/ …削除されました。/ …ただしインベントリ機能がオフです。 | 選択肢の条件を直してください。 |

## もし…

| 警告 | 対処 |
|---|---|
| この条件で調べる変数を選んでください。 | 変数を選んでください。 |
| この条件で調べるアイテムを選んでください。 | アイテムを選んでください。 |
| この条件は、削除された変数を調べています。/ 削除されたアイテムを調べています。 | 別のものを選んでください。 |
| この条件はアイテムを調べますが、インベントリ機能がオフです。 | インベントリをオンにしてください。 |
| 条件が真のときの移動先シーンを選んでください。 | シーンを選んでください。 |
| 真の場合、削除されたシーンへ移動します。/ それ以外の場合、削除されたシーンへ移動します。 | 別のシーンを選んでください。 |

条件が壊れている「もし…」は、ゲームに読み飛ばされることを覚えておいてください。[「もし…」条件](/novelworks-docs/ja/branching/conditions/)を見てください。

## ジャンプ

| 警告 | 対処 |
|---|---|
| 移動先のシーンを選んでください。 | シーンを選んでください。 |
| 削除されたシーンへ移動します。 | 別のシーンを選んでください。 |

## アイテムのカット

| 警告 | 対処 |
|---|---|
| 渡すアイテムを選んでください。/ 取り上げるアイテムを選んでください。 | アイテムを選んでください。 |
| このカットは、削除されたアイテムを渡します。/ …削除されたアイテムを取り上げます。 | 別のアイテムを選んでください。 |
| インベントリ機能がオフのため、プレイヤーはインベントリを使えません。機能設定でオンにしてください。 | インベントリをオンにしてください。 |

## 探索のカット

| 警告 | 対処 |
|---|---|
| プレイヤーがクリックするゾーンを1つ以上描いてください。 | ゾーンを描いてください。 |
| 「ゾーン」は、シーンへ移動しますが、シーンが選ばれていません。/ 削除されたシーンへ移動します。（「…アイテム使用時に、シーンへ移動しますが、シーンが選ばれていません。」もあります。） | シーンを選んでください。 |
| 「ゾーン」には、調べたときのセリフがありません。/ …アイテム使用時の… | 表示する行を入力してください。 |
| 「ゾーン」は変数またはアイテムを調べますが、何も選ばれていません。/ …削除されました。/ …ただしインベントリ機能がオフです。（そのゾーンの条件） | 条件を直してください。 |
| 「ゾーン」はアイテムを使いますが、アイテムが選ばれていません。/ …削除されました。/ …ただしインベントリ機能がオフです。 | アイテムを直してください。 |
| 「ゾーン」は、削除されたキャラクターが調べます。 | 別の話し手を選んでください。 |
| 「ゾーン」は変数を変更しますが、変数が選ばれていません。/ …削除されました。 | 変数を選んでください。 |
| 「ゾーン」には、プレイヤーが入手できないアイテムが必要です。 | どこかでアイテムを渡してください（アイテムのカット、選択肢、または拾うゾーン）。 |
| 「ゾーン」は使用できません。条件が決して真になりません。 | 変数を変える、またはアイテムを渡すものを確認してください。 |
| 画像のない小道具があります。/ 小道具が、削除されたゾーンにリンクされています。 | 画像を選ぶか、小道具を別のゾーンにリンクしてください。 |
| プレイヤーがここで進めなくなる可能性があります。クリックできるゾーンのどれも、別のシーンへ移動せず、物語も続きません。 | シーンへ移動する、または続けるゾーンを追加してください。 |

## マップ

| 警告 | 対処 |
|---|---|
| マップ機能がオフのため、このカットは何もしません。機能設定でオンにしてください。 | 機能設定でマップをオンにしてください（これは「{tx.moments.showMap}」カットの警告です）。 |
| マップでマップを作成し、背景を追加してください。/ マップのカットが削除されました。別の探索カットを選んでください。/ マップのカットは探索ではなくなりました。別のカットを選んでください。 | マップを作成するか、直してください。「{tx.moments.showMap}」カットでは、これらの末尾に「それまで、このカットは何もしません。」が付きます。 |
| マップで背景画像を追加してください。 | 背景を選んでください。 |
| プレイヤーはマップを開けません。ゲームに開始シーンがありません。 | 開始シーンを設定してください。 |
| プレイヤーはマップを開けません。マップボタンはオフ / 「{tx.moments.showMap}」カットを待っていて、「{tx.moments.showMap}」カットに到達できません。カットを追加するか、マップを常に使えるようにしてください。 | 「{tx.moments.showMap}」カットを追加するか、マップの使える条件を変えてください。 |

## ゲーム全体（書き出しウインドウ）

| 警告 | 対処 |
|---|---|
| ゲームにまだシーンがありません。プレイヤーにはタイトル画面だけが表示されます。 | シーンを追加してください。 |
| 開始シーンが設定されていません。「はじめから」を選ぶとすぐに終了します。 | 星印で開始シーンを設定してください。 |
| プレイヤーはこのシーンに到達できません。選択肢、条件、ジャンプ、エリアのいずれもこのシーンにつながっていません。（ゲームにシーンが2つ以上あるときのみ。） | リンクするか、削除してください。 |
| このシーンにはカットがありません。 | カットを追加してください。 |
| プレイヤーにはこれらのカットは表示されません。このシーンの前に、エンディング、ジャンプ、または「続ける」エリアのない探索があります。 | 移動するか、削除してください。 |

書き出しウインドウには、各カット自身の警告も、「シーン、カット4 — メッセージ」の形で一覧になります。

## マップで作れないリンク

ストーリーマップでリンクをドラッグしたとき、適用できない種類のリンクは、理由つきでグレー表示になります。理由は、シーンがエンディングで終わっている、すでにジャンプで終わっている、探索で終わっている（代わりにエリアを追加してください）、またはその選択肢がすでに6個の項目を持っている、のいずれかです。

## チェックされないもの

セリフのカットには、それ自身の警告はありません。空のセリフは警告されません。
