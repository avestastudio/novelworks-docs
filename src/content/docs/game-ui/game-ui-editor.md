---
title: Game UI editor
description: Change the look of every screen of your game.
---

Click **Game UI** in the top bar (**Cmd/Ctrl+5**). Pick a screen on the left, change it on the right, and see it live in the center.

| Screen | What it controls |
|---|---|
| **Fonts & colors** | The font and colors every screen uses |
| **Title screen** | The first screen of your game |
| **Dialogue box** | Where names and lines appear |
| **Choices** | The buttons of a choice |
| **Pause menu** | Opened with a right-click or Esc |
| **Save & load** | The Save and Load screens |
| **History** | The list of lines already read |
| **The End** | Shown when the story is over |
| **Inventory** | Its button and the panel of items (Inventory feature) |
| **Map button** | The button that opens the map (Map feature) |
| **Notices** | Short messages like "You got: Key" |

## Good to know

- Settings you leave empty **follow the global ones**.
- The dialogue box can sit at the bottom, top, left, right or center, with adjustable margins, width and height. Its background is a **color** or an **image** (**Stretch**, **Fit** or **9-slice**).
- The **name tag** can sit inside the box or as a tab above it. Name colors can follow each character or be one color.
- Button styles: **Pill**, **Rounded** or **Square**.
- **Reset** brings a screen back to its defaults.
