The **{ui.gameUI.options}** screen is where players adapt the game to themselves. You control its **look**. The options themselves are the same in every game, and you cannot hide any of them.

## What you can change

Under **{ui.gameUIInspector.screen}**:

- **{ui.gameUIInspector.backgroundColor}**: the title screen's color by default, slightly see-through;
- **{ui.gameUIInspector.textColor}**: "{tx.gameUIInspector.sameAsTheTextColor}" by default;
- **{ui.gameUIInspector.buttonStyle}**: the style of the buttons.

## What players can choose

| Option | Choices |
|---|---|
| Text size | Normal, Large, Very large |
| Text speed | Slow, Normal, Fast, Very fast, Instant |
| Auto speed | Slow, Normal, Fast |
| Dyslexia-friendly font | On, Off |
| High contrast | On, Off |

A sample line shows the text as it will look, and **Default settings** puts everything back. Changes apply at once. They apply **over** your Game UI, only for that player, and are kept for your game in their browser.

If a player has not chosen a text speed and their system asks for reduced motion, the text appears instantly.

More about each option, and how players reach this screen, in [Options and accessibility](/novelworks-docs/player/options-and-accessibility/).

## Where players find it

The **{rt.game.options}** button of the title screen, the pause menu, and the quick menu if you show its Options button. Esc closes it.
