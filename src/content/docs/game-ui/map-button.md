The **{ui.gameUI.mapButton}** screen is the look of the button that opens the [map](/novelworks-docs/features/map/). It needs the Map feature. When the feature is off, the page says so and offers to open Features.

## What you can change

- **{ui.gameUIInspector.label}**: the text of the button and of the pause-menu entry. Default "{tx.theme.map}".
- **{ui.gameUIInspector.cornerOfTheScreen}**: top left (default), top right, bottom left or bottom right.
- **{ui.gameUIInspector.buttonStyle}**: "{tx.gameUIInspector.sameAsFontsColors}" by default.

The button uses the colors of the dialogue box, and its color cannot be set separately.

## What players get

Players also open the map from the pause menu, or with the **M** key. On the map, a **{rt.game.back}** button with the same look takes them back to where they were.

When the button shows is a map setting (always, or after the story has first shown the map). See [Map](/novelworks-docs/features/map/).
