## Saving

- Press **Cmd+S** / **Ctrl+S**, or click **Save**.
- NovelWorks also **autosaves**. The top bar shows "Saved · auto" when it has.

## Backups

Every time your project is saved, the previous version goes into a `backups` folder inside your project. NovelWorks keeps the last 20, plus the newest one of each of the last 7 days.

To go back: **File → Restore from Backup…**, pick a version and restore. The current version is backed up first, so you can undo the restore too.

Pictures you delete are moved to `backups/deleted-assets`, not erased, so a backup still finds its pictures.

## Undo and redo

**Edit → Undo** (Cmd+Z / Ctrl+Z) and **Redo** work on every change in the project, including typing.

## Older projects

NovelWorks opens projects made with older versions and updates them. Because the previous version is backed up when you save, you can always go back.
