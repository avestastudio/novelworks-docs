---
title: The free demo
description: What the NovelWorks Demo can and cannot do.
---

**NovelWorks Demo** is the free edition. You get the whole editor and Play mode, so you can make a complete game and test it.

The one limit: **exporting**. In the demo, **File → Export for Web** opens a window with a button to the full version instead of exporting.

Projects made in the demo open in the full version without any change. Both editions use the same project format, and the demo installs next to the full version if you want both.
