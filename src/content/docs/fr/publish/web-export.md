---
title: "Exporter pour le web"
description: "Créer un jeu jouable dans le navigateur."
---

Ouvrez **File → Export for Web (itch.io)…** (**Cmd/Ctrl+E**), choisissez le dossier et NovelWorks crée un `.zip` prêt pour itch.io. L’édition itch.io complète doit être activée.

Les jeux exportés commencent par « **Made with NovelWorks** », pendant environ 3 secondes. Un clic, un toucher ou une touche permet de passer cet écran.

Les notes, résumés de scènes et états d’écriture ne sont pas exportés.
