---
title: "Images et ressources"
description: "Importer et organiser les images du jeu."
---

L’onglet **Assets** rassemble les images du jeu. Glissez des fichiers dans la fenêtre pour les importer.

Chaque image appartient à une **catégorie** :

| Catégorie | Usage |
|---|---|
| **Background** | Décor derrière les personnages |
| **Sprite** | Image d’un personnage |
| **CG** | Illustration d’événement en plein écran, utilisée comme un décor |
| **Prop** | Objet placé dans un moment d’exploration |
| **UI** | Image d’interface : boîte de dialogue, logo, boutons |
| **Avatar** | Petit portrait à côté du nom du personnage qui parle |

Les filtres en haut de l’onglet permettent de n’afficher qu’une catégorie.

Les images sont copiées dans le dossier `assets` du projet. Une image supprimée est déplacée vers les sauvegardes pour permettre un retour en arrière.
