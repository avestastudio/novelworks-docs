---
title: "Importer un script"
description: "Transformer un texte en scènes, répliques et personnages."
---

Votre histoire existe déjà dans un fichier texte ? Ouvrez **File → Import Script…**.

## Format

```
# Matin de printemps
Mia: Bonjour !
Il pleuvait.
Aoi: Hé… ça va ?
```

- Une ligne commençant par **#** crée une scène.
- **Nom: texte** crée une réplique de ce personnage.
- Sans nom, la ligne est attribuée au **Narrator**.
- Les lignes vides sont ignorées.

## Étapes

1. Collez le script à gauche. **Preview** affiche les scènes, répliques et nouveaux personnages à créer.
2. Décochez les noms qui ne doivent pas devenir des personnages : ils restent dans le texte du narrateur.
3. Choisissez où placer les répliques, puis importez.

En cas d’erreur, **Undo** annule l’importation.
