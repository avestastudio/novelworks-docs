Ouvrez **Characters** pour ajouter et modifier les personnages.

## Les propriétés d’un personnage

- **Name** : nom affiché dans l’étiquette de dialogue.
- **Name color** : choisissez une couleur prédéfinie ou personnalisée.
- **Expressions** : chaque expression possède un nom et une image, par exemple « Joyeux ». L’étoile indique l’expression par défaut, utilisée à l’ajout sur scène.
- **Avatar** : petit portrait près du nom. **None** le masque ; **Fixed** utilise une image ; **Per expression** associe un portrait à chaque expression, avec repli sur l’avatar par défaut.

## Sur scène

Utilisez **+ Character** au-dessus de l’écran, puis choisissez une expression. Voir [Moments et dialogues](/novelworks-docs/fr/writing/moments-and-dialogue/).

## Clic droit

Un clic droit permet de renommer ou dupliquer le personnage, ou de voir où il est utilisé.
