## Notes sur les moments

Une **note** est pour vous seul : idées, choses à faire, rappels. Chaque moment peut en avoir une.

- Sélectionnez le moment et tapez dans **{ui.momentInspector.note}** dans l’inspecteur (« Idées, choses à faire, rappels… »). L’inspecteur précise que vous seul voyez vos notes : elles ne sont jamais affichées dans le jeu.
- Ou faites un clic droit sur le moment et choisissez **{ui.contextMenus.addNote}** (ou **{ui.contextMenus.editNote}**), ce qui vous amène à cette zone.

Un moment qui a une note affiche une icône de pense-bête sur sa carte ; pointez-la pour lire la note. La carte de l’histoire indique combien de moments de chaque scène ont une note. Les notes sont trouvées par [Rechercher et remplacer](/novelworks-docs/fr/writing/search/).

### Notes en mode Script

En [mode Script](/novelworks-docs/fr/writing/script-mode-lines/), une note est une ligne qui commence par `//`, placée avant le moment auquel elle appartient :

```
// check the timing of this joke
Mia : Hello!
```

Une note sans ligne après elle est signalée.

## Notes sur les scènes

Il n’y a pas de note sur une scène, mais une scène a un **{ui.sceneInspector.summary}** : une phrase ou deux pour vous seul, affichées sur la carte de l’histoire et au-dessus de la chronologie, jamais dans le jeu. Voir [Scènes](/novelworks-docs/fr/writing/scenes/).
