## Pour commencer

**Dois-je savoir programmer ?** Non. NovelWorks est conçu pour les personnes qui ne programment pas : vous construisez le jeu tel qu’il apparaît, et vous appuyez sur Jouer.

**À qui appartiennent mes jeux ?** À vous : « Vos jeux vous appartiennent, sans redevances », dit la fenêtre À propos. Les polices gratuites incluses dans vos jeux gardent leurs propres licences ouvertes.

**Quelles langues parle l’éditeur ?** L’anglais, le français, l’espagnol, le portugais brésilien, le chinois simplifié, le russe et le japonais. Changez-la dans **Affichage → Langue**. Votre histoire reste dans la langue où vous l’écrivez.

**Puis-je utiliser la démo pour faire un jeu complet ?** Oui, vous pouvez tout construire et tout jouer. L’export est limité aux jeux de 5 scènes ou moins. Voir [La démo gratuite](/novelworks-docs/fr/getting-started/demo-edition/).

## Votre travail

**Où est mon projet ?** Dans le dossier que vous avez choisi en le créant. Les réglages du projet l’indiquent sous « Enregistré dans ». Pour copier un projet, copiez le dossier entier.

**J’ai perdu une modification.** Essayez **{ui.topBar.undo}** (jusqu’à 200 étapes), puis **Fichier → Restaurer depuis une sauvegarde de secours…**. Voir [Enregistrement, sauvegardes et annulation](/novelworks-docs/fr/getting-started/saving-and-undo/).

**J’ai supprimé une image, une scène ou une variable par erreur.** Appuyez sur **{ui.topBar.undo}**. Une image supprimée est conservée dans `backups/deleted-assets` et revient avec Annuler. La suppression d’une scène ou d’une variable peut être annulée, et en attendant les endroits qui l’utilisaient affichent des avertissements.

**Puis-je déplacer mon projet vers un autre ordinateur ?** Oui : copiez son dossier, puis ouvrez-le avec **Fichier → Ouvrir un projet…**.

## Écriture

**Pourquoi un personnage est-il encore à l’écran au moment suivant ?** Les personnages restent en scène jusqu’à ce que vous les changiez. Voir [La scène de jeu](/novelworks-docs/fr/concepts/stage/).

**Comment faire en sorte qu’un choix compte ?** Faites retenir quelque chose au jeu dans une option, puis utilisez un Si… ou une condition sur une option. Voir [Comment une histoire se ramifie](/novelworks-docs/fr/concepts/how-stories-branch/).

**Puis-je écrire toute mon histoire sous forme de texte ?** Oui : le [mode Script](/novelworks-docs/fr/writing/script-mode/), et [Importer et exporter un script](/novelworks-docs/fr/writing/import-a-script/).

**Puis-je utiliser ma propre police ?** Pas encore. Vous pouvez choisir l’une des quatre polices. Voir [Polices et couleurs](/novelworks-docs/fr/game-ui/fonts-and-colors/).

## Tester et publier

**Comment tester à partir du milieu ?** Sélectionnez un moment et utilisez **{ui.leftPanel.playFromHere}**. Voir [Jouer, Jouer à partir d’ici, Essayer la carte](/novelworks-docs/fr/testing/play/).

**Que signifient les avertissements ?** Voir [Problèmes : tous les avertissements](/novelworks-docs/fr/testing/problems/). Un avertissement ne vous empêche jamais de jouer ou d’exporter.

**Les joueurs doivent-ils installer quelque chose ?** Non. Un export web se joue dans n’importe quel navigateur, sur ordinateur comme sur téléphone. Voir [Export web](/novelworks-docs/fr/publish/web-export/).

**Où vont les sauvegardes des joueurs ?** Dans leur navigateur, pour votre jeu. Elles sont conservées quand vous mettez le jeu à jour. Voir [Enregistrer et charger](/novelworks-docs/fr/player/save-and-load/).

## Problèmes

**L’export est verrouillé.** Dans la version complète, activez NovelWorks : **Aide → Activer NovelWorks…**. Voir [Dépannage](/novelworks-docs/fr/reference/troubleshooting/).

**Autre chose ne va pas.** Voir [Dépannage et messages](/novelworks-docs/fr/reference/troubleshooting/), ou [signalez un bogue](/novelworks-docs/fr/reference/report-a-bug/).
