---
title: "Questions fréquentes"
description: "Les réponses essentielles."
---

**Faut-il savoir programmer ?** Non. NovelWorks est conçu pour les personnes qui ne programment pas.

**À qui appartiennent mes jeux ?** Entièrement à vous, sans redevance.

**Où est mon projet ?** Dans le dossier choisi à sa création. Cliquez sur le nom du projet : le chemin apparaît sous **Saved in**.

**Puis-je créer un jeu complet avec la démo ?** Oui. Seul l’export nécessite la version complète.

**J’ai perdu une modification.** Essayez **Undo**, puis **File → Restore from Backup…**.
