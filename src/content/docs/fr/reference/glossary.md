---
title: Glossaire
description: Les mots utilisés dans NovelWorks et dans cette documentation.
---

| Mot | Signification |
|---|---|
| {ui.inspector.scene} | Un chapitre de votre histoire : une suite de moments joués les uns après les autres. |
| Moment | Une étape d’une scène : une réplique de dialogue, un choix, un saut, une fin… |
| {ui.timeline.timeline} | La rangée de cartes de moments en bas de l’éditeur. |
| Plateau | Ce qui se trouve sur l’écran du jeu : le décor et les personnages. Cela se poursuit d’un moment au suivant. |
| Scène de départ | La scène où commence une nouvelle partie, marquée d’une étoile. |
| Personnage | Une personne de votre histoire, avec une couleur de nom et des expressions. |
| Expression | Une image d’un personnage pour une humeur (joyeux, triste…). Celle qui porte une étoile est celle par défaut. |
| {ui.gameUIInspector.avatar} | Un petit portrait affiché à côté du nom du personnage dans la boîte de dialogue. |
| {ui.gameUIInspector.image} | Une image de votre projet : un décor, un sprite de personnage, une illustration (CG), un accessoire, une image de l’interface ou un avatar. |
| CG | Une illustration en plein écran pour un événement spécial. |
| Accessoire | Une image d’objet, placée sur une exploration ou utilisée comme image d’objet. |
| Variable | Quelque chose dont le jeu se souvient. Un *Score* est un nombre ; un *Fait* est oui ou non. |
| {ui.moments.item} | Quelque chose que le joueur porte (fonctionnalité Inventaire). *Unique* (on l’a ou non) ou *Cumulable* (plusieurs). |
| {ui.moments.choice} | Un moment où le joueur choisit une option parmi 2 à 6. |
| {ui.moments.condition} | Un moment, invisible pour les joueurs, qui vérifie ce dont le jeu se souvient et va vers une scène. Il a des *cas*, vérifiés de haut en bas, et un *sinon*. |
| {ui.moments.jump} | Un moment invisible qui va directement vers une autre scène. |
| {ui.moments.ending} | Un moment qui affiche le nom de la fin et retourne à l’écran-titre. |
| {ui.moments.exploration} | Un moment sans boîte de texte où le joueur clique sur des *zones* d’une image. |
| Zone | Une région cliquable d’une exploration. Sur la carte, une zone est un *lieu*. |
| Fonctionnalité | Une partie facultative de votre jeu que vous activez dans la bibliothèque des fonctionnalités : Inventaire ou Carte. |
| {ui.topBar.storyMap} | La vue de toutes les scènes et des liens entre elles. |
| {ui.topBar.gameUI} | Le mode où vous changez l’apparence du jeu. |
| Mode Script | La vue d’une scène sous forme de texte, comme un scénario. |
| Notification | Un court message dans le jeu, comme « Vous avez obtenu : Clé ». |
| {ui.quickMenu.title} | La petite barre de commandes de lecture au-dessus de l’histoire. |
| Mode Jeu | Jouer à votre jeu dans l’éditeur. |
| Sauvegarde de secours | Une copie antérieure de `project.json`, conservée dans le dossier `backups`. |
| Langue du jeu | La langue des boutons et des menus du jeu lui-même. Votre histoire reste comme vous l’avez écrite. |
| {ui.languageDialog.label} | La langue de l’éditeur lui-même. |
