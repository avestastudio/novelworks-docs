title: Tous les menus
description: Chaque élément des menus de l’application, avec son raccourci.
---

NovelWorks utilise les menus natifs de votre ordinateur. **Cmd** correspond à **Ctrl** sous Windows. Certains éléments demandent un projet ouvert, et la plupart des commandes d’édition sont ignorées pendant que vous jouez.

## Menu de l’application (Mac uniquement)

**À propos de Novelworks**, Services, **Masquer Novelworks** (**Cmd+H**), **{ui.native.role.hideOthers}**, **{ui.native.role.unhide}**, **Quitter Novelworks** (**Cmd+Q**). Sous Windows, Quitter se trouve à la fin du menu Fichier, et À propos se trouve dans le menu Aide.

## Fichier

| Élément | Raccourci | Ce qu’il fait |
|---|---|---|
| {ui.native.menu.newProject} | **Cmd+N** | Ouvre l’écran de nouveau projet. |
| {ui.native.menu.openProject} | **Cmd+O** | Ouvre un dossier de projet. |
| {ui.native.menu.save} | **Cmd+S** | Enregistre le projet. |
| {ui.native.menu.restoreFromBackup} | | Revient à une version antérieure. Voir [Enregistrement, sauvegardes et annulation](/novelworks-docs/fr/getting-started/saving-and-undo/). |
| {ui.native.menu.importScript} | | Ajoute un fichier texte à vos scènes. Voir [Importer et exporter un script](/novelworks-docs/fr/writing/import-a-script/). |
| {ui.native.menu.exportScript} | | Enregistre tout votre jeu dans un fichier texte. |
| {ui.native.menu.exportForWeb} | **Cmd+E** | Exporte votre jeu pour le web. Voir [Export web](/novelworks-docs/fr/publish/web-export/). |
| {ui.native.menu.closeProject} | **Cmd+Shift+W** | Revient à l’écran des projets. |

## Édition

| Élément | Raccourci |
|---|---|
| {ui.native.menu.undo} | **Cmd+Z** |
| {ui.native.menu.redo} | **Shift+Cmd+Z** (Windows : **Ctrl+Shift+Z**, et **Ctrl+Y** dans l’éditeur) |
| {ui.native.menu.findAndReplace} | **Cmd+F** |
| Couper, Copier, Coller, Tout sélectionner | **Cmd+X**, **Cmd+C**, **Cmd+V**, **Cmd+A** |
| {ui.native.spelling.spellingLanguage} | Sous Windows : les langues de votre ordinateur, plus l’anglais, ou une autre langue. Sur Mac, macOS détecte la langue de votre texte. Enregistrée dans le projet. |

Annuler et Rétablir agissent sur le projet, sauf dans le champ du nom de l’écran de nouveau projet.

## Affichage

- **{ui.native.menu.theme}** : {ui.native.menu.dark}, {ui.native.menu.light} ou {ui.native.menu.system}.
- **{ui.native.menu.language}** : {ui.native.menu.languageAuto} ou l’une des sept langues.
- **{ui.native.role.togglefullscreen}** (**Control+Cmd+F** sur Mac).

Les éléments pour développeurs (Recharger, Afficher les outils de développement) n’apparaissent que dans les versions de développement, pas dans l’application publiée.

## Fenêtre

Réduire, Zoom et Tout ramener au premier plan sur Mac ; Réduire et Fermer sous Windows.

## Aide

| Élément | Ce qu’il fait |
|---|---|
| {ui.menu.documentation} | Ouvre cette documentation dans votre navigateur. |
| {ui.native.menu.replayTutorial} | Relance la [visite guidée](/novelworks-docs/fr/getting-started/guided-tour/). |
| {ui.native.menu.keyboardShortcuts} (**Cmd+/**) | Affiche la liste des raccourcis. |
| {ui.native.menu.activateNovelWorks} | Dans la version complète d’itch.io uniquement. Voir [Installer et activer](/novelworks-docs/fr/getting-started/install-and-activate/). |
| {ui.native.menu.reportABug} | Ouvre le formulaire de contact. Voir [Signaler un bogue](/novelworks-docs/fr/reference/report-a-bug/). |
| À propos de Novelworks | Sous Windows uniquement : la fenêtre À propos. |

## Menus de l’écran des projets

Sur l’écran des projets, seules les commandes de menu nouveau projet, ouvrir un projet, À propos, raccourcis, et Annuler/Rétablir (pour le champ du nom) font quelque chose.
