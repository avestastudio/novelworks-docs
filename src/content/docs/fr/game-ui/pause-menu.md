---
title: Menu pause
description: Le menu que les joueurs ouvrent pendant le jeu, avec un clic droit ou Échap.
---

Le **{ui.gameUI.pauseMenu}** « s’ouvre par un clic droit ou Échap ». Sur un écran tactile, l’hôte du jeu fournit un moyen de l’ouvrir.

## Ce que vous pouvez changer

- **{ui.gameUIInspector.buttonStyle}** : « {tx.gameUIInspector.sameAsFontsColors} » par défaut.
- **{ui.gameUIInspector.panelColor}** : « {tx.gameUIInspector.sameAsTheDialogueBox} » par défaut.
- **{ui.gameUIInspector.textColor}** : « {tx.gameUIInspector.sameAsTheTextColor} » par défaut.

## Les boutons

Ils ne se modifient pas ici, et ils suivent la langue du jeu :

- **{rt.game.resume}** ;
- **{rt.game.save}**, **{rt.game.load}**, **{rt.game.quickSave}** (F5) et **{rt.game.quickLoad}** (F9) : seulement quand la sauvegarde est disponible. **{rt.game.quickLoad}** attend aussi qu’une sauvegarde rapide existe ;
- le bouton Inventaire (intitulé « {rt.theme.inventory} » sauf si vous l’avez changé sur l’[écran de l’inventaire](/novelworks-docs/fr/game-ui/inventory-ui/)), quand la fonctionnalité Inventaire est activée ;
- **{rt.game.history}** (H) ;
- **{rt.game.options}** ;
- le bouton Carte (intitulé « {rt.theme.map} » sauf si vous l’avez changé sur l’[écran du bouton de la carte](/novelworks-docs/fr/game-ui/map-button/)), quand la carte peut être ouverte à ce moment-là (toujours, ou après que l’histoire l’a montrée une première fois) ;
- **{rt.game.backToTitle}**.

Le titre du panneau est « {tx.game.paused} ».
