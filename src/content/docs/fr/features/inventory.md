Activez **Inventory** dans [Features](/novelworks-docs/fr/features/features-panel/) pour faire apparaître **Items**.

## Créer un objet

Un objet possède un nom, une description, une image de catégorie **Prop** et un **Kind** : **Single** pour une possession oui/non, ou **Stackable** pour une quantité.

## Utiliser les objets

- Moment **Item** : donner ou retirer un objet, avec notification facultative (« You got: Key »).
- **Choices** : les effets donnent ou retirent des objets.
- **Conditions** : vérifier la possession, l’absence ou une quantité minimale.
- **Zones** : ramasser ou utiliser un objet.

Les joueurs ouvrent **Inventory** avec son bouton ou **I**. Son apparence se règle dans [Game UI](/novelworks-docs/fr/game-ui/game-ui-editor/).
