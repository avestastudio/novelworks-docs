Activez **Map** dans [Features](/novelworks-docs/fr/features/features-panel/), puis cliquez sur **Edit map** pour ouvrir son espace de travail.

## Construire la carte

1. Ajoutez une image de fond.
2. Cliquez sur **Add location** et dessinez une zone.
3. Nommez le lieu, par exemple « Café ». Le nom apparaît au survol par défaut.
4. Choisissez la scène à lancer au clic. Vous pouvez créer une scène depuis ce champ.
5. Essayez la carte avec **Test map**.

## Disponibilité

Dans les paramètres, choisissez quand les joueurs peuvent utiliser le bouton de carte :

- **From the start** : le bouton Map est disponible dès le début.
- **After first shown** : le bouton apparaît après le premier moment **Show map** de l’histoire.
- **Story only** : aucun bouton Map n’est affiché ; seuls les moments **Show map** ouvrent la carte.

## Moments Show map

Un moment **Show map** ouvre immédiatement la carte et demande de choisir une destination. Une carte ouverte avec le bouton **Map** peut être fermée pour reprendre la lecture.

## Lieux verrouillés

Une condition peut masquer ou verrouiller un lieu. Un lieu verrouillé peut afficher un message.
