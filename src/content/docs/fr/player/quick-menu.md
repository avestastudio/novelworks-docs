---
title: Menu rapide
description: Les commandes de lecture affichées par-dessus l’histoire, du point de vue du joueur.
---

Le menu rapide est une petite barre discrète placée par-dessus l’histoire. Vous choisissez son emplacement, son aspect et ses boutons dans la page de design [Menu rapide](/novelworks-docs/fr/game-ui/quick-menu/). Les joueurs peuvent utiliser n’importe lequel de ces boutons, ou les touches :

| Bouton | Touche |
|---|---|
| Historique | H |
| Auto | A |
| Passer | S |
| Enregistrer, Charger | |
| Sauvegarde rapide, Chargement rapide | F5, F9 |
| Options | |
| Menu | Esc |

- Les boutons sont estompés tant que le pointeur n’est pas dessus. Auto et Passer ont l’air enfoncés quand ils sont activés.
- Cliquer sur un bouton ne fait pas avancer l’histoire. Appuyer sur un bouton autre qu’Auto ou Passer désactive le mode de lecture.
- La barre est masquée sur l’écran-titre et sur l’écran de fin, et pendant qu’un écran ou un menu est ouvert. **{rt.game.quickLoad}** est grisé tant qu’aucune sauvegarde rapide n’existe (dans le menu pause, il est masqué à la place). Si le navigateur ne peut pas enregistrer, les écrans Enregistrer et Charger le disent.
- Masquer un bouton conserve sa touche. Les lecteurs d’écran annoncent le groupe sous le nom « Commandes de lecture ».
