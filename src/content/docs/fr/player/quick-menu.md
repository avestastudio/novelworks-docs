---
title: Menu rapide
description: Les commandes de lecture affichées par-dessus l’histoire, du côté du joueur.
---

Le menu rapide est une petite barre discrète par-dessus l’histoire. Vous choisissez son emplacement, son apparence et ses boutons dans la page de design [Menu rapide](/novelworks-docs/fr/game-ui/quick-menu/). Les joueurs peuvent utiliser n’importe lequel de ces boutons, ou les touches :

| Bouton | Touche |
|---|---|
| Historique | H |
| Auto | A |
| Passer | S |
| Sauvegarder, Charger | |
| Sauvegarde rapide, Chargement rapide | F5, F9 |
| Options | |
| Menu | Échap |

- Les boutons sont estompés tant que le pointeur n’est pas dessus. Auto et Passer ont l’air enfoncés quand ils sont activés.
- Cliquer sur un bouton ne fait pas avancer l’histoire. Appuyer sur un bouton autre qu’Auto ou Passer désactive le mode de lecture.
- La barre est masquée sur l’écran-titre et l’écran de fin, et tant qu’un écran ou un menu est ouvert. **{rt.game.quickLoad}** est grisé tant qu’il n’existe pas de sauvegarde rapide (dans le menu pause, il est masqué à la place). Si le navigateur ne peut pas enregistrer, les écrans Sauvegarder et Charger le disent.
- Masquer un bouton ne supprime pas sa touche. Les lecteurs d’écran annoncent le groupe sous le nom « {tx.quickMenu.label} ».
