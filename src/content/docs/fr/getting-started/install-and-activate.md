## Quel fichier télécharger ?

| Ordinateur | Fichier |
|---|---|
| Mac Apple Silicon (M1, M2, M3, M4…) | `Novelworks-<version>-mac-arm64.dmg` |
| Mac Intel | `Novelworks-<version>-mac-x64.dmg` |
| Windows 10 / 11 | `Novelworks-<version>-win-x64.exe` |

Pour identifier votre Mac, ouvrez le menu Apple → **À propos de ce Mac**. Une puce « Apple M… » indique un Mac Apple Silicon.

## Première ouverture

NovelWorks n’est pas encore signé avec un certificat payant Apple ou Microsoft : un avertissement peut donc apparaître à la première ouverture.

### Sur Mac

1. Ouvrez le `.dmg` et glissez **Novelworks** dans **Applications**.
2. Lancez l’application depuis Applications. Si macOS indique ne pas pouvoir la vérifier, cliquez sur **Terminé**.
3. Sur macOS 15 Sequoia et les versions suivantes, ouvrez **Réglages Système → Confidentialité et sécurité**, trouvez le message concernant Novelworks et cliquez sur **Ouvrir quand même**. Sur les anciennes versions, faites un clic droit sur l’application dans Applications, puis choisissez **Ouvrir**.

### Sur Windows

1. Lancez le `.exe`.
2. Si l’écran bleu **Windows a protégé votre ordinateur** apparaît, cliquez sur **Informations complémentaires**, puis **Exécuter quand même**.
3. Suivez les étapes de l’installation.

## Activer la version complète

La version complète demande la **clé de téléchargement** de votre achat itch.io. Sans activation, vous pouvez ouvrir, modifier et tester vos projets, mais **File → Export for Web** reste verrouillé.

1. Ouvrez **Help → Activate NovelWorks…**, également accessible depuis l’accueil et **About**.
2. Collez la clé de téléchargement de votre achat itch.io.
3. Cliquez sur **Activate**.

À savoir :

- Une clé fonctionne sur **3 ordinateurs** au maximum.
- Une fois activée, l’application fonctionne **hors ligne**.
- Pour libérer un ordinateur, notamment avant de le vendre, cliquez sur **Deactivate this device** dans la même fenêtre.
- Si vous atteignez la limite, utilisez **Contact us**.
