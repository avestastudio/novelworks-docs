---
title: Glossary
description: The words used in NovelWorks and in this documentation.
---

| Word | Meaning |
|---|---|
| {ui.inspector.scene} | A part of your story: a series of moments played one after another. |
| Moment | One step of a scene: a line of dialogue, a choice, a jump, an ending… |
| {ui.timeline.timeline} | The row of moment cards at the bottom of the editor. |
| Stage | What is on the game screen: the background and the characters. It carries over from one moment to the next. |
| Start scene | The scene where a new game begins, marked with a star. |
| Character | A person in your story, with a name color and expressions. |
| Expression | One picture of a character for a mood (happy, sad…). The one with a star is the default. |
| {ui.stageControls.outfit} | A set of wardrobe pieces a character wears. It stays until you change it. |
| {ui.gameUIInspector.avatar} | A small portrait shown next to the character's name in the dialogue box. |
| {ui.gameUIInspector.image} | A picture in your project: a background, a character sprite, a CG, a prop, a UI picture, an avatar or a clothing piece. |
| CG | A full-screen illustration for a special event. |
| Prop | A picture of an object, placed on an exploration or used as an item picture. |
| {ui.ambience.title} | A color mood over the picture, such as Night or Sepia. It stays from one moment to the next. |
| {ui.camera.title} | What part of the stage the player sees, and how it moves. A moment can have several *shots*, up to 6. |
| {ui.effects.title} | A short animation of a character or of the whole screen, such as a shake, or a transition. They play once, at the start of a moment. |
| {ui.effects.category.particles} | Rain, snow, petals and the like. They stay from one moment to the next until you stop them. |
| {ui.sound.ambience} | A sound that loops under the story, such as rain. |
| Rich text | Bold, italic, colors, sizes, shaking or waving letters, pauses and variables inside a line of dialogue. |
| Variable | Something the game remembers. A *Score* is a number; a *Fact* is yes or no. |
| {ui.moments.item} | Something the player carries (Inventory feature). *Single* (have it or not) or *Stackable* (several). |
| {ui.moments.choice} | A moment where the player picks one option out of 2 to 6. |
| {ui.moments.condition} | A moment, invisible to players, that checks what the game remembers and goes to a scene. It has *cases*, checked from top to bottom, and an *otherwise*. |
| {ui.moments.jump} | An invisible moment that goes straight to another scene. |
| {ui.moments.ending} | A moment that shows the ending's name and returns to the title screen. |
| {ui.moments.exploration} | A moment with no text box where the player clicks *zones* on a picture. |
| Zone | A clickable area of an exploration. On the map, a zone is a *location*. |
| Feature | An optional part of your game you turn on in the Features library: Inventory or Map. |
| {ui.topBar.storyMap} | The view of all scenes and the links between them. |
| {ui.topBar.gameUI} | The mode where you change how the game looks. |
| Script mode | The view of a scene as text, like a screenplay. |
| {ui.gameUI.credits} | The rolling list of who made the game. |
| {ui.gameUI.chapters} | Scenes marked as starts of chapters, which players can replay from the title screen. |
| {ui.templates.heading} | Ready-made looks for the title screen and ready-made places for the dialogue box. |
| Notice | A short message in the game, such as "You got: Key". |
| {ui.quickMenu.title} | The small bar of reading controls over the story. |
| Play mode | Playing your game inside the editor. |
| Backup | An earlier copy of `project.json`, kept in the `backups` folder. |
| Game language | The language of the game's own buttons and menus. Your story stays as you wrote it. |
| {ui.languageDialog.label} | The language of the editor itself. |
