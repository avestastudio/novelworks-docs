NovelWorks uses the native menus of your computer. **Cmd** is **Ctrl** on Windows. Some items need an open project, and most editing commands are ignored while you play.

## Application menu (Mac only)

**About Novelworks**, Services, **Hide Novelworks** (**Cmd+H**), **{ui.native.role.hideOthers}**, **{ui.native.role.unhide}**, **Quit Novelworks** (**Cmd+Q**). On Windows, Quit is at the end of the File menu, and About is in the Help menu.

## File

| Item | Shortcut | What it does |
|---|---|---|
| {ui.native.menu.newProject} | **Cmd+N** | Opens the new project screen. |
| {ui.native.menu.openProject} | **Cmd+O** | Opens a project folder. |
| {ui.native.menu.save} | **Cmd+S** | Saves the project. |
| {ui.native.menu.restoreFromBackup} | | Goes back to an earlier version. See [Saving, backups and undo](/novelworks-docs/getting-started/saving-and-undo/). |
| {ui.native.menu.importScript} | | Adds a text file to your scenes. See [Import and export a script](/novelworks-docs/writing/import-a-script/). |
| {ui.native.menu.exportScript} | | Saves your whole game as a text file. |
| {ui.native.menu.exportForWeb} | **Cmd+E** | Exports your game for the web. See [Web export](/novelworks-docs/publish/web-export/). |
| {ui.native.menu.closeProject} | **Cmd+Shift+W** | Goes back to the projects screen. |

## Edit

| Item | Shortcut |
|---|---|
| {ui.native.menu.undo} | **Cmd+Z** |
| {ui.native.menu.redo} | **Shift+Cmd+Z** (Windows: **Ctrl+Shift+Z**, and **Ctrl+Y** in the editor) |
| {ui.native.menu.findAndReplace} | **Cmd+F** |
| Cut, Copy, Paste, Select All | **Cmd+X**, **Cmd+C**, **Cmd+V**, **Cmd+A** |
| {ui.native.spelling.spellingLanguage} | On Windows: your computer's languages plus English, or another language. On a Mac, macOS detects the language of your text. Saved in the project. |

Undo and Redo work on the project, except in the name field of the new project screen.

## View

- **{ui.native.menu.theme}**: {ui.native.menu.dark}, {ui.native.menu.light} or {ui.native.menu.system}.
- **{ui.native.menu.language}**: {ui.native.menu.languageAuto} or one of the seven languages.
- **{ui.native.role.togglefullscreen}** (**Control+Cmd+F** on a Mac).

Developer items (Reload, Toggle Developer Tools) only appear in development builds, not in the released app.

## Window

Minimize, Zoom and Bring All to Front on a Mac; Minimize and Close on Windows.

## Help

| Item | What it does |
|---|---|
| {ui.menu.documentation} | Opens this documentation in your browser. |
| {ui.native.menu.replayTutorial} | Replays the [guided tour](/novelworks-docs/getting-started/guided-tour/). |
| {ui.native.menu.keyboardShortcuts} (**Cmd+/**) | Shows the list of shortcuts. |
| {ui.native.menu.activateNovelWorks} | In the itch.io full version only. See [Install and activate](/novelworks-docs/getting-started/install-and-activate/). |
| {ui.native.menu.reportABug} | Opens the contact form. See [Report a bug](/novelworks-docs/reference/report-a-bug/). |
| About Novelworks | Windows only: the About window. |

## Menus of the projects screen

On the projects screen, only the new project, open project, About, shortcuts, and Undo/Redo (for the name field) menu commands do anything.
