---
title: Keyboard shortcuts
description: Every shortcut of the editor and of the games.
---

Mac keys are shown first. On Windows, use **Ctrl** instead of **Cmd**. In the app, **Help → Keyboard Shortcuts** (Cmd/Ctrl+/) shows the same list.

## Editor

| Action | Keys |
|---|---|
| Save | Cmd+S |
| Undo / Redo | Cmd+Z / Shift+Cmd+Z (Windows: Ctrl+Y) |
| Play from the title screen | Cmd+P |
| Play from the selected moment | Shift+Cmd+P |
| Find and replace | Cmd+F |
| Export for web | Cmd+E |
| New project / Open project | Cmd+N / Cmd+O |
| New dialogue moment after this one | Cmd+Enter |
| Duplicate moment | Cmd+D |
| Delete moment, character, zone or prop | Delete or Backspace |
| Previous / next moment | ← / → (Cmd+[ and Cmd+] also while typing) |
| First / last moment | Home / End |
| Scenes, Assets, Characters, Variables | Cmd+1, 2, 3, 4 |
| Game UI | Cmd+5 |
| Story map | Cmd+6 |
| Next line (while writing) | Enter |
| New line in the same box | Shift+Enter |

## In a game

| Action | Keys |
|---|---|
| Advance | Click, Space or Enter |
| Choose an option | 1 to 6 |
| Pause menu | Esc or right-click |
| Quick save / quick load | F5 / F9 |
| History | H or mouse wheel up |
| Auto | A |
| Skip | S, or hold Ctrl |
| Inventory | I |
| Map | M |
