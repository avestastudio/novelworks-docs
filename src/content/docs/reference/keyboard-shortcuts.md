In the editor, **Help → {ui.native.menu.keyboardShortcuts}** (**Cmd+/** on a Mac, **Ctrl+/** on Windows) opens the same list. A shortcut marked "while typing" also works when a text box has the focus; the others do not.

Notes:

- **Cut, copy and paste** work on a moment, a scene (in the Scenes tab) or a character on the game screen, in the Visual view. See [Copy, paste and duplicate](/novelworks-docs/writing/copy-paste-duplicate/).
- The **play**, **duplicate**, **new moment**, **previous/next moment** (with **Cmd+[** / **Cmd+]**) and **panel** shortcuts work while typing. Delete, the arrows, **Home** and **End** do not.
- The panel shortcuts switch to the Story mode, except Game UI (**Cmd+5**) and Story map (**Cmd+6**), which switch to those modes.
- All shortcuts are ignored while you play, and while a window, a menu or a pop-up is open.
- In the Map workspace, `Delete` and **Cmd+D** act on the selected location.
- In the Script view, copy and paste of moments do not apply: the text editor keeps its own.

## In a game

These work in exported games and in Play mode.

| Action | Keys |
|---|---|
| Move on (finishes the text first) | Click, **Space** or **Enter** |
| Choose an option | **1** to **6** (the Nth option on screen) |
| Pause menu | **Esc** or right-click |
| Quick save / quick load | **F5** / **F9** |
| History | **H** or mouse wheel up |
| Auto | **A** |
| Skip | **S**, or hold **Ctrl** |
| Inventory | **I** (Inventory feature) |
| Map | **M** (when the Map button is shown) |
| Move between buttons and zones | **Tab** |

More details, with touch screens: [Keys and touch screens](/novelworks-docs/player/keys-and-touch/).
