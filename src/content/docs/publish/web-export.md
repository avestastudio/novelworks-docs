---
title: Export for web
description: Make a playable web game.
---

Choose **File → Export for Web (itch.io)…** (**Cmd/Ctrl+E**), pick where to save, and NovelWorks creates a `.zip` ready for itch.io. This needs the full, activated version.

Exported games open with a short **"Made with NovelWorks"** screen (about 3 seconds). Players can skip it with a click, tap or key.

Notes, scene summaries and writing statuses are not included in the export.
