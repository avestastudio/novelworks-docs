---
title: Assets
description: Import and organize your pictures.
---

The **Assets** tab holds every picture of your game. You can drag files into the window to import them.

Each picture has a **category**:

| Category | Use |
|---|---|
| **Background** | Behind the characters |
| **Sprite** | Character pictures |
| **CG** | Full-screen event illustrations, used like backgrounds |
| **Prop** | Object pictures placed on exploration moments |
| **UI** | Pictures for the game's own screens (text box, logo, buttons) |
| **Avatar** | Small portraits next to the speaker's name |

Use the filter chips at the top of the tab to show one category.

Pictures are copied into the `assets` folder of your project. Deleting a picture moves it to the backups, so you can still go back.
