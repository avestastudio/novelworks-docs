title: Characters
description: Create characters with expressions and avatars.
---

Open the **Characters** tab to add and edit characters.

## A character

- **Name**: shown in the name tag.
- **Name color**: pick a swatch or any color.
- **Expressions**: each expression is a name and a picture (for example "Happy"). The star marks the **default expression**, used when you add the character to a stage.
- **Avatar**: a small portrait next to the name. Choose **None**, **Fixed** (one picture) or **Per expression** (a picture for each expression, falling back to the default avatar).

## On stage

Add a character to a moment with **+ Character** above the screen, then pick its expression. See [Moments and dialogue](/novelworks-docs/writing/moments-and-dialogue/).

## Right-click

Right-click a character to rename or duplicate it, or to see where it is used.
