---
title: "问题：所有警告"
description: 编辑器会在哪些地方提醒你出了问题，以及完整的警告列表和应对办法。
---

当你的剧情不完整或永远无法正常运行时，编辑器会提醒你，这样你可以在玩家看到之前修好它。**警告从不会阻止你：**你仍然可以试玩和导出。游戏本身绝不会因为这些问题而崩溃：缺少链接只会被当作“继续下一个片段”。

## 警告出现在哪里

- **在时间线的片段卡片上**，会有一个警告三角形。把鼠标指向它，可以看到该片段的所有问题。
- **在片段的检查器中**，一个“{tx.branchInspectors.thisMomentNeedsYourAttention}”的框会列出它们。
- **在“场景”标签页中**，没有任何内容通向的场景上，会有一个红色的**{ui.scenesTab.unreachable}**标记。
- **在[剧情地图](/novelworks-docs/zh-cn/branching/story-map/)上**，场景卡片上有带数字的警告徽标，还有**{ui.storyMap.unreachable}**标记。**{ui.storyMap.problems}**筛选会高亮有警告或无法到达的场景。“{tx.storyMap.gameEndsHere}”这个标记只是信息，不是警告。
- **在地图工作区中**，有一个“检查你的地图”框。
- **导出时**，会列出整个游戏的“需要先检查的事项”。见[网页导出](/novelworks-docs/zh-cn/publish/web-export/)。
- **在[剧本模式](/novelworks-docs/zh-cn/writing/script-mode/)中**，行上会有另一套黄色下划线。

顶栏里没有问题计数器，也没有列出所有问题的面板：导出窗口是唯一一次性列出整个游戏所有问题的地方。

## 任何片段

| 警告 | 它的意思和应对办法 |
|---|---|
| 玩家永远看不到这个片段：在此场景中，它之前有结局、跳转、“{tx.moments.showMap}”片段，或没有“继续”区域的探索。 | 这个片段排在一个会离开场景的片段之后。移动它或删除它。 |

## 选择

| 警告 | 应对办法 |
|---|---|
| 这个选择没有选项。 | 添加选项。 |
| 选项 N 没有文字。 | 输入这个选项的文字。 |
| 选项 N 要前往的场景已被删除。请另选一个场景，或选择“继续”。 | 另选一个场景，或选“继续”。 |
| 选项 N 要修改变量，但还没有选择变量。/ …已被删除。 | 选择一个变量。 |
| 选项 N 要使用物品，但还没有选择物品。/ …已被删除。/ …但“物品栏”功能已关闭。 | 选择一个物品，或在“功能库”中开启物品栏。 |
| 选项 N 要检查变量或物品，但还没有选择。/ …已被删除。/ …但“物品栏”功能已关闭。 | 修正这个选项的条件。 |

## 如果…

| 警告 | 应对办法 |
|---|---|
| 请选择此条件要检查的变量。 | 选择一个变量。 |
| 请选择此条件要检查的物品。 | 选择一个物品。 |
| 这个条件检查的变量已被删除。/ 物品已被删除。 | 另选一个。 |
| 这个条件要检查物品，但“物品栏”功能已关闭。 | 开启物品栏。 |
| 请选择条件成立时要前往的场景。 | 选择一个场景。 |
| 条件成立时，要前往的场景已被删除。/ 否则，这里要前往的场景已被删除。 | 另选一个场景。 |

请记住，条件有问题的“如果…”会被游戏跳过。见[“如果…”条件](/novelworks-docs/zh-cn/branching/conditions/)。

## 跳转

| 警告 | 应对办法 |
|---|---|
| 请选择要前往的场景。 | 选择一个场景。 |
| 这里要前往的场景已被删除。 | 另选一个场景。 |

## 物品片段

| 警告 | 应对办法 |
|---|---|
| 请选择要给予的物品。/ 请选择要移除的物品。 | 选择一个物品。 |
| 这个片段给予的物品已被删除。/ …移除的物品已被删除。 | 另选一个物品。 |
| “物品栏”功能已关闭：玩家没有物品栏。请在“功能库”中开启。 | 开启物品栏。 |

## 探索片段

| 警告 | 应对办法 |
|---|---|
| 请至少画一个供玩家点击的区域。 | 画一个区域。 |
| “区域”要前往场景，但还没有选择场景。/ 要前往的场景已被删除。（还有“…使用物品时要前往场景，但还没有选择场景。”） | 选择一个场景。 |
| “区域”（查看时）没有要说的话。/ …（使用物品时）。 | 输入它要显示的那句话。 |
| “区域”要检查变量或物品，但还没有选择。/ …已被删除。/ …但“物品栏”功能已关闭。（它的条件） | 修正条件。 |
| “区域”要使用物品，但还没有选择物品。/ …已被删除。/ …但“物品栏”功能已关闭。 | 修正物品。 |
| “区域”由一个已删除的角色来查看。 | 另选一个说话人。 |
| “区域”要修改变量，但还没有选择变量。/ …已被删除。 | 选择一个变量。 |
| “区域”需要一个玩家永远无法获得的物品。 | 在某处给出这个物品（物品片段、选择，或拾取区域）。 |
| “区域”永远无法使用：它的条件永远不会成立。 | 检查是什么在修改变量，或给出物品。 |
| 有一个道具没有图片。/ 有一个道具链接到了已删除的区域。 | 选择一张图片，或把道具链接到另一个区域。 |
| 玩家可能会卡在这里：没有任何可点击的区域能通向其他场景或继续剧情。 | 添加一个通向场景或继续剧情的区域。 |

## 地图

| 警告 | 应对办法 |
|---|---|
| “地图”功能已关闭：这个片段不会有任何作用。请在“功能库”中开启。 | 在“功能库”中开启“地图”（这是“{tx.moments.showMap}”片段的警告）。 |
| 请在“地图”中创建你的地图并添加背景。/ 地图片段已被删除。请另选一个探索片段。/ 地图片段不再是探索片段。请另选一个。 | 创建或修正地图。在“{tx.moments.showMap}”片段上，这些警告的末尾会加上“在此之前，这个片段不会有任何作用。” |
| 请在“地图”中添加背景图片。 | 选择一个背景。 |
| 玩家永远无法打开地图：游戏没有起始场景。 | 设置一个起始场景。 |
| 玩家永远无法打开地图：地图按钮已关闭 / 正在等待“{tx.moments.showMap}”片段，而且无法到达任何“{tx.moments.showMap}”片段。请添加一个，或设为始终可用。 | 添加一个“{tx.moments.showMap}”片段，或更改地图的可用时机。 |

## 整个游戏（导出窗口）

| 警告 | 应对办法 |
|---|---|
| 游戏还没有任何场景：玩家只能看到标题画面。 | 添加一个场景。 |
| 尚未设置起始场景：“新游戏”会直接跳到结尾。 | 用星标设置一个起始场景。 |
| 玩家永远无法到达这个场景：没有任何选择、条件、跳转或区域通向它。（仅当游戏有多个场景时。） | 把它链接起来，或删除它。 |
| 这个场景没有片段。 | 添加一个片段。 |
| 玩家永远看不到这些片段：在此场景中，它们之前有结局、跳转，或没有“继续”区域的探索。 | 移动或删除它们。 |

导出窗口还会列出每个片段自己的警告，格式为“场景，第 4 个片段 — 消息”。

## 在地图上无法建立的链接

当你在剧情地图上拖出一条链接时，不适用的链接类型会变灰并给出原因：这个场景以结局结尾、已经以跳转结尾、以探索结尾（请改为添加区域），或者它的选择已经有 6 个选项了。

## 不会检查的内容

对话片段本身没有警告：空的对话行不会被标出。
