---
title: "键盘快捷键"
description: "编辑器与游戏的快捷键。"
---

下面以 Mac 键位为例；Windows 用 **Ctrl** 替代 **Cmd**。应用内的 **Help → Keyboard Shortcuts**（**Cmd/Ctrl+/**）也可查看列表。

## 编辑器

| 操作 | 按键 |
|---|---|
| 保存 | Cmd+S |
| 撤销 / 重做 | Cmd+Z / Shift+Cmd+Z（Windows：Ctrl+Y） |
| 从标题开始测试 | Cmd+P |
| 从所选时刻开始 | Shift+Cmd+P |
| 查找与替换 | Cmd+F |
| 导出网页游戏 | Cmd+E |
| 新建 / 打开项目 | Cmd+N / Cmd+O |
| 在当前时刻后添加对话 | Cmd+Enter |
| 复制时刻 | Cmd+D |
| 删除时刻、角色、区域或道具 | Delete 或 Backspace |
| 上一个 / 下一个时刻 | ← / →（输入时也可用 Cmd+[ 和 Cmd+]） |
| 第一个 / 最后一个时刻 | Home / End |
| Scenes、Assets、Characters、Variables | Cmd+1、2、3、4 |
| Game UI | Cmd+5 |
| Story map | Cmd+6 |
| 写作时进入下一句 | Enter |
| 同一对话框内换行 | Shift+Enter |

## 游戏中

| 操作 | 按键 |
|---|---|
| 前进 | 点击、Space 或 Enter |
| 选择选项 | 1 至 6 |
| 暂停菜单 | Esc 或右键 |
| 快速保存 / 读取 | F5 / F9 |
| History | H 或滚轮向上 |
| Auto | A |
| Skip | S 或按住 Ctrl |
| Inventory | I |
| Map | M |
