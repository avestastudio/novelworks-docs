说明：

- **剪切、复制和粘贴**可用于片段、场景（在“场景”标签页中）或游戏画面上的角色，在可视化视图中使用。见[复制、粘贴和创建副本](/novelworks-docs/zh-cn/writing/copy-paste-duplicate/)。
- **试玩**、**创建副本**、**新片段**、**上一个/下一个片段**（用 **Cmd+[** / **Cmd+]**）和**面板**快捷键在输入时也可用。Delete、方向键、**Home** 和 **End** 则不行。
- 面板快捷键会切换到剧情模式，但游戏界面（**Cmd+5**）和剧情地图（**Cmd+6**）除外，它们会切换到各自的模式。
- 试玩期间，以及窗口、菜单或弹出框打开时，所有快捷键都会被忽略。
- 在地图工作区中，`Delete` 和 **Cmd+D** 作用于所选的地点。
- 在剧本视图中，片段的复制和粘贴不适用：文本编辑器使用它自己的。在那里，**Cmd+Enter** / **Ctrl+Enter** 是“{tx.scriptMode.playFromCursor}”，**Cmd+.** / **Ctrl+.** 会创建所有缺少的内容。

## 在游戏中

这些在导出的游戏和试玩模式中都有效。

| 操作 | 按键 |
|---|---|
| 继续（先显示完文字） | 点击、**Space** 或 **Enter** |
| 选择一个选项 | **1** 到 **6**（屏幕上的第 N 个选项） |
| 暂停菜单 | **Esc** 或右键点击 |
| 快速存档 / 快速读档 | **F5** / **F9** |
| 历史记录 | **H** 或鼠标滚轮向上 |
| 自动 | **A** |
| 快进 | **S**，或按住 **Ctrl** |
| 物品栏 | **I**（需启用物品栏功能） |
| 地图 | **M**（显示地图按钮时） |
| 在按钮和区域之间移动 | **Tab** |

更多细节（包括触屏）：[按键与触屏](/novelworks-docs/zh-cn/player/keys-and-touch/)。
