---
title: 术语表
description: NovelWorks 和这份文档中用到的词。
---

| 词 | 含义 |
|---|---|
| {ui.inspector.scene} | 你故事中的一章：由一连串依次播放的片段组成。 |
| 片段 | 场景中的一步：一句对话、一个选择、一次跳转、一个结局…… |
| {ui.timeline.timeline} | 编辑器底部那一排片段卡片。 |
| 舞台 | 游戏画面上的内容：背景和角色。它会从一个片段延续到下一个片段。 |
| 起始场景 | 新游戏开始的场景，用一颗星标出。 |
| 角色 | 你故事中的一个人物，有姓名颜色和表情。 |
| 表情 | 角色在某种心情（开心、难过……）下的一张图片。带星的是默认表情。 |
| {ui.gameUIInspector.avatar} | 在对话框中显示在角色名字旁边的小肖像。 |
| {ui.gameUIInspector.image} | 项目中的一张图片：背景、角色立绘、CG、道具、界面图片或头像。 |
| CG | 用于特殊事件的全屏插画。 |
| 道具 | 一件物品的图片，放在探索画面上，或用作物品图片。 |
| 变量 | 游戏记住的东西。*分数*是一个数字；*事实*是“是”或“否”。 |
| {ui.moments.item} | 玩家携带的东西（物品栏功能）。*单个*（有或没有）或*可叠加*（可以有多个）。 |
| {ui.moments.choice} | 玩家要从 2 到 6 个选项中选一个的片段。 |
| {ui.moments.condition} | 玩家看不到的片段，它检查游戏记住的内容，然后前往某个场景。它有按从上到下顺序检查的*情况*，以及一个*否则*。 |
| {ui.moments.jump} | 直接前往另一个场景的隐形片段。 |
| {ui.moments.ending} | 显示结局名称并回到标题画面的片段。 |
| {ui.moments.exploration} | 没有文本框的片段，玩家在一张图片上点击各个*区域*。 |
| 区域 | 探索画面中可以点击的一块地方。在地图上，一个区域就是一个*地点*。 |
| 功能 | 你游戏中可选的一部分，在功能库中打开：物品栏或地图。 |
| {ui.topBar.storyMap} | 显示所有场景以及它们之间连接的视图。 |
| {ui.topBar.gameUI} | 用来更改游戏外观的模式。 |
| 剧本模式 | 像电影剧本一样，把场景显示为文本的视图。 |
| 提示 | 游戏中的一条简短消息，例如“你获得了：钥匙”。 |
| {ui.quickMenu.title} | 显示在剧情上方的阅读控制小栏。 |
| 试玩模式 | 在编辑器里试玩你的游戏。 |
| 备份 | `project.json` 的一份较早的副本，保存在 `backups` 文件夹中。 |
| 游戏语言 | 游戏自身按钮和菜单使用的语言。你的剧情保持你写的样子。 |
| {ui.languageDialog.label} | 编辑器本身的语言。 |
