title: 所有菜单
description: 应用菜单的每一项，以及它的快捷键。
---

NovelWorks 使用你电脑的原生菜单。在 Windows 上，**Cmd** 对应 **Ctrl**。有些菜单项需要先打开一个项目，而且在试玩时，大多数编辑命令会被忽略。

## 应用菜单（仅限 Mac）

**关于 Novelworks**、服务、**隐藏 Novelworks**（**Cmd+H**）、{ui.native.role.hideOthers}、{ui.native.role.unhide}、**退出 Novelworks**（**Cmd+Q**）。在 Windows 上，“退出”在“文件”菜单的末尾，“关于”在“帮助”菜单里。

## 文件

| 菜单项 | 快捷键 | 作用 |
|---|---|---|
| {ui.native.menu.newProject} | **Cmd+N** | 打开新建项目画面。 |
| {ui.native.menu.openProject} | **Cmd+O** | 打开一个项目文件夹。 |
| {ui.native.menu.save} | **Cmd+S** | 保存项目。 |
| {ui.native.menu.restoreFromBackup} | | 回到更早的版本。见[保存、备份和撤销](/novelworks-docs/zh-cn/getting-started/saving-and-undo/)。 |
| {ui.native.menu.importScript} | | 把一个文本文件添加到你的场景中。见[导入和导出剧本](/novelworks-docs/zh-cn/writing/import-a-script/)。 |
| {ui.native.menu.exportScript} | | 把你的整个游戏保存为一个文本文件。 |
| {ui.native.menu.exportForWeb} | **Cmd+E** | 把你的游戏导出为网页版。见[网页导出](/novelworks-docs/zh-cn/publish/web-export/)。 |
| {ui.native.menu.closeProject} | **Cmd+Shift+W** | 回到项目画面。 |

## 编辑

| 菜单项 | 快捷键 |
|---|---|
| {ui.native.menu.undo} | **Cmd+Z** |
| {ui.native.menu.redo} | **Shift+Cmd+Z**（Windows：**Ctrl+Shift+Z**，在编辑器中也可用 **Ctrl+Y**） |
| {ui.native.menu.findAndReplace} | **Cmd+F** |
| 剪切、复制、粘贴、全选 | **Cmd+X**、**Cmd+C**、**Cmd+V**、**Cmd+A** |
| {ui.native.spelling.spellingLanguage} | 在 Windows 上：你电脑的语言加上英语，或另一种语言。在 Mac 上，macOS 会自动识别你文字的语言。保存在项目中。 |

撤销和重做作用于项目，但在新建项目画面的名称输入框中除外。

## 视图

- {ui.native.menu.theme}：{ui.native.menu.dark}、{ui.native.menu.light}或{ui.native.menu.system}。
- {ui.native.menu.language}：{ui.native.menu.languageAuto}，或七种语言之一。
- {ui.native.role.togglefullscreen}（Mac 上是 **Control+Cmd+F**）。

开发者菜单项（重新加载、切换开发者工具）只出现在开发版本中，正式发布的应用里没有。

## 窗口

Mac 上有最小化、缩放和全部置于最前；Windows 上有最小化和关闭。

## 帮助

| 菜单项 | 作用 |
|---|---|
| {ui.menu.documentation} | 在浏览器中打开这份文档。 |
| {ui.native.menu.replayTutorial} | 重新播放[引导教程](/novelworks-docs/zh-cn/getting-started/guided-tour/)。 |
| {ui.native.menu.keyboardShortcuts}（**Cmd+/**） | 显示快捷键列表。 |
| {ui.native.menu.activateNovelWorks} | 仅限 itch.io 完整版。见[安装和激活](/novelworks-docs/zh-cn/getting-started/install-and-activate/)。 |
| {ui.native.menu.reportABug} | 打开联系表单。见[报告问题](/novelworks-docs/zh-cn/reference/report-a-bug/)。 |
| 关于 Novelworks | 仅限 Windows：打开“关于”窗口。 |

## 项目画面的菜单

在项目画面上，只有新建项目、打开项目、关于、快捷键，以及撤销/重做（用于名称输入框）这几个菜单命令有作用。
