## 你的游戏归你

NovelWorks 的“关于”窗口写道：“{tx.aboutDialog.makeVisualNovelsWithoutCodeYourGames}”你的游戏里包含的字体保留它们各自的开源许可（见下文）。

## 版本

| | 演示版 | 完整版 |
|---|---|---|
| 完整的编辑器、试玩模式、剧本模式、游戏界面 | 有，但受下面的限制 | 有 |
| 导出为网页版 | 最多 5 个场景且不超出下面的限制，导出的游戏中带标记 | 不限大小，无标记 |
| 需要下载密钥 | 不需要 | 需要，用于导出（itch.io 完整版）。Steam 版不需要。 |

见[免费演示版](/novelworks-docs/zh-cn/getting-started/demo-edition/)和[安装与激活](/novelworks-docs/zh-cn/getting-started/install-and-activate/)。两个版本读写的项目格式相同。

## 演示版的限制

| 演示版中 | 最多 |
|---|---|
| 角色 | 3 |
| 每个角色的服装 | 2 |
| 每个片段的镜头 | 2 |
| 声音文件 | 5 |
| 变量 | 5 |
| 物品 | 3 |
| 效果 | 登场、退场、反应、画面和转场每类各 2 种 |
| 粒子 | 雨和雪 |

这些限制只是不让你继续添加。不会丢失任何内容，你的项目在完整版中会保持原样继续使用。超出限制的项目仍然可以在演示版中打开，但演示版无法导出它。

## 激活

完整版会要求你输入购买时附带的**密钥**。没有它，你仍然可以打开、编辑和试玩你的项目，只有导出被锁定。激活窗口说明，一个密钥最多可在 3 台电脑上使用，也可以停用后换到另一台电脑。NovelWorks 每次启动时都会在你的电脑上检查许可，所以没有网络时也可以导出。

你可以在“关于”窗口里看到你的许可状态（“{tx.aboutDialog.activated}{tx.aboutDialog.manage}”或“{tx.aboutDialog.notActivated}{tx.aboutDialog.activateNovelWorks}”）。

## 导出的游戏包含什么

- 你的游戏、你的图片、视频、声音和文字。
- 你的游戏界面所用的字体和适合阅读障碍者的字体，以及它们的许可文件。游戏字体（Inter、Lora、Nunito 和 Courier Prime）和适合阅读障碍者的字体都是免费字体，遵循它们各自的开源许可（四种主要字体使用 SIL 开放字体许可）。
- 游戏开始时会有一个简短的“Made with NovelWorks”画面。
- 从演示版导出的游戏中，会带有“Made with NovelWorks Demo”画面，游戏运行时角落里还有一个小小的“NovelWorks Demo”标志。

Mac 版应用目前还没有用 Apple Developer ID 签名。见[安装与激活](/novelworks-docs/zh-cn/getting-started/install-and-activate/)。
