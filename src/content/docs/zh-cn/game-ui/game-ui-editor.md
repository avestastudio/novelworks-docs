---
title: "Game UI 编辑器"
description: "调整游戏各个界面的外观。"
---

点击 **Game UI**（**Cmd/Ctrl+5**）。左侧选择画面，右侧修改，中间实时预览。

| 画面 | 控制内容 |
|---|---|
| **Fonts & colors** | 全局字体与颜色 |
| **Title screen** | 标题画面 |
| **Dialogue box** | 姓名与台词框 |
| **Choices** | 选项按钮 |
| **Pause menu** | Esc 或右键打开的暂停菜单 |
| **Save & load** | 保存与读取画面 |
| **History** | 已读文字记录 |
| **The End** | 故事结束画面 |
| **Inventory** | 背包按钮及物品面板，需要 Inventory |
| **Map button** | 地图按钮，需要 Map |
| **Notices** | “You got: Key”等简短通知 |

## 使用提示

- 留空的设置沿用全局值。
- 对话框可位于底部、顶部、左侧、右侧或中央；边距、宽高均可调。背景可选颜色或图片，图片支持 **Stretch**、**Fit**、**9-slice**。
- 姓名标签可放在框内或上方。姓名颜色可跟随角色，也可统一设置。
- 按钮样式：**Pill**、**Rounded**、**Square**。
- **Reset** 恢复该画面的默认设置。
