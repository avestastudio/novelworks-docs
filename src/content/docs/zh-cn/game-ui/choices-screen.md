---

{ui.gameUI.choices} 画面就是[选择](/novelworks-docs/zh-cn/branching/choices/)按钮的外观。预览会显示一个问题和三个示例选项。

## 按钮

- {ui.gameUIInspector.buttonStyle}：默认是“{tx.gameUIInspector.sameAsFontsColors}”。
- {ui.gameUIInspector.buttonColor}：默认是“{tx.gameUIInspector.sameAsTheDialogueBox}”（方框的颜色连同它的不透明度）。
- {ui.gameUIInspector.textColor}：默认是“{tx.gameUIInspector.sameAsTheTextColor}”。

选项的文字来自你的剧情。玩家可以点击选项，也可以按它的数字键。

被锁定的选项（参见[选择](/novelworks-docs/zh-cn/branching/choices/)）会显示成灰色，无法选取。
