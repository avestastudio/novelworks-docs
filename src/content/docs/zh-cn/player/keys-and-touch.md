description: 玩家在游戏中可以使用的所有按键、鼠标操作和触屏手势。
---

按住 **Ctrl**、**Cmd** 或 **Alt** 时，快捷键会被忽略（只单独按住 **Ctrl** 来快进除外）。

## 键盘

| 按键 | 作用 |
|---|---|
| **Space**、**Enter** | 先把文字显示完，再继续。在获得焦点的按钮上，按下该按钮。在获得焦点的区域上，使用该区域。 |
| **1** 到 **6** | 选择屏幕上的第 N 个选项。文字正在出现时第一次按下，会先把文字显示完。 |
| **Esc** | 打开或关闭暂停菜单。关闭物品栏、历史记录、选项和存档/读档。 |
| **H** | 打开或关闭历史记录。 |
| **A** | 开启或关闭自动。 |
| **S** | 开启或关闭快进。 |
| **Ctrl**（按住） | 按住期间快进。 |
| **F5** | 快速存档（游戏进行中）。 |
| **F9** | 快速读档（在标题画面也可以）。 |
| **I** | 打开或关闭物品栏（需要启用物品栏功能）。 |
| **M** | 打开地图（显示地图按钮时）。 |
| **Tab** | 在按钮和探索区域之间移动。存档、历史记录、选项和内容提示打开时，焦点只在它们内部移动。 |
| 方向键、**Home**、**End**、**Page Up**、**Page Down** | 在历史记录中：滚动。在存档和读档中：方向键、**Home** 和 **End** 在存档位之间移动。在选项中：方向键改变数值。它们不会推进剧情。 |
| 在存档位上按 `Delete` / `Backspace` | 询问是否删除该存档。 |

游戏中没有全屏键：可以使用浏览器自带的全屏键（**F11**），或页面上的全屏按钮。

## 鼠标

- 在剧情上**左键点击**：显示完文字、继续、选择一个选项，或使用一个区域。
- **右键点击**：打开或关闭暂停菜单（浏览器自己的菜单不会出现在游戏上方）。在存档、读档、历史记录、选项或某个提问打开时，右键没有作用。
- **滚轮向上**：打开历史记录。滚轮向下没有作用。
- 鼠标**悬停**在探索区域上：显示它的高亮和标签。

## 触屏

- **轻点**会继续，和点击一样。
- 在**带标签**的探索区域上，第一次轻点显示标签，第二次轻点才执行。没有标签时，轻点一次就执行。
- 游戏中没有滑动、长按或双击。右键点击在触屏上没有对应的操作：页面会为触屏设备增加一个{ui.gameUIInspector.menu}按钮。
- 拖动可以滚动历史记录。

## 导出的网页还增加了什么

右上角有一小组按钮（在被触摸或悬停之前是淡淡的）：

- {ui.gameUIInspector.menu}，仅在触屏设备上：打开暂停菜单，因为触屏没有右键，也没有 Esc。
- {rt.player.fullscreen} / {rt.player.exitFullscreen}，在浏览器支持时出现（iPhone 上没有）。

网页版游戏中没有“退出”按钮。游戏会按窗口大小等比缩放，四周留有黑边。它需要 JavaScript，还需要允许本地存储的浏览器才能保存存档。见[网页导出](/novelworks-docs/zh-cn/publish/web-export/)。
