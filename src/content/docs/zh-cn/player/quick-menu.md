---
title: 快捷菜单
description: 显示在剧情上方的阅读控制，从玩家的角度来看。
---

快捷菜单是剧情上方一个小巧不起眼的栏。它的位置、外观和按钮，由你在[快捷菜单](/novelworks-docs/zh-cn/game-ui/quick-menu/)设计页中设置。玩家可以使用下面任何一个按钮，或者按对应的键：

| 按钮 | 按键 |
|---|---|
| 历史记录 | H |
| 自动 | A |
| 快进 | S |
| 存档、读档 | |
| 快速存档、快速读档 | F5、F9 |
| 选项 | |
| 菜单 | Esc |

- 鼠标指针移到按钮上之前，按钮是淡淡的。“自动”和“快进”开启时看起来是按下的状态。
- 点击按钮不会推进剧情。按下“自动”和“快进”以外的任何按钮，都会关闭阅读模式。
- 在标题画面和结束画面上，以及打开某个界面或菜单时，这个栏会隐藏。在出现快速存档之前，**{rt.game.quickLoad}**是灰色的（在暂停菜单中则是隐藏的）。如果浏览器无法保存，存档和读档界面会提示。
- 隐藏某个按钮后，它的按键仍然有效。屏幕阅读器会把这一组朗读为“{tx.quickMenu.label}”。
