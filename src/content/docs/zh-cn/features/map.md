在 [Features](/novelworks-docs/zh-cn/features/features-panel/) 中启用 **Map**，点击 **Edit map** 打开地图工作区。

## 制作地图

1. 添加地图背景。
2. 点击 **Add location** 并画出区域。
3. 为地点命名，例如“咖啡店”。默认在悬停时显示名称。
4. 选择点击后播放的场景，也可直接在此字段创建场景。
5. 用 **Test map** 测试。

## 何时允许打开？

在地图设置中选择玩家何时可以使用地图按钮：

- **From the start**：从游戏开始就显示 Map 按钮。
- **After first shown**：故事首次到达 **Show map** 时刻后，才显示按钮。
- **Story only**：不显示 Map 按钮，只能由 **Show map** 时刻打开地图。

## Show map 时刻

**Show map** 会立即打开地图，要求玩家选择目的地。通过 **Map** 按钮打开的地图则可以关闭，继续阅读。

## 锁定地点

地点可根据条件隐藏或锁定；锁定时可显示说明文字。
