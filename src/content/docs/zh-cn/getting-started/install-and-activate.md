## 应下载哪个文件？

| 电脑 | 文件 |
|---|---|
| Apple Silicon Mac（M1、M2、M3、M4 等） | `Novelworks-<version>-mac-arm64.dmg` |
| Intel Mac | `Novelworks-<version>-mac-x64.dmg` |
| Windows 10 / 11 | `Novelworks-<version>-win-x64.exe` |

不确定 Mac 类型？打开苹果菜单 → **关于本机**。芯片显示“Apple M…”即为 Apple Silicon。

## 首次打开

NovelWorks 暂未使用付费的 Apple 或 Microsoft 证书签名，因此首次打开时可能出现系统提示。

### Mac

1. 打开 `.dmg`，把 **Novelworks** 拖到**应用程序**。
2. 从应用程序文件夹启动。如果 macOS 提示无法验证应用，点击**完成**。
3. 在 macOS 15 Sequoia 及更新版本中，打开**系统设置 → 隐私与安全性**，找到 Novelworks 提示并点击**仍要打开**。旧版系统可右键点击应用，选择**打开**。

### Windows

1. 运行 `.exe`。
2. 如果出现 **Windows 已保护你的电脑**，点击**更多信息**，再点击**仍要运行**。
3. 按安装程序提示操作。

## 激活完整版

完整版需要 itch.io 购买记录中的**下载密钥**。未激活时仍可打开、编辑和测试项目，但 **File → Export for Web** 不可用。

1. 打开 **Help → Activate NovelWorks…**；欢迎页和 **About** 中也有入口。
2. 粘贴 itch.io 下载密钥。
3. 点击 **Activate**。

- 每个密钥最多用于 **3 台电脑**。
- 激活后可以**离线使用**。
- 要释放某台电脑的名额，例如出售前，在同一窗口点击 **Deactivate this device**。
- 达到上限时，可点击 **Contact us** 联系我们。
