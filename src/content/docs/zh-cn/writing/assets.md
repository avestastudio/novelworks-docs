---
title: "图片与素材"
description: "导入并整理游戏图片。"
---

**Assets** 包含游戏中的所有图片。把文件拖入窗口即可导入。

| 类别 | 用途 |
|---|---|
| **Background** | 角色后方的背景 |
| **Sprite** | 角色立绘 |
| **CG** | 全屏事件插画，使用方式与背景相同 |
| **Prop** | 放在探索时刻中的物体图片 |
| **UI** | 对话框、标志、按钮等界面图片 |
| **Avatar** | 说话者姓名旁的小头像 |

用顶部筛选按钮只显示某个类别。

图片会复制到项目的 `assets` 文件夹。删除时会移入备份，方便恢复。
