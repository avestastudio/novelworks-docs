---
title: "时刻与对话"
description: "了解场景的步骤及对话写法。"
---

场景由时间轴上的一系列**时刻**组成。每个时刻保存舞台布置（背景和角色），以及一种内容。

## 时刻类型

| 类型 | 功能 |
|---|---|
| **Dialogue** | 对话或旁白 |
| **Choice** | 玩家选择，可改变变量并跳到其他场景 |
| **Condition** | 检查条件并选择目标场景，玩家看不到此步骤 |
| **Jump** | 直接跳到其他场景，玩家看不到此步骤 |
| **Ending** | 显示结局名称，然后返回标题画面 |
| **Exploration** | 没有对话框，通过点击图片区域互动 |
| **Item** | 给予或移除物品，需要 Inventory |
| **Show map** | 打开地图，需要 Map |

## 编写对话

1. 选中时刻并点击画面上的对话框，或使用 **+ Dialogue**。
2. 在姓名标签中选择说话者，或保持 **Narrator**。
3. 输入台词。

**Enter** 创建下一句并保留舞台布置；**Shift+Enter** 在同一框内换行；**Cmd/Ctrl+Enter** 即使正在输入也能添加新对话时刻。

## 舞台布置

每个时刻保存自己的背景和角色。画面上方：

- 选择背景。**Apply to the following moments** 将背景复制到后续时刻。
- **+ Character** 添加角色。

点击角色可移动，拖动角部控制点缩放，还可翻转、切换表情和调整前后层级。**Left**、**Center**、**Right** 是一键定位。

## 笔记

每个时刻可填写私人笔记，不会出现在游戏或导出内容中。

## 切换时刻

使用 **← →**、**Home**、**End**，或点击卡片。
