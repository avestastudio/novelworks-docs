## 片段上的笔记

**笔记**只给你自己看：想法、待办事项、提醒。每个片段都可以有一条。

- 选中片段，在检查器{ui.inspectorTabs.text}标签页的 {ui.momentInspector.note} 中输入（“{tx.momentInspector.ideasToDosReminders}”）。检查器会说明只有你能看到你的笔记：它们永远不会在游戏中显示。
- 或者右键点击片段，选择 {ui.contextMenus.addNote}（或 {ui.contextMenus.editNote}），这会把你带到那个框。

带有笔记的片段，卡片上会显示一个便利贴图标；把鼠标指向它就能读到笔记。剧情地图会显示每个场景中有多少个片段带笔记。[查找和替换](/novelworks-docs/zh-cn/writing/search/)可以找到笔记。

### 剧本模式中的笔记

在[剧本模式](/novelworks-docs/zh-cn/writing/script-mode-lines/)中，笔记是以 `//` 开头的一行，放在它所属的片段之前：

```
// check the timing of this joke
Mia : Hello!
```

后面没有任何行的笔记会被标出。

## 场景上的笔记

场景没有笔记，但场景有一个 {ui.sceneInspector.summary}：一两句只给你自己看的话，显示在剧情地图上和时间线上方，永远不会在游戏中显示。请看[场景](/novelworks-docs/zh-cn/writing/scenes/)。
