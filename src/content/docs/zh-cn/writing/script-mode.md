---
title: "剧本模式：基础"
description: "像写电影剧本一样，把整个场景写成文字，并在你输入时看着它实时更新。"
---

**剧本模式**把场景显示成文字，而不是游戏画面和时间线。你每发生一件事就写一行，就像写剧本一样，场景会随着你的输入而更新。两种视图编辑的是同一个故事：你可以随时在它们之间切换。

```
Mia : Hello!
Mia (surprised) : You came back.
background : Station
? What now?
- Talk to her -> Park
- Leave
```

## 切换到剧本模式

在游戏画面上方，开关{ui.topBar.storyView}有两个按钮：{ui.topBar.visual}（游戏画面和时间线）和{ui.topBar.script}（文字形式的场景）。剧本视图里也有同样的开关，所以你可以切换回去。

![剧本模式：左边是文字形式的场景，右边是光标所在的片段。](/novelworks-docs/screenshots/script-mode.png)

## 文字显示什么

剧本工具栏有一个开关{ui.scriptMode.scope}：

- **场景的名称**：只显示所选的场景。
- {ui.scriptMode.wholeGame}：游戏的每个场景都在一段文字里，每个场景都在一个 `# Name` 标题下面。你可以在标题上重命名场景，用新标题添加场景，也可以在场景之间移动行。如果你删除了某个场景的标题，这个场景会被保留，并移到其他场景之后。地图自己的隐藏场景不包括在内。

单场景视图里的 `# heading` 会被忽略并标出。

## 预览

右侧显示**光标所在的片段**，就是它在游戏里的样子（“第 3 个时刻，共 12 个”）。移动光标会选中那个片段，而在别处选中某个片段，光标会移到它所在的行。接着上一行继续的行，属于同一个片段。预览栏可以拖动它的边缘来调整大小；双击边缘可以重置。

在预览上方，{ui.branches.whereTitle}行显示所选片段通向哪里，和可视化视图里一样（见[剧情如何分支](/novelworks-docs/zh-cn/concepts/how-stories-branch/)）。有一个按钮可以把它隐藏。

## 编辑

- 文字会在你**停止输入半秒后**应用到你的项目，在你切换范围、试玩或离开剧本模式时也会应用。
- 一连串的输入算**一步撤销**。停顿大约一秒后，会开始新的一步。
- 文字没有改动的片段会**保持原样**，包括它的笔记、它在剧情地图上的位置、它已读的台词和玩家的存档。文字无法表达的东西（自由摆放、大小、翻转、角色顺序、探索区域和道具）也会保留，画面没有改动的片段会完全保留它的画面。
- 如果你在别处（检查器、时间线、撤销）更改了项目，文字会更新，但不会移动你的光标。如果这时你正在输入，以你输入的文字为准。
- 还不存在的名称绝不会挡住任何东西。片段照样会被创建，这一行会加下划线。

## 输入时的帮助

- 在行首输入 `/`，可以从列表里选一个命令。输入时会建议角色、图片、场景、变量和物品的名称，在 `background :`、`show :`、`hide :`、`give`、`remove`、`->`、`+`、`=` 和 `if` 之后，列表里是对应种类的名称。
- **Tab** 增加缩进，**Shift+Tab** 减少缩进。
- 角色名会用角色的姓名颜色上色。
- **?** 按钮（{ui.scriptMode.help}）会打开一个“{tx.script.help.title}”面板，里面有格式说明。

## 还不存在的名称

不认识的名称会加下划线，快速修复可以一键创建它：

- 工具栏里的按钮{ui.scriptMode.createMissing_other}会创建文字里提到的所有缺失的角色、表情、场景、变量和物品（**Cmd+.** / **Ctrl+.**）；
- 在某一行上，快速修复只会创建那一个。

新创建的表情还没有图片。如果这一行拿变量做比较，或把它设为真或假，变量会被创建为事实，否则创建为分数。如果这一行有 `x3` 这样的数量，物品就是可堆叠的。

## 从光标处试玩

{ui.scriptMode.playFromCursor}会从光标所在的行开始播放游戏（**Cmd+Enter** / **Ctrl+Enter**）。

## 剧本模式里的警告

NovelWorks 希望你检查的行会带黄色下划线。把鼠标指向它，就能看到原因。需要检查的行数显示在预览下方。

| 信息 | 何时出现 |
|---|---|
| 没有名为“…”的角色 | `Name : text` 这样的行，其中的名字不是角色。这一行暂时按旁白处理。修复方法：创建这个角色，或者“这是旁白”。 |
| 没有名为“…”的表情 | 角色没有的表情。修复方法：创建它。 |
| 没有名为“…”的图片 | `background :` 没有对应的图片。导入它，或检查名称。 |
| 没有名为“…”的场景 | `->` 的目标、选项或条件里写了不存在的场景。修复方法：创建它。 |
| 没有名为“…”的变量 / 物品 | 修复方法：创建它。 |
| 选项下的这一行不是效果 | 选项下面缩进的一行，但不是 `+`、`=`、`give` 或 `remove`。它会被忽略。 |
| 无法读取这个条件 | 一行 `if`，其中的判断无法理解。 |
| 同一个条件里请只用“{tx.conditionCases.and}”或“或者” | 同一个条件里两种都有：只会采用第一种。 |
| 这一行改变了舞台，但后面没有其他行 | 后面没有任何行的 `background`、`show` 或 `hide`。 |
| 这条备注没有可归属的行 | 末尾的 `//` 备注，后面什么也没有。 |
| “…”此时不在舞台上 | 对不在台上的角色使用了 `hide :`。 |
| “…”是保留词 | 角色的名字和命令相同。重命名角色，或者把命令写在方括号里。 |
| # 标题只在整个游戏文档中有效 | 单场景视图里的标题。它会被忽略。 |
