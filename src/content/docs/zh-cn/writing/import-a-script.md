---
title: "导入剧本"
description: "把文本变成场景、台词和角色。"
---

已经在文本文件中写好了故事？使用 **File → Import Script…**。

## 格式

```
# 春日清晨
Mia: 你好！
外面下着雨。
Aoi: 嘿……你还好吗？
```

- 以 **#** 开头的行新建场景。
- **姓名: 文本** 表示该角色的一句台词；冒号使用示例中的半角符号。
- 没有姓名的行由 **Narrator** 旁白讲述。
- 空行会被忽略。

## 操作步骤

1. 把剧本粘贴到左侧。**Preview** 显示将创建的场景、台词和新角色。
2. 取消勾选不应成为角色的名字；它们将保留在旁白文本中。
3. 选择台词插入的位置，然后导入。

如果结果不对，用 **Undo** 撤销导入。
