title: Выбор

Экран **{ui.gameUI.choices}** задаёт внешний вид кнопок [выбора](/novelworks-docs/ru/branching/choices/). Предпросмотр показывает вопрос с тремя образцами вариантов.

## Кнопки

- **{ui.gameUIInspector.buttonStyle}**: по умолчанию «{tx.gameUIInspector.sameAsFontsColors}».
- **{ui.gameUIInspector.buttonColor}**: по умолчанию «{tx.gameUIInspector.sameAsTheDialogueBox}» (цвет окна с его непрозрачностью).
- **{ui.gameUIInspector.textColor}**: по умолчанию «{tx.gameUIInspector.sameAsTheTextColor}».

Текст вариантов берётся из вашей истории. Игроки нажимают на вариант или клавишу с его номером.

Заблокированный вариант (см. [Выбор](/novelworks-docs/ru/branching/choices/)) рисуется серым, и его нельзя выбрать.
