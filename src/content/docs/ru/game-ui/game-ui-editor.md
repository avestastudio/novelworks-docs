---
title: "Редактор Game UI"
description: "Настройте оформление всех экранов игры."
---

Нажмите **Game UI** (**Cmd/Ctrl+5**). Выберите экран слева, изменяйте справа и смотрите результат в центре.

| Экран | Что настраивает |
|---|---|
| **Fonts & colors** | Общие шрифты и цвета |
| **Title screen** | Титульный экран |
| **Dialogue box** | Имена и реплики |
| **Choices** | Кнопки выбора |
| **Pause menu** | Меню по Esc или правой кнопке мыши |
| **Save & load** | Сохранение и загрузку |
| **History** | Прочитанные реплики |
| **The End** | Экран окончания истории |
| **Inventory** | Кнопку и панель предметов, нужен Inventory |
| **Map button** | Кнопку карты, нужен Map |
| **Notices** | Короткие уведомления вроде «You got: Key» |

## Полезно знать

- Пустые настройки наследуют общие значения.
- Окно диалога можно расположить внизу, вверху, слева, справа или по центру. Настраиваются отступы, ширина и высота. Фон — цвет или изображение с режимом **Stretch**, **Fit** либо **9-slice**.
- Имя может быть внутри окна или на вкладке над ним. Цвет имени берётся у персонажа либо задаётся единым.
- Стили кнопок: **Pill**, **Rounded**, **Square**.
- **Reset** возвращает экран к исходным настройкам.
