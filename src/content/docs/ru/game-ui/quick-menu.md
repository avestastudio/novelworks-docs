**{ui.quickMenu.title}** — это небольшая панель «управления чтением поверх истории». Игроки могут нажимать её кнопки вместо клавиш.

![Настройки быстрого меню и предпросмотр панели в верхней части игры.](/novelworks-docs/screenshots/game-ui-quick-menu.png)

## Показать и разместить

- **{ui.quickMenu.enabled}**: по умолчанию включено. Выключите, чтобы скрыть всю панель.
- **{ui.quickMenu.position}**: вверху слева, вверху по центру (по умолчанию), вверху справа, внизу слева, внизу по центру или внизу справа.
- **{ui.quickMenu.margin}**: расстояние до краёв, от 0 до 10 % (по умолчанию 1,5).

## Внешний вид

- **{ui.gameUIInspector.buttonStyle}**: по умолчанию «Капсула».
- **{ui.quickMenu.textSize}**: от 60 до 140 % от базового размера текста (по умолчанию 80).
- **{ui.quickMenu.buttonColor}**: по умолчанию полупрозрачный тёмный фон. Ссылка возвращает значение по умолчанию.
- **{ui.gameUIInspector.textColor}**: по умолчанию «{tx.gameUIInspector.sameAsTheTextColor}».

## Видимые кнопки

Девять кнопок, у каждой свой переключатель. Их **порядок фиксирован**: их можно показывать или скрывать, но не переставлять.

| Кнопка | По умолчанию | Клавиша | Что делает |
|---|---|---|---|
| {ui.quickMenu.button.history} | вкл. | H | Открывает историю реплик. |
| {ui.quickMenu.button.auto} | вкл. | A | Включает или выключает режим «Авто». |
| {ui.quickMenu.button.skip} | вкл. | S | Включает или выключает режим пропуска. |
| {ui.quickMenu.button.save} | выкл. | | Открывает экран сохранения. |
| {ui.quickMenu.button.load} | выкл. | | Открывает экран загрузки. |
| {ui.quickMenu.button.quickSave} | выкл. | F5 | Быстрое сохранение. |
| {ui.quickMenu.button.quickLoad} | выкл. | F9 | Быстрая загрузка (серая, пока нет быстрого сохранения). |
| {ui.quickMenu.button.options} | выкл. | | Открывает настройки игрока. |
| {ui.quickMenu.button.menu} | выкл. | Esc | Открывает меню паузы. |

**{ui.quickMenu.shortcutsHelp}**

## Когда панель видна

Панель скрыта на титульном экране и на экране конца, пока открыто меню, история реплик, настройки, сохранение или загрузка, а также когда скрыты все кнопки. **{rt.game.quickLoad}** серая, пока нет быстрого сохранения. Кнопки «Авто» и «Пропуск» показывают, включены ли они.
