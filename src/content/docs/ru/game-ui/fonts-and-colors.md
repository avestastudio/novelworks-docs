**{ui.gameUI.fontsColors}** содержит то, что общее для всех экранов. Каждый другой экран может переопределить часть этих настроек.

## Текст

- **{ui.gameUIInspector.font}**: четыре шрифта, каждый показан в своём начертании.

| Название | Стиль | Шрифт | Лицензия |
|---|---|---|---|
| {ui.gameUIInspector.fontClean} (по умолчанию) | Современный шрифт без засечек | Inter | SIL Open Font License 1.1 |
| {ui.gameUIInspector.fontClassic} | Шрифт с засечками, для литературного вида | Lora | SIL Open Font License 1.1 |
| {ui.gameUIInspector.fontRounded} | Мягкий, дружелюбный | Nunito | SIL Open Font License 1.1 |
| {ui.gameUIInspector.fontTypewriter} | Печатная машинка | Courier Prime | SIL Open Font License 1.1 |

  Файлы шрифтов и тексты их лицензий входят в каждую экспортированную игру.

- **{ui.gameUIInspector.textColor}**: цвет текста во всей игре. По умолчанию он белый. Экраны, у которых указано «{tx.gameUIInspector.sameAsTheTextColor}», следуют за ним.

### Языки и шрифты

**{ui.gameUIInspector.fontClean}**, **{ui.gameUIInspector.fontClassic}** и **{ui.gameUIInspector.fontRounded}** поддерживают латиницу с диакритическими знаками, кириллицу и вьетнамский. Греческий поддерживает только **{ui.gameUIInspector.fontClean}**. **{ui.gameUIInspector.fontTypewriter}** поддерживает только латиницу (с диакритическими знаками). Для символов, которых нет в шрифте, например китайских и японских, игра использует системные шрифты игрока (а если язык игры японский, сначала японские системные шрифты).

Свой шрифт пока импортировать нельзя.

Игроки, которые включили в настройках шрифт для людей с дислексией, получают отдельный шрифт, что бы вы ни выбрали здесь.

## Появление и уход персонажей

«{ui.effects.defaultsTitle}»: выберите «{ui.effects.defaultEnter}» и «{ui.effects.defaultExit}» для всей игры. Они используются всякий раз, когда у момента нет собственного [эффекта](/novelworks-docs/ru/writing/effects/) для этого персонажа. По умолчанию стоит «{tx.effects.defaultNone}».

## Цвета и кнопки

- **{ui.gameUIInspector.primaryColor}**: «Кнопки, выделения и стрелка „продолжить“». Он же задаёт свечение титульного экрана. По умолчанию это розовый.
- **{ui.gameUIInspector.buttonStyle}**: **{ui.gameUIInspector.pill}** (полностью скруглённые, по умолчанию), **{ui.gameUIInspector.rounded}** (мягкие углы), **{ui.gameUIInspector.square}** (острые углы) или **{ui.gameUIInspector.text}** (без рамки, только слова). Он «используется во всех меню и выборах, если экран не выбрал свой».

Общего цвета фона нет: фоны задаются для каждого экрана отдельно.

## Предпросмотр

На предпросмотре этой страницы показано текстовое окно поверх вашего первого фона. Кнопка **{ui.gameUIMode.longTextAvatar}** поможет проверить длинные реплики.

## Сброс

**{ui.gameUIInspector.resetToDefault}** на этой странице сбрасывает только настройки этой страницы. Остальные экраны сохраняют свои настройки.
