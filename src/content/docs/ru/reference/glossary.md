---
title: Глоссарий
description: Слова, которые используются в NovelWorks и в этой документации.
---

| Слово | Значение |
|---|---|
| {ui.inspector.scene} | Глава вашей истории: ряд моментов, которые воспроизводятся один за другим. |
| Момент | Один шаг сцены: реплика, выбор, переход, концовка… |
| {ui.timeline.timeline} | Ряд карточек моментов внизу редактора. |
| На сцене (экран игры) | То, что есть на экране игры, как на театральной сцене: фон и персонажи. Переходит из одного момента в следующий. |
| Начальная сцена | Сцена, с которой начинается новая игра. Отмечена звездой. |
| Персонаж | Человек в вашей истории, у него есть цвет имени и эмоции. |
| Эмоция | Одна картинка персонажа для настроения (радость, грусть…). Картинка со звездой — по умолчанию. |
| {ui.gameUIInspector.avatar} | Маленький портрет рядом с именем персонажа в текстовом окне. |
| {ui.gameUIInspector.image} | Картинка в вашем проекте: фон, спрайт персонажа, CG, предмет декора, картинка интерфейса или аватар. |
| CG | Иллюстрация на весь экран для особого события. |
| Предмет декора | Картинка вещи: размещается в исследовании или служит картинкой предмета. |
| Переменная | То, что запоминает игра. *Счёт* — это число; *Факт* — это «да» или «нет». |
| {ui.moments.item} | То, что игрок носит с собой (функция «Инвентарь»). *Одиночный* (есть или нет) или *Складываемый* (несколько штук). |
| {ui.moments.choice} | Момент, где игрок выбирает один вариант из 2–6. |
| {ui.moments.condition} | Момент, невидимый для игроков: он проверяет, что запомнила игра, и переходит к сцене. В нём есть *случаи*, которые проверяются сверху вниз, и *иначе*. |
| {ui.moments.jump} | Невидимый момент, который сразу переходит к другой сцене. |
| {ui.moments.ending} | Момент, который показывает название концовки и возвращает на титульный экран. |
| {ui.moments.exploration} | Момент без текстового окна, где игрок щёлкает по *зонам* на картинке. |
| Зона | Область исследования, по которой можно щёлкнуть. На карте зона — это *место*. |
| Функция | Необязательная часть вашей игры, которую вы включаете в библиотеке «Функции»: «Инвентарь» или «Карта». |
| {ui.topBar.storyMap} | Вид всех сцен и связей между ними. |
| {ui.topBar.gameUI} | Режим, в котором вы меняете внешний вид игры. |
| Режим «Сценарий» | Вид сцены в виде текста, как в киносценарии. |
| Уведомление | Короткое сообщение в игре, например «Вы получили: Ключ». |
| {ui.quickMenu.title} | Небольшая панель управления чтением поверх истории. |
| Режим игры | Игра в вашу игру прямо в редакторе. |
| Резервная копия | Более ранняя копия файла `project.json`, хранится в папке `backups`. |
| Язык игры | Язык собственных кнопок и меню игры. Ваша история остаётся такой, как вы её написали. |
| {ui.languageDialog.label} | Язык самого редактора. |
