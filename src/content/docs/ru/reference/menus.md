NovelWorks использует обычные меню вашего компьютера. **Cmd** в Windows — это **Ctrl**. Некоторым пунктам нужен открытый проект, а большинство команд редактирования не действуют, пока вы играете.

## Меню приложения (только на Mac)

«О программе Novelworks», «Службы», «Скрыть Novelworks» (**Cmd+H**), **{ui.native.role.hideOthers}**, **{ui.native.role.unhide}**, «Завершить Novelworks» (**Cmd+Q**). В Windows пункт «Завершить» находится в конце меню «Файл», а «О программе» — в меню «Справка».

## Файл

| Пункт | Сочетание | Что делает |
|---|---|---|
| {ui.native.menu.newProject} | **Cmd+N** | Открывает экран нового проекта. |
| {ui.native.menu.openProject} | **Cmd+O** | Открывает папку проекта. |
| {ui.native.menu.save} | **Cmd+S** | Сохраняет проект. |
| {ui.native.menu.restoreFromBackup} | | Возвращает более раннюю версию. См. [Сохранение, резервные копии и отмена](/novelworks-docs/ru/getting-started/saving-and-undo/). |
| {ui.native.menu.importScript} | | Добавляет текстовый файл в ваши сцены. См. [Импорт и экспорт сценария](/novelworks-docs/ru/writing/import-a-script/). |
| {ui.native.menu.exportScript} | | Сохраняет всю вашу игру в виде текстового файла. |
| {ui.native.menu.exportForWeb} | **Cmd+E** | Экспортирует игру для веба. См. [Веб-экспорт](/novelworks-docs/ru/publish/web-export/). |
| {ui.native.menu.closeProject} | **Cmd+Shift+W** | Возвращает к экрану проектов. |

## Правка

| Пункт | Сочетание |
|---|---|
| {ui.native.menu.undo} | **Cmd+Z** |
| {ui.native.menu.redo} | **Shift+Cmd+Z** (в Windows: **Ctrl+Shift+Z**, а в редакторе ещё и **Ctrl+Y**) |
| {ui.native.menu.findAndReplace} | **Cmd+F** |
| Вырезать, Копировать, Вставить, Выбрать всё | **Cmd+X**, **Cmd+C**, **Cmd+V**, **Cmd+A** |
| {ui.native.spelling.spellingLanguage} | В Windows: языки вашего компьютера плюс английский или другой язык. На Mac macOS сама определяет язык вашего текста. Сохраняется в проекте. |

«Отменить» и «Повторить» действуют на проект, кроме поля названия на экране нового проекта.

## Вид

- **{ui.native.menu.theme}**: {ui.native.menu.dark}, {ui.native.menu.light} или {ui.native.menu.system}.
- **{ui.native.menu.language}**: {ui.native.menu.languageAuto} или один из семи языков.
- **{ui.native.role.togglefullscreen}** (**Control+Cmd+F** на Mac).

Пункты для разработчиков (Reload, Toggle Developer Tools) есть только в сборках для разработки, а в выпущенном приложении их нет.

## Окно

На Mac: «Свернуть», «Масштаб» и «Все окна — на передний план»; в Windows: «Свернуть» и «Закрыть окно».

## Справка

| Пункт | Что делает |
|---|---|
| {ui.menu.documentation} | Открывает эту документацию в вашем браузере. |
| {ui.native.menu.replayTutorial} | Запускает [обучающий тур](/novelworks-docs/ru/getting-started/guided-tour/) заново. |
| {ui.native.menu.keyboardShortcuts} (**Cmd+/**) | Показывает список сочетаний клавиш. |
| {ui.native.menu.activateNovelWorks} | Только в полной версии с itch.io. См. [Установка и активация](/novelworks-docs/ru/getting-started/install-and-activate/). |
| {ui.native.menu.reportABug} | Открывает форму обратной связи. См. [Сообщить об ошибке](/novelworks-docs/ru/reference/report-a-bug/). |
| О программе Novelworks | Только в Windows: окно «О программе». |

## Меню экрана проектов

На экране проектов работают только команды меню «новый проект», «открыть проект», About, сочетания клавиш и «Отменить»/«Повторить» (для поля названия).
