---
title: "Частые вопросы"
description: "Короткие ответы."
---

**Нужно уметь программировать?** Нет. NovelWorks создан для тех, кто не пишет код.

**Кому принадлежат мои игры?** Полностью вам, без роялти.

**Где находится проект?** В папке, выбранной при создании. Щёлкните по названию проекта: путь указан в **Saved in**.

**Можно сделать полную игру в демоверсии?** Да. Полная версия нужна только для экспорта.

**Пропало изменение.** Попробуйте **Undo**, затем **File → Restore from Backup…**.
