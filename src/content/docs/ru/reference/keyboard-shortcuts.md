Ниже указаны клавиши Mac. В Windows используйте **Ctrl** вместо **Cmd**. Список также есть в **Help → Keyboard Shortcuts** (**Cmd/Ctrl+/**).

## Редактор

| Действие | Клавиши |
|---|---|
| Сохранить | Cmd+S |
| Отменить / повторить | Cmd+Z / Shift+Cmd+Z (Windows: Ctrl+Y) |
| Играть с титульного экрана | Cmd+P |
| Играть с выбранного момента | Shift+Cmd+P |
| Поиск и замена | Cmd+F |
| Экспорт для браузера | Cmd+E |
| Новый проект / открыть | Cmd+N / Cmd+O |
| Новый диалог после текущего момента | Cmd+Enter |
| Дублировать момент | Cmd+D |
| Удалить момент, персонажа, зону или объект сцены | Delete или Backspace |
| Предыдущий / следующий момент | ← / → (Cmd+[ и Cmd+] работают и при вводе текста) |
| Первый / последний момент | Home / End |
| Scenes, Assets, Characters, Variables | Cmd+1, 2, 3, 4 |
| Game UI | Cmd+5 |
| Story map | Cmd+6 |
| Следующая реплика при вводе | Enter |
| Новая строка в том же окне | Shift+Enter |

## Игра

| Действие | Клавиши |
|---|---|
| Продолжить | Щелчок, Space или Enter |
| Выбрать вариант | 1–6 |
| Меню паузы | Esc или правая кнопка мыши |
| Быстро сохранить / загрузить | F5 / F9 |
| History | H или колесо вверх |
| Auto | A |
| Skip | S или удерживать Ctrl |
| Inventory | I |
| Map | M |
