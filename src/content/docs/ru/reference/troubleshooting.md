## Открытие проекта

| Сообщение | Что это значит и что делать |
|---|---|
| «… — не проект Novelworks: в нём нет файла project.json.» | В выбранной папке нет `project.json`. Выберите саму папку проекта. |
| «Файл project.json повреждён: это некорректный JSON.» | Файл изменили или он оборван. Откройте резервную копию: скопируйте файл из `backups` поверх `project.json` (повреждённый файл сохраните отдельно). |
| "This project was saved by a newer version of Novelworks (format N). Please update Novelworks to open it." | Установите последнюю версию NovelWorks. Ничего не изменено. |
| «Novelworks не смог сохранить резервную копию проекта перед обновлением, поэтому проект не был открыт. Ваш проект не изменён.» | В папку нельзя записывать. Проверьте права доступа и свободное место, затем откройте проект снова. |
| «{tx.projectHub.folderNotFound}» (экран проектов) | Папку проекта переместили или удалили. Нажмите **{ui.projectHub.locate}** и выберите её новое место. |

## Активация

| Сообщение | Что делать |
|---|---|
| Сначала вставьте ключ загрузки. | Вставьте ключ в поле. |
| NovelWorks не удалось связаться с сервером активации. | Проверьте подключение к интернету и попробуйте снова. Для активации и деактивации он нужен. |
| Это не ключ загрузки NovelWorks. | Скопируйте его ещё раз со страницы загрузки или из письма о покупке. |
| Этот ключ уже активирован на 3 компьютерах. | Деактивируйте NovelWorks на другом компьютере или нажмите **{ui.activateDialog.contactUs}** в окне. |
| Активация сейчас не работает. Попробуйте через несколько минут. | Временная неполадка на стороне сервера. |
| Деактивация сейчас не работает. Попробуйте через несколько минут. | То же самое, при деактивации. |

## Когда в истории что-то выглядит неправильно

- Сцена с пометкой **{ui.scenesTab.unreachable}**, треугольник на карточке или рамка «{tx.branchInspectors.thisMomentNeedsYourAttention}»: см. [Проблемы: все предупреждения](/novelworks-docs/ru/testing/problems/).
- Персонаж пропал с экрана: персонажи остаются на сцене, пока что-то их не изменит, и уходят, когда так сказано в моменте. См. [Сцена](/novelworks-docs/ru/concepts/stage/).
- Не виден вариант выбора: возможно, у него есть условие. См. [Выбор](/novelworks-docs/ru/branching/choices/).
- История пропускает «Если…»: условие проверяет то, что было удалено. См. [Условия «Если…»](/novelworks-docs/ru/branching/conditions/).
