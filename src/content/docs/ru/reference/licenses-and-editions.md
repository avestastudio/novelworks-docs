## Ваши игры принадлежат вам

В окне «О программе» NovelWorks сказано: «{tx.aboutDialog.makeVisualNovelsWithoutCodeYourGames}» Шрифты, включённые в ваши игры, сохраняют свои открытые лицензии (см. ниже).

## Версии

| | Демо | Полная версия |
|---|---|---|
| Весь редактор, режим игры, режим сценария, интерфейс игры | да, с ограничениями ниже | да |
| Экспорт для веба | до 5 сцен и в пределах ограничений ниже, с отметкой в экспортированной игре | любого размера, без отметки |
| Нужен ключ загрузки | нет | да, для экспорта (полная версия с itch.io). Изданию для Steam ключ не нужен. |

См. [Бесплатная демоверсия](/novelworks-docs/ru/getting-started/demo-edition/) и [Установка и активация](/novelworks-docs/ru/getting-started/install-and-activate/). Обе версии читают и записывают один и тот же формат проекта.

## Ограничения демоверсии

| В демоверсии | Не больше |
|---|---|
| Персонажи | 3 |
| Наряды на персонажа | 2 |
| Планы камеры на момент | 2 |
| Звуковые файлы | 5 |
| Переменные | 5 |
| Предметы | 3 |
| Эффекты | по 2 в каждой из категорий: появления, уходы, реакции, экран и переходы |
| Частицы | Дождь и снег |

Эти ограничения лишь не дают добавить больше. Ничего не теряется, и в полной версии проект продолжается как есть. Проект, который выходит за эти рамки, всё равно открывается в демоверсии, но экспортировать его из неё нельзя.

## Активация

Полная версия просит **ключ загрузки**, который приходит вместе с покупкой. Без него вы можете открывать и редактировать свои проекты и играть в них. Заблокирован только экспорт. В окне активации сказано, что ключ работает на 3 компьютерах и его можно деактивировать, чтобы перенести на другой. NovelWorks проверяет лицензию на вашем компьютере при каждом запуске, поэтому экспорт работает и без интернета.

Состояние лицензии можно увидеть в окне «О программе» («{tx.aboutDialog.activated}{tx.aboutDialog.manage}» или «{tx.aboutDialog.notActivated}{tx.aboutDialog.activateNovelWorks}»).

## Что входит в экспортированную игру

- Ваша игра, ваши картинки, видео, звуки и текст.
- Шрифты вашего интерфейса игры и шрифт для людей с дислексией вместе с файлами их лицензий. Шрифты игры (Inter, Lora, Nunito и Courier Prime) и шрифт для людей с дислексией — бесплатные шрифты с собственными открытыми лицензиями (для четырёх основных шрифтов это SIL Open Font License).
- Короткий экран «Made with NovelWorks» при запуске игры.
- В игре, экспортированной из демо, — экран «Made with NovelWorks Demo» и маленький логотип «NovelWorks Demo» в углу во время игры.

## Установщики для Windows и macOS

Приложение для Mac пока не подписано идентификатором Apple Developer ID. См. [Установка и активация](/novelworks-docs/ru/getting-started/install-and-activate/).
