---

История уже написана в текстовом файле? Откройте **File → Import Script…**.

## Формат

```
# Весеннее утро
Миа: Привет!
Шёл дождь.
Аой: Эй… ты в порядке?
```

- Строка с **#** в начале создаёт сцену.
- **Имя: текст** — реплика этого персонажа.
- Без имени строку произносит **Narrator**.
- Пустые строки игнорируются.

## Порядок действий

1. Вставьте сценарий слева. **Preview** покажет создаваемые сцены, реплики и новых персонажей.
2. Снимите отметки с имён, которые не должны стать персонажами: они останутся в тексте рассказчика.
3. Выберите место вставки и импортируйте.

**Undo** позволяет отменить импорт.
