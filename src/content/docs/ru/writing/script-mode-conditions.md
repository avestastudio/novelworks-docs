Эта страница продолжает статью [Режим «Сценарий»: все виды строк](/novelworks-docs/ru/writing/script-mode-lines/). В примерах используются английские слова; NovelWorks одновременно понимает и слова других языков редактора.

## Переходы

```
-> Park
```

Переход к сцене с именем Park. Игроки этот момент не видят. Если написать `->` без имени, это переход, у которого ещё нет сцены.

## Выбор

```
? What now?
- Talk to her -> Park
- Leave
```

- Строка, которая начинается с `?`, — это вопрос. Он необязателен: строка с `-` без вопроса перед ней начинает выбор без вопроса.
- Каждая строка, которая начинается с `-`, — это вариант. `-> Park` после текста — это сцена, к которой ведёт вариант (часть после **последнего** `->`). Вариант без `->` позволяет истории идти дальше.
- Выбор, состоящий только из вопроса и без вариантов, читается именно так. Чтобы выбор работал в игре, нужно минимум два варианта.

### Что меняет вариант

Строки с отступом под вариантом — это то, что он меняет:

```
- Give her the flower -> Park
  + Affection 1
  = MetMia true
  give : Key
  remove : Coin
```

| Строка | Значение |
|---|---|
| `+ Affection 1` | Прибавляет 1 к счёту Affection. |
| `= MetMia true` | Задаёт значение MetMia. Значение — число либо `true` / `false` (`yes` / `no` тоже подойдут). |
| `give : Key` (`give : Key x3`) | Даёт игроку предмет. |
| `remove : Key` | Забирает предмет. |

Любая другая строка с отступом помечается и игнорируется.

### Вариант, который появляется не всегда

```
- Open the door -> Hall
  if item Key, locked
```

Строка `if` с отступом под вариантом говорит, когда он доступен. Добавьте `, locked`, чтобы недоступный вариант показывался серым. Без этого он скрыт. См. [Как ветвится история](/novelworks-docs/ru/concepts/how-stories-branch/): у игроков всегда остаётся путь дальше.

## Проверки

Условие проверяет переменную или предмет:

| Проверка | Значение |
|---|---|
| `Affection >= 3` | Счёт Affection не меньше 3. |
| `MetMia = true` | Факт MetMia — «Да». |
| `item Key` | У игрока есть Key. |
| `item Coin x3` | У игрока не меньше 3 Coin. |
| `without Key` | У игрока нет Key. |

Для счёта можно использовать `=` (или `==`), `!=` (или `≠`), `>`, `>=` (или `≥`), `<` и `<=` (или `≤`). Для факта — `=` и `!=`. Число с десятичной запятой принимается.

## Условия: момент «Если…»

```
if Affection >= 3 -> Park, else -> Nothing
```

Куда идти, если условие выполняется, и, после `, else ->`, куда идти, если нет. Обе части необязательны. Игроки этот момент не видят.

### Несколько случаев

Пишите каждый случай на отдельной строке. Побеждает первый случай, который выполняется:

```
if Affection >= 5 -> Park
else if Affection >= 2 -> Station
else -> Nothing
```

- `else if …` добавляет случай. `else -> …` — это то, куда идти, когда ни один случай не выполняется.
- Эти строки должны идти подряд, без пустой строки между ними, и после последнего `else` ничего быть не может. Строка `else`, которая не продолжает условие, — обычный текст.
- Если после последнего `else` сцена не указана, история продолжается со следующего момента.

![Момент «Если…» проверяет случай 1, затем случай 2, затем переходит к «иначе».](/novelworks-docs/diagrams/if-order.svg)

### Несколько проверок в одном случае

```
if Affection >= 3 and item Key -> Park
if MetMia = true or item Letter -> Library
```

Используйте `and`, когда должны выполняться все проверки, и `or`, когда достаточно одной. **Не смешивайте `and` и `or` в одной строке:** NovelWorks помечает такую строку и использует только первый вид.

## Если имени ещё нет

Неизвестная сцена, переменная или предмет подчёркиваются. Быстрое исправление или кнопка **{ui.scriptMode.createMissing_other}** создаёт их. См. [Режим «Сценарий»: основы](/novelworks-docs/ru/writing/script-mode/).
