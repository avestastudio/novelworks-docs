В режиме «Сценарий» **одна строка — это одно событие**. В примерах используются английские слова. NovelWorks одновременно понимает и слова других языков редактора (`si`, `décor`, `fin`…). Заглавные буквы, диакритические знаки и лишние пробелы не важны, когда NovelWorks читает ключевое слово или имя.

О выборах, условиях и переходах читайте в статье [Режим «Сценарий»: условия и выбор](/novelworks-docs/ru/writing/script-mode-conditions/).

## Диалог

```
Mia : Hello!
```

Строка `Name : text` — это реплика, которую произносит этот персонаж. Пробелы вокруг двоеточия необязательны. Если персонажа с таким именем нет, вся строка читается как слова рассказчика и помечается, а быстрое исправление предлагает создать персонажа.

### С эмоцией

```
Mia (happy) : Hello!
```

Мия говорит с эмоцией «happy». Если она уже на сцене, она меняет эмоцию и остаётся на своём месте. Если её нет на сцене, она появляется в центре.

### Текст в несколько строк

```
Mia : I looked for you everywhere.
  I had given up hope.
```

Строка с отступом в два пробела продолжает строку выше как новую строку **в том же окне**.

Чтобы оформить слова или добавить паузу внутри реплики, см. [Оформление текста](/novelworks-docs/ru/writing/rich-text/).

## Слова рассказчика

```
It had been raining since morning.
```

Любая строка, которая не относится к другим видам, — это слова рассказчика.

### Строка, оставленная как есть

```
> background : this is just text
```

Строка, которая начинается с `>`, — это слова рассказчика **ровно в том виде, как написано**, даже если она похожа на команду. NovelWorks сам ставит `>`, когда иначе текст был бы прочитан неверно.

## Заметки

```
// to re-read
Mia : Hello!
```

Строка, которая начинается с `//`, — это личная заметка к следующему моменту. В игре она никогда не показывается. См. [Заметки](/novelworks-docs/ru/writing/notes/).

## Строки сцены

Эти строки не создают отдельный момент: они меняют сцену, начиная со следующей строки.

```
background : Station
show : Mia happy left
hide : Mia
hide : everyone
```

- **`background : Name`** меняет фон на картинку с именем Name. `background : none` или пустое место после двоеточия убирает фон.
- **`show : Mia happy left`** показывает персонажа или меняет его эмоцию или место. После имени можно добавить эмоцию, слово `outfit` с названием наряда (`outfit default` возвращает к первому наряду; см. [Наряды и гардероб](/novelworks-docs/ru/writing/outfits/)) и место: `left`, `center` или `right`, либо `placed by hand`, чтобы оставить свободное размещение. Если место не указано, персонаж, который уже на сцене, остаётся на своём месте, а новый встаёт в центр. Имя персонажа может содержать пробелы.
- **`hide : Mia`** убирает персонажа со сцены. `hide : everyone` или пустое место после двоеточия очищает сцену.

После строки сцены должна идти ещё одна строка. Иначе она помечается.

## Предметы

```
give : Key
give : Key x3
remove : Key
give : Key, no notice
```

Момент, в котором игрок получает предмет или теряет его. `x3` — это количество (знак × тоже подойдёт). `take :` означает то же, что `remove :`. `, no notice` скрывает короткое уведомление, которое игрок обычно видит. Предметы — это функция вашей игры, см. [Инвентарь](/novelworks-docs/ru/features/inventory/).

## Открыть карту

```
map
```

Строка из одного слова `map` открывает карту (момент «Показать карту»). См. [Карта](/novelworks-docs/ru/features/map/).

## Концовки

```
end : Good ending
  You understood everything.
```

Концовка с названием после двоеточия. Строки с отступом ниже — необязательный короткий текст. `ending :` тоже работает. Если персонажа случайно зовут «End», он главнее ключевого слова, если только вы не напишете команду в скобках.

## Моменты исследования

```
exploration : 3 zones
```

Режим «Сценарий» показывает момент исследования как одну строку с числом зон. Создавать или править зоны здесь нельзя: исследование редактируется в инспекторе, а момент сохраняет свои зоны и предметы декора, когда вы правите остальной текст. Новая строка `exploration` начинается пустой. См. [Исследование](/novelworks-docs/ru/features/exploration/).

## Заголовки (текст всей игры)

```
# Park
```

В тексте всей игры строка, которая начинается с `#`, начинает сцену с этим именем.

## Скобки

Строку-команду можно заключить в квадратные скобки: `[background : Station]` — то же самое, что `background : Station`. Скобки всегда означают «это команда». Они нужны только тогда, когда у персонажа то же имя, что и у команды: если у вас есть персонаж по имени Background, пишите `[background : Station]` для команды и `Background : Hi!` для персонажа.

## Краткая справка

| Вы пишете | Что происходит |
|---|---|
| `Mia : Hello!` | Мия говорит. |
| `Mia (happy) : Hello!` | Мия говорит с эмоцией. |
| `It rained.` | Слова рассказчика. |
| `  more text` | Текст продолжается в том же окне. |
| `> text` | Строка, оставленная как есть. |
| `// note` | Личная заметка к следующему моменту. |
| `background : Station` | Фон меняется с этого места. |
| `show : Mia happy left` | Персонаж появляется или меняется. |
| `hide : Mia` | Персонаж уходит. |
| `give : Key x3` / `remove : Key` | Даёт или забирает предмет. |
| `map` | Открывает карту. |
| `end : Good ending` | Концовка. |
| `-> Park` | Переход к сцене. |
| `? …`, `- …`, `if …` | Выбор и условия: см. следующую страницу. |
| `# Park` | Сцена (только в тексте всей игры). |
