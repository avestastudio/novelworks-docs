---
title: "Изображения и ресурсы"
description: "Импортируйте и упорядочивайте изображения."
---

Во вкладке **Assets** находятся все изображения игры. Перетащите файлы в окно для импорта.

| Категория | Назначение |
|---|---|
| **Background** | Фон за персонажами |
| **Sprite** | Изображения персонажей |
| **CG** | Полноэкранные иллюстрации событий, используемые как фон |
| **Prop** | Изображения объектов для моментов исследования |
| **UI** | Изображения интерфейса: окно диалога, логотип, кнопки |
| **Avatar** | Небольшой портрет рядом с именем говорящего |

Фильтры сверху позволяют показать одну категорию.

Изображения копируются в `assets` внутри проекта. При удалении они перемещаются в резервные копии, чтобы их можно было восстановить.
