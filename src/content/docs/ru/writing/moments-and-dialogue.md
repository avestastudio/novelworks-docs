Сцена состоит из **моментов** на временной шкале. Каждый момент хранит оформление — фон и персонажей — и один тип содержимого.

## Типы моментов

| Тип | Действие |
|---|---|
| **Dialogue** | Реплика или повествование |
| **Choice** | Выбор, который может изменить переменные и вести в другую сцену |
| **Condition** | Невидимая проверка, выбирающая одну из сцен |
| **Jump** | Невидимый прямой переход в другую сцену |
| **Ending** | Показывает название концовки и возвращает к титульному экрану |
| **Exploration** | Кликабельные зоны без окна диалога |
| **Item** | Выдаёт или забирает предметы; нужен Inventory |
| **Show map** | Открывает карту; нужен Map |

## Написание диалога

1. Выберите момент и щёлкните по окну текста или нажмите **+ Dialogue**.
2. Выберите говорящего в поле имени либо оставьте **Narrator**.
3. Введите реплику.

**Enter** создаёт следующую реплику с той же расстановкой. **Shift+Enter** переносит строку внутри окна. **Cmd/Ctrl+Enter** добавляет момент диалога даже во время ввода.

## Расстановка

Каждый момент запоминает свой фон и персонажей. Над экраном:

- Выберите фон. **Apply to the following moments** копирует его в следующие моменты.
- **+ Character** добавляет персонажа.

Щёлкните по персонажу, чтобы переместить его, изменить размер за угловые маркеры, отразить, сменить выражение или порядок слоёв. **Left**, **Center** и **Right** размещают его одним нажатием.

## Заметки

У каждого момента может быть личная заметка. Она не появляется в игре и не экспортируется.

## Навигация

Используйте **← →**, **Home**, **End** или щёлкните по карточке.
