## Какой файл скачать?

| Компьютер | Файл |
|---|---|
| Mac с чипом Apple Silicon (M1, M2, M3, M4…) | `Novelworks-<version>-mac-arm64.dmg` |
| Mac с процессором Intel | `Novelworks-<version>-mac-x64.dmg` |
| Windows 10 / 11 | `Novelworks-<version>-win-x64.exe` |

У бесплатной демоверсии те же три файла, только после номера версии стоит `-demo` (например, `Novelworks-<version>-demo-win-x64.exe`). Смотрите [бесплатную демоверсию](/novelworks-docs/ru/getting-started/demo-edition/).

Не знаете, какой у вас Mac? Откройте меню Apple → «Об этом Mac». Если там написано «Чип: Apple M…», это Apple Silicon.

## Первый запуск

### На Mac

Приложение для Mac пока **не подписано сертификатом Apple Developer ID** (у него только ad-hoc подпись), поэтому при первом запуске macOS может отказаться его открыть и показать предупреждение. Точные шаги зависят от вашей версии macOS.

1. Откройте файл `.dmg` и перетащите значок Novelworks в папку «Программы».
2. Откройте приложение из папки «Программы».
3. Если macOS его блокирует, найдите в разделе «Системные настройки → Конфиденциальность и безопасность» сообщение о Novelworks с кнопкой, которая всё равно открывает приложение. В более старых версиях macOS обычно нужно щёлкнуть приложение правой кнопкой мыши и выбрать «Открыть».

### В Windows

Запустите файл `.exe`. Установщик позволяет выбрать папку установки, устанавливает программу только для вашего пользователя и добавляет ярлык на рабочий стол. Если при запуске Windows показывает предупреждение безопасности, обычно в нём есть способ всё равно запустить программу. Формулировка зависит от вашей версии Windows.

## Выберите язык редактора

При самом первом запуске NovelWorks спрашивает «{ui.languageDialog.title}». Выберите язык и нажмите кнопку «{ui.languageDialog.continue}». Если вместо этого закрыть окно, NovelWorks будет использовать язык вашего компьютера. Позже его можно сменить в меню «{ui.menu.view} → {ui.native.menu.language}». После этого вы увидите [экран проектов](/novelworks-docs/ru/getting-started/projects-screen/).

## Активация NovelWorks (полная версия)

Полная версия запрашивает **ключ загрузки**, который приходит вместе с покупкой. Без него вы по-прежнему можете открывать и редактировать свои проекты и играть в них. Заблокирован только **экспорт**: команда экспорта в меню «Файл» открывает окно активации.

1. Откройте «{ui.native.role.help} → {ui.native.menu.activateNovelWorks}». То же окно открывается с экрана проектов и из окна «О программе».
2. Вставьте ключ загрузки в поле «{ui.activateDialog.downloadKey}». Можно вставить и весь адрес вашей страницы загрузки.
3. Нажмите кнопку «{ui.activateDialog.activate}».

Где найти ключ: откройте письмо о покупке в браузере, затем откройте страницу загрузки NovelWorks и скопируйте ключ загрузки или адрес страницы.

![Окно активации NovelWorks с пустым полем ключа загрузки](/novelworks-docs/screenshots/activate-novelworks.png)

Полезно знать:

- Для активации нужно связаться с сервером активации, поэтому нужен интернет. После активации NovelWorks при каждом запуске проверяет лицензию на вашем компьютере, так что экспортировать можно и без интернета.
- В окне активации сказано, что **один ключ работает на 3 компьютерах** и что можно деактивировать один компьютер, чтобы использовать ключ на другом. Для этого откройте то же окно и нажмите кнопку «{ui.activateDialog.deactivateThisDevice}». Это тоже связывается с сервером, поэтому нужен интернет.
- Если окно сообщает, что ключ уже активирован на максимальном числе компьютеров, деактивируйте NovelWorks на другом компьютере или воспользуйтесь кнопкой «{ui.activateDialog.contactUs}» в окне.

Если активация не удалась, в окне появится сообщение о том, что делать. Смотрите также [ЧаВо](/novelworks-docs/ru/reference/faq/).
