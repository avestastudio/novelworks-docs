## Какой файл скачать?

| Компьютер | Файл |
|---|---|
| Mac с Apple Silicon (M1, M2, M3, M4…) | `Novelworks-<version>-mac-arm64.dmg` |
| Mac с Intel | `Novelworks-<version>-mac-x64.dmg` |
| Windows 10 / 11 | `Novelworks-<version>-win-x64.exe` |

Чтобы узнать модель Mac, откройте меню Apple → **Об этом Mac**. Надпись «Чип: Apple M…» означает Apple Silicon.

## Первый запуск

У NovelWorks пока нет подписи платным сертификатом Apple или Microsoft, поэтому при первом запуске может появиться предупреждение системы.

### Mac

1. Откройте `.dmg` и перетащите **Novelworks** в **Программы**.
2. Запустите приложение. Если macOS сообщает, что не может его проверить, нажмите **Готово**.
3. В macOS 15 Sequoia и новее откройте **Системные настройки → Конфиденциальность и безопасность**, найдите сообщение о Novelworks и разрешите открытие. В старых версиях щёлкните по приложению правой кнопкой и выберите **Открыть**.

### Windows

1. Запустите `.exe`.
2. Если появится окно **Система Windows защитила ваш компьютер**, нажмите **Подробнее**, затем **Выполнить в любом случае**.
3. Следуйте инструкциям установщика.

## Активация полной версии

Нужен **ключ загрузки** из покупки на itch.io. Без активации можно открывать, редактировать и тестировать проекты, но **File → Export for Web** недоступен.

1. Откройте **Help → Activate NovelWorks…**. Этот пункт также есть на приветственном экране и в **About**.
2. Вставьте ключ из покупки itch.io.
3. Нажмите **Activate**.

- Один ключ работает максимум на **3 компьютерах**.
- После активации приложение работает **без интернета**.
- Чтобы освободить место, например перед продажей компьютера, нажмите **Deactivate this device** в том же окне.
- При достижении лимита воспользуйтесь **Contact us**.
