Настройки бывают двух видов: настройки **редактора** (одинаковые для всех ваших проектов) и настройки одного **проекта**.

## Настройки редактора

Все они находятся в меню «{ui.menu.view}» и «{ui.native.menu.edit}».

### Тема

«{ui.menu.view} → {ui.native.menu.theme}»: «{ui.native.menu.dark}» (по умолчанию), «{ui.native.menu.light}» или «{ui.native.menu.system}» (как на вашем компьютере).

### Язык редактора

«{ui.menu.view} → {ui.native.menu.language}»: «{ui.native.menu.languageAuto}» или один из семи языков, каждый записан своим названием. Меню и редактор сразу меняются во всех открытых окнах. Эта настройка касается только редактора. Она не меняет вашу историю и язык вашей игры.

### Язык проверки орфографии (сохраняется в проекте)

Это исключение: настройка не общая для всех ваших проектов, потому что выбор сохраняется **в проекте** (и его можно отменить).

«{ui.native.menu.edit} → {ui.native.spelling.spellingLanguage}». В Windows по умолчанию используются языки вашего компьютера плюс английский, и можно выбрать другой язык. На Mac macOS сама определяет язык вашего текста, поэтому меню только сообщает об этом.

### Полноэкранный режим

«{ui.menu.view} → {ui.native.role.togglefullscreen}».

## Настройки проекта

Щёлкните название проекта на верхней панели или ничего не выбирайте, и инспектор покажет «{ui.inspector.projectSettings}»:

| Настройка | Что она делает |
|---|---|
| {ui.projectSettings.gameTitle} | Название вашей игры. |
| {ui.projectSettings.author} | Ваше имя как автора. |
| {ui.project.gameLanguage} | Язык кнопок и меню самой игры. Текст вашей истории остаётся таким, как вы его написали. Если для игры нет какого-то языка, игра использует для него английский. |
| {ui.projectSettings.length} | Сколько читать историю: каждая реплика, выбор и концовка, прочитанные по одному разу (слова и минуты). Это только показывается и не настраивается. Прохождение ветвящейся истории короче. |
| {ui.projectSettings.features} | Включённые необязательные части. Кнопка «{ui.projectSettings.openFeatures}» открывает список, чтобы их переключать. |
| {ui.projectSettings.screenSize} | Размер экрана игры, 1280 × 720 пикселей. Это только показывается. |
| {ui.projectSettings.savedIn} | Папка проекта. |

Любое изменение здесь можно отменить командой «{ui.native.menu.undo}».
