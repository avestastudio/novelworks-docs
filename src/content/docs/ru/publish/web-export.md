---
title: "Экспорт для браузера"
description: "Создайте веб-версию игры."
---

Выберите **File → Export for Web (itch.io)…** (**Cmd/Ctrl+E**) и папку. NovelWorks создаст `.zip` для itch.io. Полная itch.io-версия должна быть активирована.

Игра начинается с экрана «**Made with NovelWorks**» примерно на 3 секунды. Его можно пропустить щелчком, касанием или клавишей.

Заметки, описания сцен и состояния текста не экспортируются.
