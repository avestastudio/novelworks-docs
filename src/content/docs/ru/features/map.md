Включите **Map** в [Features](/novelworks-docs/ru/features/features-panel/) и нажмите **Edit map**, чтобы открыть рабочую область карты.

## Создание карты

1. Добавьте фон.
2. Нажмите **Add location** и нарисуйте зону.
3. Назовите место, например «Кафе». По умолчанию название видно при наведении.
4. Выберите сцену, которая начнётся при нажатии. Её можно создать прямо из этого поля.
5. Проверьте результат через **Test map**.

## Когда карта доступна?

В настройках выберите, когда игроки смогут пользоваться кнопкой карты:

- **From the start**: кнопка Map доступна с начала игры.
- **After first shown**: кнопка появляется, когда история впервые достигает момента **Show map**.
- **Story only**: кнопки Map нет; карту открывают только моменты **Show map**.

## Моменты Show map

**Show map** сразу открывает карту и предлагает выбрать место назначения. Карту, открытую кнопкой **Map**, можно закрыть и продолжить чтение.

## Заблокированные места

Условие может скрыть или заблокировать место, показав сообщение при блокировке.
