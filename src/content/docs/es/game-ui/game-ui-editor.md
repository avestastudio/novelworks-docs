---
title: "El editor Game UI"
description: "Personaliza cada pantalla del juego."
---

Pulsa **Game UI** (**Cmd/Ctrl+5**). Elige una pantalla a la izquierda, edítala a la derecha y ve el resultado en el centro.

| Pantalla | Qué controla |
|---|---|
| **Fonts & colors** | Tipografía y colores generales |
| **Title screen** | Pantalla de título |
| **Dialogue box** | Nombres y diálogos |
| **Choices** | Botones de las elecciones |
| **Pause menu** | Menú abierto con Esc o clic derecho |
| **Save & load** | Pantallas de guardar y cargar |
| **History** | Líneas ya leídas |
| **The End** | Pantalla de final |
| **Inventory** | Botón y panel de objetos, con Inventory |
| **Map button** | Botón del mapa, con Map |
| **Notices** | Avisos breves como «You got: Key» |

## Consejos

- Los ajustes vacíos heredan los valores globales.
- El cuadro de diálogo puede ir abajo, arriba, a izquierda, derecha o en el centro, con márgenes, anchura y altura ajustables. El fondo puede ser un color o una imagen: **Stretch**, **Fit**, **9-slice**.
- La etiqueta del nombre puede ir dentro o sobre el cuadro. El color puede seguir al personaje o ser común.
- Estilos de botón: **Pill**, **Rounded**, **Square**.
- **Reset** restaura los valores predeterminados de la pantalla.
