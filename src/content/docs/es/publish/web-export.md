---
title: "Exportar para la web"
description: "Crea un juego para el navegador."
---

Elige **File → Export for Web (itch.io)…** (**Cmd/Ctrl+E**) y una carpeta. NovelWorks crea un `.zip` listo para itch.io. La edición completa de itch.io debe estar activada.

El juego empieza con «**Made with NovelWorks**» durante unos 3 segundos. Se puede omitir con un clic, un toque o una tecla.

No se exportan notas, resúmenes de escenas ni estados de escritura.
