---
title: "Glosario"
description: "Las palabras que se usan en NovelWorks y en esta documentación."
---

| Palabra | Significado |
|---|---|
| {ui.inspector.scene} | Un capítulo de tu historia: una serie de momentos que se reproducen uno tras otro. |
| Momento | Un paso de una escena: una línea de diálogo, una elección, un salto, un final… |
| {ui.timeline.timeline} | La fila de tarjetas de momentos en la parte inferior del editor. |
| Escenario | Lo que hay en la pantalla del juego: el fondo y los personajes. Pasa de un momento al siguiente. |
| Escena inicial | La escena donde empieza una partida nueva, marcada con una estrella. |
| Personaje | Una persona de tu historia, con un color de nombre y expresiones. |
| Expresión | Una imagen de un personaje para un estado de ánimo (feliz, triste…). La que tiene una estrella es la predeterminada. |
| {ui.gameUIInspector.avatar} | Un pequeño retrato que se muestra junto al nombre del personaje en el cuadro de diálogo. |
| {ui.gameUIInspector.image} | Una imagen de tu proyecto: un fondo, un sprite de personaje, un CG, un objeto decorativo, una imagen de la interfaz o un avatar. |
| CG | Una ilustración a pantalla completa para un acontecimiento especial. |
| Objeto decorativo | Una imagen de un objeto, colocada en una exploración o usada como imagen de un objeto. |
| Variable | Algo que el juego recuerda. Una *Puntuación* es un número; un *Hecho* es sí o no. |
| {ui.moments.item} | Algo que lleva el jugador (función Inventario). *Único* (lo tiene o no) o *Acumulable* (varios). |
| {ui.moments.choice} | Un momento en el que el jugador elige una opción entre 2 y 6. |
| {ui.moments.condition} | Un momento, invisible para los jugadores, que comprueba lo que el juego recuerda y va a una escena. Tiene *casos*, que se comprueban de arriba abajo, y un *si no*. |
| {ui.moments.jump} | Un momento invisible que va directamente a otra escena. |
| {ui.moments.ending} | Un momento que muestra el nombre del final y vuelve a la pantalla de título. |
| {ui.moments.exploration} | Un momento sin cuadro de texto en el que el jugador hace clic en *zonas* de una imagen. |
| Zona | Un área en la que se puede hacer clic en una exploración. En el mapa, una zona es un *lugar*. |
| Función | Una parte opcional de tu juego que activas en la biblioteca de Funciones: Inventario o Mapa. |
| {ui.topBar.storyMap} | La vista de todas las escenas y los enlaces entre ellas. |
| {ui.topBar.gameUI} | El modo en el que cambias el aspecto del juego. |
| Modo Guion | La vista de una escena como texto, como un guion de cine. |
| Aviso | Un mensaje corto en el juego, como «Has conseguido: Llave». |
| {ui.quickMenu.title} | La pequeña barra de controles de lectura sobre la historia. |
| Modo Jugar | Jugar tu juego dentro del editor. |
| Copia de seguridad | Una copia anterior de `project.json`, guardada en la carpeta `backups`. |
| Idioma del juego | El idioma de los botones y menús del propio juego. Tu historia sigue como la escribiste. |
| {ui.languageDialog.label} | El idioma del propio editor. |
