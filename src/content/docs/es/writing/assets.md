---
title: "Imágenes y recursos"
description: "Importa y organiza las imágenes del juego."
---

**Assets** contiene todas las imágenes. Arrastra archivos a la ventana para importarlos.

| Categoría | Uso |
|---|---|
| **Background** | Fondo detrás de los personajes |
| **Sprite** | Imágenes de personajes |
| **CG** | Ilustraciones de eventos a pantalla completa, usadas como fondos |
| **Prop** | Objetos colocados en momentos de exploración |
| **UI** | Imágenes de interfaz: cuadro de texto, logotipo, botones |
| **Avatar** | Retratos pequeños junto al nombre de quien habla |

Usa los filtros superiores para mostrar una categoría.

Las imágenes se copian a `assets` en el proyecto. Al eliminarlas se trasladan a las copias de seguridad, para poder recuperarlas.
