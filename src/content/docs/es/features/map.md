Activa **Map** en [Features](/novelworks-docs/es/features/features-panel/) y pulsa **Edit map** para abrir su espacio de trabajo.

## Crear el mapa

1. Añade un fondo.
2. Pulsa **Add location** y dibuja una zona.
3. Dale un nombre, como «Cafetería». Se muestra al pasar el cursor por defecto.
4. Elige la escena que se reproduce al pulsar. Puedes crear una desde ese campo.
5. Pruébalo con **Test map**.

## Disponibilidad

En los ajustes, elige cuándo pueden usar los jugadores el botón del mapa:

- **From the start**: el botón Map está disponible desde el principio.
- **After first shown**: el botón aparece cuando la historia llega por primera vez a un momento **Show map**.
- **Story only**: no se muestra el botón Map; solo los momentos **Show map** abren el mapa.

## Momentos Show map

**Show map** abre el mapa inmediatamente y pide elegir un destino. Si se abre con el botón **Map**, puede cerrarse para seguir leyendo.

## Lugares bloqueados

Una condición puede ocultar o bloquear un lugar, con un mensaje cuando esté bloqueado.
