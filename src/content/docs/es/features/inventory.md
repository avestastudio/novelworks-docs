Activa **Inventory** en [Features](/novelworks-docs/es/features/features-panel/) para mostrar **Items**.

## Crear un objeto

Tiene nombre, descripción, imagen de categoría **Prop** y **Kind**: **Single** para tenerlo o no, o **Stackable** para guardar una cantidad.

## Usar objetos

- Momento **Item**: entrega o retira objetos, con aviso opcional como «You got: Key».
- **Choices**: los efectos dan o quitan objetos.
- **Conditions**: comprueban posesión, ausencia o cantidad mínima.
- **Zones**: recogen o usan objetos.

El jugador abre **Inventory** con su botón o **I**. Personalízalo en [Game UI](/novelworks-docs/es/game-ui/game-ui-editor/).
