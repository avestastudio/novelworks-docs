---
title: Variables
description: Remember what players did.
---

A variable is a value your game remembers, like "Mia affection" or "Has the key".

Open the **Variables** tab and add one:

- **Name**: for example "Mia affection".
- **Type**: **Number** or **Yes/No** (boolean).
- **Starts at**: every new game begins with this value.
- **Used in**: shows where it is used. If it says it is not used yet, change it in a choice and check it with a condition.

Variables are changed by [choices](/novelworks-docs/branching/choices/) and exploration zones, and read by [conditions](/novelworks-docs/branching/conditions/).
