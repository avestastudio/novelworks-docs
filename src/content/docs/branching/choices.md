---
title: Choices
description: Let players decide, and make it matter.
---

Add a **Choice** moment from the timeline.

1. Write the **prompt** (the question).
2. Add **options**. For each one: its text, the **scene** it leads to, and optional **effects**.
3. An effect **sets** or **adds to** a variable, for example "Mia affection + 1". With the Inventory feature on, effects can also give or remove items.

Players pick with the mouse, touch, or the number keys **1** to **6**.
