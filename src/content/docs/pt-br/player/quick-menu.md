---
title: Menu rápido
description: Os controles de leitura mostrados sobre a história, do ponto de vista do jogador.
---

O menu rápido é uma barra pequena e discreta sobre a história. Você escolhe o lugar, o visual e os botões dele na página de design [Menu rápido](/novelworks-docs/pt-br/game-ui/quick-menu/). Os jogadores podem usar qualquer um destes botões, ou as teclas:

| Botão | Tecla |
|---|---|
| Histórico | H |
| Auto | A |
| Pular | S |
| Salvar, Carregar | |
| Salvamento rápido, Carregamento rápido | F5, F9 |
| Opções | |
| Menu | Esc |

- Os botões ficam apagados até o ponteiro passar por cima. Auto e Pular parecem apertados enquanto estão ligados.
- Clicar em um botão não avança a história. Apertar qualquer botão que não seja Auto ou Pular desliga o modo de leitura.
- A barra fica oculta na tela de título e na tela final, e enquanto uma tela ou um menu está aberto. **{rt.game.quickLoad}** fica acinzentado até existir um salvamento rápido (no menu de pausa, ele fica oculto). Se o navegador não consegue salvar, as telas Salvar e Carregar avisam.
- Ocultar um botão mantém a tecla dele. Os leitores de tela anunciam o grupo como “{tx.quickMenu.label}”.
