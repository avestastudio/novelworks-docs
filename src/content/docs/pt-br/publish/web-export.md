---
title: "Exportar para a web"
description: "Crie um jogo para o navegador."
---

Escolha **File → Export for Web (itch.io)…** (**Cmd/Ctrl+E**) e uma pasta. O NovelWorks cria um `.zip` pronto para itch.io. A edição completa do itch.io precisa estar ativada.

O jogo começa com «**Made with NovelWorks**» por cerca de 3 segundos. É possível pular com um clique, toque ou tecla.

Notas, resumos de cenas e estados de escrita não são exportados.
