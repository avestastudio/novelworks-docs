---
title: "O editor Game UI"
description: "Personalize todas as telas do jogo."
---

Clique em **Game UI** (**Cmd/Ctrl+5**). Escolha uma tela à esquerda, altere-a à direita e veja o resultado no centro.

| Tela | O que controla |
|---|---|
| **Fonts & colors** | Fonte e cores gerais |
| **Title screen** | Tela de título |
| **Dialogue box** | Nomes e falas |
| **Choices** | Botões das escolhas |
| **Pause menu** | Menu aberto com Esc ou botão direito |
| **Save & load** | Telas de salvar e carregar |
| **History** | Falas já lidas |
| **The End** | Tela de final |
| **Inventory** | Botão e painel de objetos, com Inventory |
| **Map button** | Botão do mapa, com Map |
| **Notices** | Avisos curtos como «You got: Key» |

## Dicas

- Configurações vazias seguem os valores globais.
- A caixa de diálogo pode ficar embaixo, em cima, à esquerda, à direita ou no centro. Ajuste margens, largura e altura. O fundo pode ser cor ou imagem, com **Stretch**, **Fit** ou **9-slice**.
- A etiqueta do nome pode ficar dentro ou acima da caixa. A cor pode seguir cada personagem ou ser comum.
- Estilos de botão: **Pill**, **Rounded**, **Square**.
- **Reset** restaura os valores padrão da tela.
