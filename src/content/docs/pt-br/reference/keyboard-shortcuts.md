---
title: "Atalhos de teclado"
description: "Atalhos do editor e dos jogos."
---

As teclas abaixo são do Mac. No Windows, use **Ctrl** em vez de **Cmd**. A lista também está em **Help → Keyboard Shortcuts** (**Cmd/Ctrl+/**).

## Editor

| Ação | Teclas |
|---|---|
| Salvar | Cmd+S |
| Desfazer / refazer | Cmd+Z / Shift+Cmd+Z (Windows: Ctrl+Y) |
| Jogar desde o título | Cmd+P |
| Jogar desde o momento selecionado | Shift+Cmd+P |
| Buscar e substituir | Cmd+F |
| Exportar para web | Cmd+E |
| Novo projeto / abrir | Cmd+N / Cmd+O |
| Novo diálogo após este momento | Cmd+Enter |
| Duplicar momento | Cmd+D |
| Excluir momento, personagem, zona ou objeto de cenário | Delete ou Backspace |
| Momento anterior / seguinte | ← / → (Cmd+[ e Cmd+] também durante a digitação) |
| Primeiro / último momento | Home / End |
| Scenes, Assets, Characters, Variables | Cmd+1, 2, 3, 4 |
| Game UI | Cmd+5 |
| Story map | Cmd+6 |
| Próxima fala durante a escrita | Enter |
| Nova linha na mesma caixa | Shift+Enter |

## Jogo

| Ação | Teclas |
|---|---|
| Avançar | Clique, Space ou Enter |
| Escolher opção | 1 a 6 |
| Menu de pausa | Esc ou botão direito |
| Salvar / carregar rapidamente | F5 / F9 |
| History | H ou roda para cima |
| Auto | A |
| Skip | S ou segurar Ctrl |
| Inventory | I |
| Map | M |
