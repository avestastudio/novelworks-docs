---
title: Todos os menus
description: Todos os itens dos menus do aplicativo, com seus atalhos.
---

O NovelWorks usa os menus nativos do seu computador. **Cmd** é **Ctrl** no Windows. Alguns itens precisam de um projeto aberto, e a maioria dos comandos de edição é ignorada enquanto você joga.

## Menu do aplicativo (só no Mac)

Sobre o Novelworks, Serviços, Ocultar Novelworks (**Cmd+H**), **{ui.native.role.hideOthers}**, **{ui.native.role.unhide}**, Sair do Novelworks (**Cmd+Q**). No Windows, Sair fica no fim do menu Arquivo, e Sobre fica no menu Ajuda.

## Arquivo

| Item | Atalho | O que faz |
|---|---|---|
| {ui.native.menu.newProject} | **Cmd+N** | Abre a tela de novo projeto. |
| {ui.native.menu.openProject} | **Cmd+O** | Abre a pasta de um projeto. |
| {ui.native.menu.save} | **Cmd+S** | Salva o projeto. |
| {ui.native.menu.restoreFromBackup} | | Volta a uma versão anterior. Veja [Salvar, backups e desfazer](/novelworks-docs/pt-br/getting-started/saving-and-undo/). |
| {ui.native.menu.importScript} | | Adiciona um arquivo de texto às suas cenas. Veja [Importar e exportar um roteiro](/novelworks-docs/pt-br/writing/import-a-script/). |
| {ui.native.menu.exportScript} | | Salva o seu jogo inteiro como um arquivo de texto. |
| {ui.native.menu.exportForWeb} | **Cmd+E** | Exporta o seu jogo para a web. Veja [Exportação para web](/novelworks-docs/pt-br/publish/web-export/). |
| {ui.native.menu.closeProject} | **Cmd+Shift+W** | Volta à tela de projetos. |

## Editar

| Item | Atalho |
|---|---|
| {ui.native.menu.undo} | **Cmd+Z** |
| {ui.native.menu.redo} | **Shift+Cmd+Z** (Windows: **Ctrl+Shift+Z**, e **Ctrl+Y** no editor) |
| {ui.native.menu.findAndReplace} | **Cmd+F** |
| Recortar, Copiar, Colar, Selecionar tudo | **Cmd+X**, **Cmd+C**, **Cmd+V**, **Cmd+A** |
| {ui.native.spelling.spellingLanguage} | No Windows: os idiomas do seu computador mais o inglês, ou outro idioma. No Mac, o macOS detecta o idioma do seu texto. Salvo no projeto. |

Desfazer e Refazer valem para o projeto, exceto no campo de nome da tela de novo projeto.

## Exibir

- **{ui.native.menu.theme}**: {ui.native.menu.dark}, {ui.native.menu.light} ou {ui.native.menu.system}.
- **{ui.native.menu.language}**: {ui.native.menu.languageAuto} ou um dos sete idiomas.
- **{ui.native.role.togglefullscreen}** (**Control+Cmd+F** no Mac).

Os itens de desenvolvedor (Recarregar, Alternar ferramentas do desenvolvedor) só aparecem nas versões de desenvolvimento, não no aplicativo publicado.

## Janela

Minimizar, Zoom e Trazer tudo para a frente no Mac; Minimizar e Fechar no Windows.

## Ajuda

| Item | O que faz |
|---|---|
| {ui.menu.documentation} | Abre esta documentação no seu navegador. |
| {ui.native.menu.replayTutorial} | Repete o [tour guiado](/novelworks-docs/pt-br/getting-started/guided-tour/). |
| {ui.native.menu.keyboardShortcuts} (**Cmd+/**) | Mostra a lista de atalhos. |
| {ui.native.menu.activateNovelWorks} | Só na versão completa do itch.io. Veja [Instalar e ativar](/novelworks-docs/pt-br/getting-started/install-and-activate/). |
| {ui.native.menu.reportABug} | Abre o formulário de contato. Veja [Relatar um bug](/novelworks-docs/pt-br/reference/report-a-bug/). |
| Sobre o Novelworks | Só no Windows: a janela Sobre. |

## Menus da tela de projetos

Na tela de projetos, só os comandos de menu novo projeto, abrir projeto, Sobre, atalhos e Desfazer/Refazer (para o campo de nome) fazem alguma coisa.
