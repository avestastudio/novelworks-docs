---
title: "Imagens e recursos"
description: "Importe e organize as imagens do jogo."
---

**Assets** contém todas as imagens. Arraste arquivos para a janela para importá-los.

| Categoria | Uso |
|---|---|
| **Background** | Fundo atrás dos personagens |
| **Sprite** | Imagens de personagens |
| **CG** | Ilustrações de eventos em tela cheia, usadas como fundos |
| **Prop** | Objetos colocados nos momentos de exploração |
| **UI** | Imagens da interface: caixa de texto, logotipo, botões |
| **Avatar** | Pequenos retratos ao lado do nome de quem fala |

Use os filtros no topo para mostrar uma categoria.

As imagens são copiadas para `assets` no projeto. Quando excluídas, vão para os backups, permitindo recuperação.
