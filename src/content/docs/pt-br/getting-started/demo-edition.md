---
title: "A demonstração gratuita"
description: "O que a edição NovelWorks Demo permite fazer."
---

**NovelWorks Demo** é a edição gratuita. Ela inclui o editor completo e o modo Play, para criar um jogo inteiro e testá-lo.

A única limitação é a **exportação**. Na demo, **File → Export for Web** abre uma janela com um botão para obter a versão completa, em vez de exportar.

Os projetos da demo abrem na versão completa sem alterações. As duas edições usam o mesmo formato de projeto e podem ser instaladas lado a lado.
